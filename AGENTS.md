# Unified Headless Wrapper

Every session in this repo follows the ruling protocol. Before anything else, read `src/rnd/v0.0.1/02-ruling-protocol.md` in full, then `src/rnd/v0.0.1/00-status.md`. Read the status page first in every session and update it last.

This file is the Antigravity (AGY) loader; `CLAUDE.md` is the Claude Code loader. Both point at the same protocol, and the protocol is the only place the procedure is written.

Where the protocol names a Claude Code tool, use the AGY equivalent: `ask_question` for `AskUserQuestion`, one decision per call.
