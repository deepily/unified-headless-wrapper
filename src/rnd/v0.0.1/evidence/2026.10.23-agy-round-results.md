# AGY round on the test VM: invalid, because AGY is installed as a snap

**Run:** 2026-10-23 22:42 · test VM (`lupin-host-test`) · **AGY 1.2.11, installed as a snap** · `agy_round.sh` · results in `src/captures/out/*-agy-20261023*`

**Bottom line:** do not use these results to compare AGY with Jetski. Snap confinement separated AGY from everything the captures plant:
- **Workspaces:** the throwaway repos live under the host's `/tmp`. The snap has a private `/tmp`, so the model's working directory became `/var/lib/snapd/void` ("Permission denied" on `touch sub.marker`).
- **Home directory:** the snap's home is `~/snap/antigravity-cli/common/`. Its MCP config is `~/snap/antigravity-cli/common/.gemini/antigravity-cli/mcp_config.json`, not `~/.gemini/config/mcp_config.json`, so the probe server never loaded ("no MCP tools are registered").
- **Project hooks:** `.agents/hooks.json` sits in an invisible workspace, so no hook ever fired. `modelName` is `none` in every C13 line, which means even the model pins are unconfirmed.

Every "no" in C11, C11b, C11c, C12 and C14 follows from these three facts, not from AGY's capabilities. Part A (2026-10-15, AGY 1.3.5, non-snap, dev server) shows AGY honoring project hooks and the standard MCP config.
