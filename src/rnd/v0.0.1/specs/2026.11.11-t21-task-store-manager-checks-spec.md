## 3. The layer rule, amended

Exposure and the gate decide what a role may call and with what arguments. A rule that depends on the state of a row in Lupin's store is decided in Lupin, once, for every caller (fleet key or browser), from one fact the kernel supplies: the persona's role. The gate carries no copy of these seven rules.

## 4. The role fact

- `kernel_row( persona_id )` is `GET /personas/{id}` on `~/.lupin/kernel/kernel.sock`, sent with `Lupin-Client: lupin-server` (D66). 404 `persona_not_found` is "not on the roster"; a row in state `closed` is too. A connection failure, a timeout or a 503 (`kernel_starting`, `kernel_stopping`) is "unreachable".
- Only `role`, `state` and `voice_persona` are read: three stable fields of the row of record (T09 spec Section 10.3).
- Manager roles: `manager`, `chief_of_staff`. The role is fixed for a persona's life, so the cache holds no stale privilege; it expires so a dismissed persona stops passing within thirty seconds.
- The task store's event row gains `role_source: kernel | bridge` beside the actor on the seven doors' events.
- Interim, Phase 1 through the Move clock: Lupin has no roster client, so a kernel persona is refused at the seven doors as "no session file". The store's own advice in that refusal (create queued, then transition; or have a manager do it) is the workaround. Kernel-1 to Kernel-8 exercise none of the seven doors.

## 5. The caller's identifier

`caller_persona_id( signature_tail, grant_persona_id )`. Until `kernel grant required` is on (T36, flipped at the switch-over), the tail of `created_by` or `actor` is the identifier. After, the grant's identifier is; a signature naming another persona is refused 403 `signature_mismatch`, a fifth wording.

## 6. The mixed fleet

During the shadow run and the soak (D63) `bridge` is `is_manager_figure`'s answer for a session that has a file, `None` otherwise. Kernel first. An old-harness manager is answered from its file even when the kernel is unreachable. Rows for the switch-over list (T19 spec Section 5): `cosa/rest/persona_role.py` `bridge` parameter and its three call sites, clock Delete; `cosa/rest/routers/podcast_proxy.py`'s session-file read, which the inventory script does not list.

## 7. Refusals

| Cause | Status | Wording ends |
| --- | --- | --- |
| `no_persona_id` | 403 | no persona identifier reached the store, so nothing could be resolved |
| `not_on_roster` | 403 | that persona identifier is not on the kernel's roster (dismissed, or never spawned) |
| `not_a_manager` | 403 | the caller resolved through the kernel with role '<role>' |
| `kernel_unreachable` | 503, `Retry-After` | This is NOT a permissions problem. Retry in N seconds. |
| `signature_mismatch` (after T36) | 403 | the signature names a different persona than the kernel's grant |

The tool server passes the 503 and its `Retry-After` through to the model unchanged and does not retry on its own; `DENIAL_STALE_BRIDGE` and its text retire at the Delete clock.

## 10. Reference implementation (runs; eight tests pass on 2026-11-11, Python 3, no dependencies)

```python
"""
T21 reference (D67, 2026-11-11): the one role fact behind the task store's seven manager-only doors.

Lands in lupin as `cosa/rest/persona_role.py` at the Move clock. The rules stay where they are
(`task_promotion_gate`, `task_priority_firewall`, `routers/tasks.py`); they stop importing
`hooks.lib.manager_figure` and ask `resolve_role` instead. Pure: every outside read is injected.
"""
import time
from typing import Callable, NamedTuple, Optional

MANAGER_ROLES      = ( "manager", "chief_of_staff" )
CACHE_SECONDS      = 30          # INI: task store role cache seconds
RETRY_AFTER        = 5           # INI: task store role retry after seconds

CAUSE_MANAGER            = "manager"
CAUSE_NO_PERSONA_ID      = "no_persona_id"
CAUSE_NOT_ON_ROSTER      = "not_on_roster"
CAUSE_NOT_A_MANAGER      = "not_a_manager"
CAUSE_KERNEL_UNREACHABLE = "kernel_unreachable"
CAUSE_SIGNATURE_MISMATCH = "signature_mismatch"


class KernelUnreachable( Exception ):
    """The kernel socket refused, timed out, or answered 503 (starting, stopping)."""


class RoleAnswer( NamedTuple ):
    is_manager   : bool
    cause        : str
    source       : Optional[str]      # "kernel" | "bridge" | None
    role         : Optional[str]
    voice_persona: Optional[str]      # the name the store is keyed on (D64); from the row, never typed


def caller_persona_id( signature_tail, grant_persona_id=None ):
    """
    Ruling 5. The eight hex off "<persona name> <eight hex>" today; the signed grant once
    `kernel grant required` is on (T36), and then a signature that disagrees is refused.

    Ensures: returns ( persona_id or None, cause or None ); cause is set only on a mismatch.
    """
    if grant_persona_id is None: return signature_tail, None
    if signature_tail is not None and signature_tail != grant_persona_id:
        return None, CAUSE_SIGNATURE_MISMATCH
    return grant_persona_id, None


def resolve_role( persona_id,
                  kernel_row : Callable[ [ str ], Optional[dict] ],
                  bridge     : Optional[ Callable[ [ str ], Optional[bool] ] ] = None,
                  cache      : Optional[dict] = None,
                  now        : Callable[ [], float ] = time.monotonic ) -> RoleAnswer:
    """
    Rulings 3, 4, 6. Ask the kernel for the persona's row; fall back to the session file
    only while both harnesses run (`bridge` is None after the Delete clock).

    Requires:
        - kernel_row( id ) returns the row of record (T09 spec Section 10.3), None on 404
          `persona_not_found`, and raises KernelUnreachable otherwise
        - bridge( id ) returns True or False when a session file resolves, None when none does
    Ensures:
        - fails closed: is_manager is True only on a live row whose role is in MANAGER_ROLES,
          or on a session file that says so
        - only kernel answers are cached, for CACHE_SECONDS; unreachable is never cached
        - never raises
    """
    if not persona_id:
        return RoleAnswer( False, CAUSE_NO_PERSONA_ID, None, None, None )

    if cache is not None and persona_id in cache and now() - cache[ persona_id ][ 0 ] < CACHE_SECONDS:
        return cache[ persona_id ][ 1 ]

    unreachable = False
    try:
        row = kernel_row( persona_id )
    except Exception:
        row, unreachable = None, True

    if row is not None and row.get( "state" ) != "closed":
        role   = row.get( "role" )
        passed = role in MANAGER_ROLES
        answer = RoleAnswer( passed, CAUSE_MANAGER if passed else CAUSE_NOT_A_MANAGER, "kernel", role, row.get( "voice_persona" ) )
        if cache is not None: cache[ persona_id ] = ( now(), answer )
        return answer

    try:
        from_file = bridge( persona_id ) if bridge is not None else None
    except Exception:
        from_file = None
    if from_file is not None:
        return RoleAnswer( bool( from_file ), CAUSE_MANAGER if from_file else CAUSE_NOT_A_MANAGER, "bridge", None, None )

    return RoleAnswer( False, CAUSE_KERNEL_UNREACHABLE if unreachable else CAUSE_NOT_ON_ROSTER, None, None, None )


def refusal( answer : RoleAnswer, actor, act ):
    """
    Ruling 7. ( status, detail, headers ) for a refused caller, or None when the caller passes.
    Four causes (five with the grant), no two worded alike; only one invites a retry.
    """
    if answer.is_manager: return None
    who = f"'{actor}'"
    if answer.cause == CAUSE_KERNEL_UNREACHABLE:
        return 503, ( f"{act} is manager-only and the Lupin kernel could not be reached to read {who}'s role. "
                      f"This is NOT a permissions problem. Retry in {RETRY_AFTER} seconds." ), { "Retry-After": str( RETRY_AFTER ) }
    tail = {
        CAUSE_NO_PERSONA_ID      : "no persona identifier reached the store, so nothing could be resolved",
        CAUSE_NOT_ON_ROSTER      : "that persona identifier is not on the kernel's roster (dismissed, or never spawned)",
        CAUSE_SIGNATURE_MISMATCH : "the signature names a different persona than the kernel's grant",
    }.get( answer.cause, f"the caller resolved through the {answer.source} with role '{answer.role or 'not manager'}'" )
    return 403, f"{act} is manager-only ({', '.join( MANAGER_ROLES )}); {who} was refused: {tail}.", { }


def sweep_refusal( answer : RoleAnswer, sweep_persona_key, canonical : Callable[ [ str ], str ] ):
    """
    Ruling 8. A sweep route carries no role check; the caller may touch only its own sweep,
    and its name is the row's `voice_persona`, never a typed field.
    """
    if answer.cause == CAUSE_KERNEL_UNREACHABLE: return refusal( answer, sweep_persona_key, "a board sweep" )
    if answer.voice_persona is None:
        return 403, "a board sweep needs a persona on the kernel's roster with a voice persona; none resolved.", { }
    if canonical( answer.voice_persona ) != sweep_persona_key:
        return 403, f"a persona may open and mark only its own sweep; this one belongs to '{sweep_persona_key}'.", { }
    return None
```

```python
from persona_role import *

ROWS = { "a1b2c3d4": { "role": "manager",        "state": "busy",   "voice_persona": "Mr. Radio" },
         "bbbbbbbb": { "role": "chief_of_staff", "state": "idle",   "voice_persona": "María" },
         "cccccccc": { "role": "implementer",    "state": "busy",   "voice_persona": "Cheech" },
         "dddddddd": { "role": "manager",        "state": "closed", "voice_persona": "Old" } }
def kernel( persona_id ): return ROWS.get( persona_id )
def down( persona_id ):   raise KernelUnreachable()
key = lambda name: name.lower().replace( ".", "" )

def test_role_only_and_chief_of_staff():
    assert resolve_role( "a1b2c3d4", kernel ).is_manager and resolve_role( "bbbbbbbb", kernel ).is_manager
    answer = resolve_role( "cccccccc", kernel )
    assert not answer.is_manager and answer.cause == CAUSE_NOT_A_MANAGER and answer.role == "implementer"

def test_four_causes_four_wordings():
    answers = [ resolve_role( None, kernel ), resolve_role( "eeeeeeee", kernel ), resolve_role( "cccccccc", kernel ), resolve_role( "a1b2c3d4", down ) ]
    assert [ a.cause for a in answers ] == [ CAUSE_NO_PERSONA_ID, CAUSE_NOT_ON_ROSTER, CAUSE_NOT_A_MANAGER, CAUSE_KERNEL_UNREACHABLE ]
    refusals = [ refusal( a, "Cheech cccccccc", "minting a blocked task" ) for a in answers ]
    assert [ r[ 0 ] for r in refusals ] == [ 403, 403, 403, 503 ] and len( { r[ 1 ] for r in refusals } ) == 4
    assert refusals[ 3 ][ 2 ] == { "Retry-After": "5" } and "NOT a permissions problem" in refusals[ 3 ][ 1 ]
    assert refusal( resolve_role( "a1b2c3d4", kernel ), "x", "y" ) is None

def test_closed_row_is_off_the_roster():
    assert resolve_role( "dddddddd", kernel ).cause == CAUSE_NOT_ON_ROSTER

def test_mixed_fleet_kernel_first_then_file_and_source_recorded():
    bridge = { "11111111": True, "22222222": False }.get
    assert resolve_role( "a1b2c3d4", kernel, bridge ).source == "kernel"
    assert resolve_role( "11111111", kernel, bridge ) == RoleAnswer( True, CAUSE_MANAGER, "bridge", None, None )
    assert resolve_role( "22222222", kernel, bridge ).cause == CAUSE_NOT_A_MANAGER
    assert resolve_role( "11111111", down, bridge ).is_manager                      # an old-harness manager is not hostage to a kernel restart
    assert resolve_role( "33333333", down, bridge ).cause == CAUSE_KERNEL_UNREACHABLE
    assert resolve_role( "11111111", kernel ).cause == CAUSE_NOT_ON_ROSTER          # after the Delete clock: no file branch

def test_cache_thirty_seconds_kernel_answers_only():
    clock, calls, cache = [ 0.0 ], [ ], { }
    def counted( persona_id ): calls.append( persona_id ); return kernel( persona_id )
    for tick in ( 0, 29, 31 ):
        clock[ 0 ] = tick; resolve_role( "a1b2c3d4", counted, cache=cache, now=lambda: clock[ 0 ] )
    assert len( calls ) == 2
    resolve_role( "a1b2c3d4", down, cache={ } ); resolve_role( "eeeeeeee", kernel, cache=cache )
    assert "eeeeeeee" not in cache

def test_signature_now_grant_later():
    assert caller_persona_id( "a1b2c3d4" ) == ( "a1b2c3d4", None )
    assert caller_persona_id( "a1b2c3d4", "a1b2c3d4" ) == ( "a1b2c3d4", None )
    assert caller_persona_id( None, "a1b2c3d4" ) == ( "a1b2c3d4", None )
    assert caller_persona_id( "cccccccc", "a1b2c3d4" ) == ( None, CAUSE_SIGNATURE_MISMATCH )

def test_sweep_own_only_name_from_the_row():
    worker = resolve_role( "cccccccc", kernel )
    assert sweep_refusal( worker, "cheech", key ) is None                           # no role check
    assert sweep_refusal( worker, "mr radio", key )[ 0 ] == 403
    assert sweep_refusal( resolve_role( "eeeeeeee", kernel ), "cheech", key )[ 0 ] == 403
    assert sweep_refusal( resolve_role( "cccccccc", down ), "cheech", key )[ 0 ] == 503

def test_never_raises():
    def broken( persona_id ): raise ValueError( "boom" )
    assert resolve_role( "a1b2c3d4", broken, broken ).cause == CAUSE_KERNEL_UNREACHABLE
```
