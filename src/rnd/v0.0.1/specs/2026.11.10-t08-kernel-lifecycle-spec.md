## 2. The unit

`~/.config/systemd/user/lupin-kernel.service`, rendered by `install-lupin-kernel.sh` from a template with two placeholders (`__LUPIN_ROOT__`, `__PYTHON__`), the convention of `install-bounce-watcher.sh`. The installer runs `loginctl enable-linger` once and `systemctl --user daemon-reload`; it never enables or starts the unit without being asked (the arbiter unit's rule).

```ini
[Unit]
Description=Lupin kernel (UHW) — one per host, one fleet per Lupin instance
After=network.target

[Service]
Type=notify
NotifyAccess=main
Environment=LUPIN_ROOT=__LUPIN_ROOT__
ExecStart=__PYTHON__ -m uhw_kernel            ; `lupin kernel run` after the move (D45)
Restart=on-failure
RestartSec=5
RestartPreventExitStatus=78                   ; a startup refusal is reported once, never retried
StartLimitIntervalSec=300
StartLimitBurst=5
WatchdogSec=60                                ; the event loop pings every 20 s
KillSignal=SIGTERM                            ; a plain stop: drain, then stop the engines
RestartKillSignal=SIGUSR1                     ; a restart: park the engines and go
TimeoutStopSec=230                            ; drain 180 + grace 10 + grace 10 + 30
FileDescriptorStoreMax=256                    ; three per persona

[Install]
WantedBy=default.target
```

The unit carries no memory property: the engines live in `lupin-personas.slice` (D60), not in this service's cgroup, which is what lets them outlive it. `WatchdogSec` catches a hung loop, which `Restart=` alone would not; a watchdog kill is a restart, so the store is kept and the engines survive it. Exit 78 is the one exit the unit never retries: the invariants of D50 and D59, a configuration the ConfigurationManager refuses, a live kernel already on the socket, a registry the kernel cannot migrate.

## 3. Engines that outlive a restart

**At spawn** the adapter, having created the process in its scope, pushes the three pipe ends to the store: `FDSTORE=1\nFDNAME=persona-<id>-in` with the stdin write end, `…-out` with the stdout read end, `…-err` with the stderr read end (`FdStore.push`). **At dismissal, at hibernation, at a crash and in the plain stop** it removes them (`FDSTOREREMOVE=1`). A persona's row and its three names are therefore always in step while a process exists.

**On SIGUSR1** (the restart-stop): `kernel.stopping { reason: restart, running, busy }`, the socket file removed, the registry flushed, exit 0. Nothing is closed and no engine is told. An engine mid-turn writes into a pipe nobody reads for the few seconds the kernel is away; the pipe holds 64 KiB and then the engine blocks on the write, which is the only effect.

**At start** (step 6 of Section 5): `FdStore.inherited()` maps names to descriptors; `plan_reattach` marks a row `reattach` when its `process_id` is alive and all three names came back, otherwise `resume_pending`; stray descriptors are closed. A reattached session resumes its read loop after `discard_partial_line` on whatever is buffered (`session.reattached { discarded_bytes }`), keeps its state (`busy` stays `busy`; the result frame arrives as it would have), and is told nothing. The Section 5.4 resume check does not run: the conversation never ended.

**What is not kept.** `systemctl stop` followed by `systemctl start` loses the store by systemd's own rule; the plain stop therefore stops the engines in order (Section 4), which is the behavior an operator typing `stop` expects. A host reboot is a plain stop. A kernel crash (an uncaught exception, a watchdog kill) is a restart by systemd and keeps the store: the engines survive the kernel's own bugs.

## 4. The stop

On SIGTERM the kernel runs `StopSequence` (Section 12):

1. `kernel.stopping { reason: stop, running, busy }`; `POST /personas` and every wake answer 503 `stopping`; the human's card (Section 10).
2. Every `idle` or `awaiting_human` engine: stdin closed (the engine exits on end-of-file), SIGTERM after `kernel stop grace seconds` (10), SIGKILL after another grace. `awaiting_human` loses nothing: the ticket is in Lupin and the answer arrives as the next block.
3. Every `busy` engine: up to `kernel stop drain seconds` (180, the family-wide MCP call cap, so one tool call can finish) for its `result` frame, then step 2's closing. Its outcome is `drained` or `cut`.
4. Per row: `process_id: null`, `stopped_at`, `stopped_in_turn: true | false` (true for `cut`), the three names removed from the store, the scope left to `--collect`.
5. `kernel.stopped { drained, cut, killed, duration_ms }`; the registry flushed; the socket file removed; exit 0.

The rows keep everything else: state (`busy` is rewritten `idle`), conversation id, manager, voice allocation, reports, `inbox.json` cursors. `TimeoutStopSec` is 230 s, so systemd never kills a draining kernel; a kernel that cannot finish inside that is a bug to find in the log, not a unit setting to raise.

## 5. The start

In this order; a failure in steps 1 to 3 is exit 78 and one line on stderr, and nothing on disk has changed:

1. Configuration through the ConfigurationManager (D62); the `kernel …` keys of Section 13 read once; `app timezone` resolved through `cosa.config.app_timezone.get_app_timezone` (no code default: a missing zone stops the kernel).
2. Invariants: the D50 credential invariants; the D59 account check for `production`; **one kernel per host**: if `kernel.sock` exists, connect to it; a live `GET /health` is exit 78 naming the other kernel's pid, a dead file is removed.
3. The registry loaded; `schema_version` older than the kernel's is migrated forward and the file as found kept as `registry.json.v<old>`; newer than the kernel's is exit 78 (a downgrade across a schema change restores the kept file by hand, the one runbook line).
4. `lupin-personas.slice` bound (D60).
5. The socket bound, mode 0600.
6. The descriptor store read; the reattach plan applied (Section 3); every other non-closed row set `process_id: null` with `resume_reason: kernel_restart` when it had a process at the stop.
7. One WebSocket per non-closed persona (D36) with the catch-up pull (D52, D55).
8. `kernel.started { version, config_sha256, owner_user_id_present, persona_account_privileged, slice_bound, invariants, previous_run: { stopped_at, reason } | null, reattached, resume_pending, crash_looping, schema_migrated_from }`.
9. `READY=1` to systemd; the watchdog ping task begins.
10. The job table's catch-up tick (Section 8); the first hibernation sweep (D59); the human's card when `previous_run` is not null (Section 10).

**The lazy start.** A persona with no process starts one on its next block, through the same path hibernation uses (D59): the stored conversation, the Section 5.4 `init.conversation_id` check, `session.resumed { reason: hibernation | kernel_restart | crash }`. A D62 poke is a block, so an owed persona returns within 600 s of the kernel's start without anyone speaking; a persona with nothing owed returns when spoken to. The first turn after a `kernel_restart` resume opens with the `restarted` block (Section 10); after a `crash` resume, with the `crashed` block (Section 6).

## 6. One engine crashing

The adapter's read loop sees the process end. If the last frame of the turn was a `result`, that is `session.exited` (D56) and not a crash. Otherwise:

- `session.crashed { exit_code, signal, oom_killed, in_turn, turn_id, uptime_seconds }` — `oom_killed` true when D60's `memory.events oom_kill` moved since the last sample, which is the D60 handoff ("then the T08 crash rule").
- The row: `process_id: null`, `state: idle`, `crashed_at`, `crash_count` within the window, `resume_reason: crash`, `interrupted_block` (the header line and text of the inbound block the turn was answering, when `in_turn`). Reports stay, the voice stays allocated, the worktree is untouched, the three store names are removed.
- `CrashGuard.record` (3 within 10 minutes by default): when it fires, `crash_looping: true` on the row, `session.crash_looping`, one notice to the manager (a `dm` block; the human's card when there is no manager), and no automatic start until the flag is cleared by a re-spin (D54 handshake, which also resets the guard) or a dismissal. A memory re-spin under D60 is a handshake, not a crash, and is not counted.
- The next block starts the process (Section 5) and the turn opens with `crash_block( now, reason, interrupted_block )`:

```
[kernel 22:05:09 crashed oom_killed]
Your previous turn ended without a result at 22:05. The message it was answering is repeated below; decide what still needs doing.

[voice 22:04:51 from human]
please rebase the branch
```

The kernel repeats the text; it never re-runs the turn. A tool call may already have had its effect and D49's approvals are single-use; the model, which can read its own worktree and the task store, decides what to redo.

## 7. The upgrade

```
cd $LUPIN_ROOT && git pull                    # Phase 1; lupin's deploy after the move
systemctl --user restart lupin-kernel
lupin kernel status                           # version, reattached, resume_pending, crash_looping, jobs
```

- The restart is Section 3: no engine notices. `kernel_version` is in every `log.segment` already (D56) and in `kernel.started`.
- The registry schema moves forward only (Section 5 step 3). Rollback (D63's "the unit's stop and start") is the same three lines with the previous version checked out, plus `cp registry.json.v<old> registry.json` when the schema moved.
- **The shim during the window.** On a connection refused or a missing socket the hook shim retries `POST /gate` every second for `kernel gate retry seconds` (30), then applies the unreachable policy: `allow` when `kernel host class` is `test`, `deny` when `production`, logged as `gate.unreachable { decision, waited_ms }` the next time the kernel can hear it (the shim appends to its own stderr line, which the adapter lifts as `engine.stderr`). This replaces the Phase 1 spec's unconditional fail-open (Section 10 step 5 there).
- The control API's version field and compatibility rule are T09's; the kit's hook shim and MCP server are pinned by `kit.lock` (D54) and are not changed by a kernel restart.

## 8. The job table

`jobs.py` (Section 12: `Scheduler`, `Job`, `Daily`, `Every`). One asyncio task wakes every 30 s and calls `tick( now )`.

| Job | Cadence (default) | Does | From |
|---|---|---|---|
| `memento.verify` | daily at `03:30` local | Section 9 | D62 |
| `archive.sweep` | daily at `04:00` local | deletes `~/.lupin/archive/ah4l-*.tar.gz` and manifests older than `kernel archive retention days` (30) | D64 |
| `log.sweep` | every 3,600 s | D56's retention sweep, moved here from its own timer | D56 |
| `tree.sweep` | every 3,600 s | D59's kept-tree sweep (lupin's `worktree_reaper` after the move), as an awaited subprocess | D59 |

Rules: a job never overlaps itself (`job.skipped { reason: running }`); a job that raises is `job.finished { ok: false, detail.error }` and waits for its cadence; **catch-up** is the ordinary due rule applied at start (a job whose `last_run` is older than one cadence is due; one run, however many cadences were missed); `last_run` per job is persisted in `~/.lupin/kernel/jobs.json` after every run. `Daily` is computed in `app timezone` through `zoneinfo`, so `03:30` is `03:30` in winter and summer alike. Not jobs: the 15 s memory sampler (D60), the per-persona idle re-check (D62), the hibernation sweep (D59) and the watchdog ping, which keep their own clocks.

CLI: `lupin kernel jobs` (name, cadence, enabled, last run, last result), `lupin kernel job run <name>` (forces one run now; `job.started { forced: true }`). The console's `:jobs` view (D58) reads the same.

## 9. The memento verify

`memento_due( rows, newest_record_at, max_age_hours )` over every non-closed row with a `last_turn_at`: due when its newest memento record stamped `persona_id=<id>` (D54; the mirror under `~/.lupin/mementos/`, the records in `io/mementos/`) is absent or more than `kernel memento verify max age hours` (24) older than the last turn. For each due persona:

- `[kernel HH:MM:SS memento due]` as its next block: "Write a memento now; your last record is <age> old (or: there is none)." A hibernated persona is woken for it: it has done work since its last record, by the test.
- Still due at the next day's run (`due_since` on the row older than one cadence): one `dm` block to its manager, once; the human's card when there is no manager.
- `job.finished { ok: due == [], due, requested, notified }`. D63's soak measure "memento verify green daily" is `ok` on the last seven `job.finished` records of this job.

## 10. Who is told

- **The human.** `POST /api/notify`, `priority: low`, ding suppressed, `payload.kind: kernel_event` (a one-line T27 row for the card): on a non-first start, "Kernel restarted at <local time> (<reason: restart | crash | watchdog | boot>): <n> personas reattached, <m> resume on their next message, <k> crash-looping."; on a plain stop, "Kernel stopping: <n> personas drained, <m> cut."
- **A resumed persona** (`resume_reason: kernel_restart`): its next turn opens with `[kernel HH:MM:SS restarted]` and one sentence: "The kernel restarted; a tool call that failed with a connection error just before may be repeated." A reattached persona gets nothing; a hibernated persona is not woken; there is no broadcast.
- **Lupin's own restarts** reach the personas as D61 broadcasts from `lupin`; the kernel's reconnect (D36) and catch-up pull (D52, D55) are its whole part.

## 12. Reference implementation (runs; ten tests pass on 2026-11-10)

`lifecycle.py` — standard library only.

```python
"""lifecycle.py — the kernel's own lifecycle (D65, T08). Standard library only.

Reference module for the T08 spec: the systemd descriptor store, the reattach plan,
the stop sequence, the crash guard and crash block, the job table with its local
clock, and the memento verify. Injectable clocks and sockets; nothing here touches
a real engine. Times are aware datetimes; the job clock is the application's zone.
"""
import array, os, socket
from dataclasses import dataclass, field
from datetime import datetime, timedelta, time as dtime
from zoneinfo import ZoneInfo

EXIT_CONFIGURATION_REFUSED = 78        # RestartPreventExitStatus=78 in the unit


# ---------------------------------------------------------------- descriptor store

class FdStore:
    """Park and recover engine pipes with systemd's per-service descriptor store.

    `push( name, fds )` and `remove( name )` speak to $NOTIFY_SOCKET; `inherited()`
    reads LISTEN_FDS / LISTEN_FDNAMES at start. `send` is injectable for tests.
    """
    def __init__( self, environ=None, send=None ):
        self.environ = os.environ if environ is None else environ
        self.send    = self._send_notify if send is None else send

    def push( self, name, fds ):
        return self.send( f"FDSTORE=1\nFDNAME={name}\n", list( fds ) )

    def remove( self, name ):
        return self.send( f"FDSTOREREMOVE=1\nFDNAME={name}\n", [] )

    def inherited( self ):
        """{ name: fd } for the descriptors systemd handed back, or {} when none."""
        if str( os.getpid() ) != self.environ.get( "LISTEN_PID", "" ): return {}
        count = int( self.environ.get( "LISTEN_FDS", "0" ) or 0 )
        names = self.environ.get( "LISTEN_FDNAMES", "" ).split( ":" ) if count else []
        return { names[ i ] if i < len( names ) else f"fd{3 + i}": 3 + i for i in range( count ) }

    def _send_notify( self, text, fds ):
        path = self.environ.get( "NOTIFY_SOCKET" )
        if not path: return False
        if path.startswith( "@" ): path = "\0" + path[ 1: ]
        with socket.socket( socket.AF_UNIX, socket.SOCK_DGRAM ) as s:
            anc = [ ( socket.SOL_SOCKET, socket.SCM_RIGHTS, array.array( "i", fds ) ) ] if fds else []
            s.sendmsg( [ text.encode() ], anc, 0, path )
        return True


def fd_names( persona_id ):
    return [ f"persona-{persona_id}-{end}" for end in ( "in", "out", "err" ) ]


def plan_reattach( rows, inherited, alive ):
    """Decide, per non-closed row, `reattach` or `resume_pending`.

    A row reattaches when it still names a live process and all three of its
    descriptors came back. Everything else resumes lazily; stray descriptors are
    listed for closing.
    """
    plan, used = {}, set()
    for row in rows:
        if row.get( "state" ) == "closed": continue
        names = fd_names( row[ "persona_id" ] )
        have  = all( n in inherited for n in names )
        if row.get( "process_id" ) and alive( row[ "process_id" ] ) and have:
            plan[ row[ "persona_id" ] ] = "reattach"; used.update( names )
        else:
            plan[ row[ "persona_id" ] ] = "resume_pending"
    stray = [ fd for name, fd in inherited.items() if name not in used ]
    return plan, stray


def discard_partial_line( buffer ):
    """After a reattach the pipe may sit mid-line: drop through the first newline.
    Returns ( discarded_bytes, remainder )."""
    cut = buffer.find( b"\n" )
    if cut < 0: return len( buffer ), b""
    return cut + 1, buffer[ cut + 1: ]


# ---------------------------------------------------------------- the stop sequence

@dataclass
class StopSequence:
    """SIGTERM handling: idle engines closed at once, busy ones drained to a bound,
    then grace, then kill. Driven by `start`, `on_result` and `due`; pure."""
    drain_seconds: int = 180
    grace_seconds: int = 10
    deadline: dict = field( default_factory=dict )    # persona_id -> (phase, when)
    outcome:  dict = field( default_factory=dict )    # persona_id -> drained | cut | killed

    def start( self, rows, now ):
        actions = []
        for row in rows:
            pid = row[ "persona_id" ]
            if row[ "state" ] == "busy":
                self.deadline[ pid ] = ( "drain", now + timedelta( seconds=self.drain_seconds ) )
            else:
                actions.append( ( "close", pid ) )
                self.deadline[ pid ] = ( "close", now + timedelta( seconds=self.grace_seconds ) )
        return actions

    def on_result( self, persona_id, now ):
        phase, _ = self.deadline.get( persona_id, ( None, None ) )
        if phase == "drain":
            self.outcome[ persona_id ] = "drained"
            self.deadline[ persona_id ] = ( "close", now + timedelta( seconds=self.grace_seconds ) )
            return [ ( "close", persona_id ) ]
        return []

    def on_exit( self, persona_id ):
        self.deadline.pop( persona_id, None )
        self.outcome.setdefault( persona_id, "drained" )

    def due( self, now ):
        actions = []
        for pid, ( phase, when ) in list( self.deadline.items() ):
            if now < when: continue
            if phase == "drain":
                self.outcome[ pid ] = "cut";    actions.append( ( "close", pid ) )
                self.deadline[ pid ] = ( "close", now + timedelta( seconds=self.grace_seconds ) )
            elif phase == "close":
                actions.append( ( "term", pid ) )
                self.deadline[ pid ] = ( "term", now + timedelta( seconds=self.grace_seconds ) )
            elif phase == "term":
                self.outcome[ pid ] = "killed"; actions.append( ( "kill", pid ) )
                del self.deadline[ pid ]
        return actions

    def finished( self ):
        return not self.deadline

    def summary( self ):
        return { k: sum( 1 for v in self.outcome.values() if v == k ) for k in ( "drained", "cut", "killed" ) }


# ---------------------------------------------------------------- crashes

class CrashGuard:
    """`kernel crash loop count` crashes within `kernel crash loop minutes` → looping."""
    def __init__( self, count=3, minutes=10 ):
        self.count, self.window, self.seen = count, timedelta( minutes=minutes ), {}

    def record( self, persona_id, now ):
        hits = [ t for t in self.seen.get( persona_id, [] ) if now - t < self.window ] + [ now ]
        self.seen[ persona_id ] = hits
        return len( hits ) >= self.count

    def clear( self, persona_id ):
        self.seen.pop( persona_id, None )


def crash_block( now, reason, interrupted=None ):
    """The first block of the turn after a crash, in the D52 grammar. `interrupted`
    is the header line and text of the message the crash cut, when there was one."""
    head = f"[kernel {now.strftime( '%H:%M:%S' )} crashed {reason}]"
    body = f"Your previous turn ended without a result at {now.strftime( '%H:%M' )}."
    if interrupted:
        body += " The message it was answering is repeated below; decide what still needs doing.\n\n" + interrupted
    return head + "\n" + body


def kernel_block( now, kind, sentence ):
    return f"[kernel {now.strftime( '%H:%M:%S' )} {kind}]\n{sentence}"


# ---------------------------------------------------------------- the job table

@dataclass
class Daily:
    """Once a day at a wall-clock time in the application's zone (DST-aware)."""
    at: dtime
    zone: ZoneInfo
    def next_after( self, last ):
        local = last.astimezone( self.zone )
        candidate = datetime.combine( local.date(), self.at, tzinfo=self.zone )
        if candidate <= local: candidate = datetime.combine( local.date() + timedelta( days=1 ), self.at, tzinfo=self.zone )
        return candidate

@dataclass
class Every:
    seconds: int
    def next_after( self, last ):
        return last + timedelta( seconds=self.seconds )

@dataclass
class Job:
    name: str
    cadence: object
    run: object                         # callable( now ) -> detail dict; may raise
    enabled: bool = True

class Scheduler:
    """One table, persisted `last_run`, catch-up at start, no overlap, `job.*` records."""
    def __init__( self, jobs, last_run=None, log=None ):
        self.jobs     = { j.name: j for j in jobs }
        self.last_run = dict( last_run or {} )
        self.log      = log if log is not None else ( lambda kind, data: None )
        self.running  = set()

    def due( self, now ):
        out = []
        for name, job in self.jobs.items():
            if not job.enabled or name in self.running: continue
            last = self.last_run.get( name )
            if last is None or now >= job.cadence.next_after( last ): out.append( name )
        return out

    def tick( self, now ):
        """Run every due job once. A kernel that was down through several cadences
        runs each job once (catch-up), never once per missed cadence."""
        results = {}
        for name in self.due( now ):
            results[ name ] = self.force( name, now )
        return results

    def force( self, name, now ):
        job = self.jobs[ name ]
        if name in self.running:
            self.log( "job.skipped", { "name": name, "reason": "running" } ); return None
        self.running.add( name ); self.log( "job.started", { "name": name } )
        started = now
        try:
            detail = job.run( now ) or {}
            ok = bool( detail.get( "ok", True ) )
        except Exception as e:
            detail, ok = { "error": repr( e ) }, False
        finally:
            self.running.discard( name )
        self.last_run[ name ] = now
        self.log( "job.finished", { "name": name, "ok": ok, "duration_ms": 0, "detail": detail } )
        return ok


# ---------------------------------------------------------------- the memento verify

def memento_due( rows, newest_record_at, max_age_hours=24 ):
    """Personas whose last turn is more than `max_age_hours` newer than their newest
    memento record (or who have turns and no record at all). Pure."""
    due, limit = [], timedelta( hours=max_age_hours )
    for row in rows:
        if row.get( "state" ) == "closed" or not row.get( "last_turn_at" ): continue
        record = newest_record_at.get( row[ "persona_id" ] )
        if record is None or row[ "last_turn_at" ] - record > limit: due.append( row[ "persona_id" ] )
    return due
```
