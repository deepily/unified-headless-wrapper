## 2. What the engine itself exempts (ruling 1)

The rule of framework Section 4.1 excuses a name that means the Claude engine. Three kinds of name do, and no fourth:

| Exemption | Names | Why |
|---|---|---|
| The Claude adapter | the kernel's `claude` adapter; the sender address `claude.code@<project>.deepily.ai#<persona_id>` (D42, `sender_id` names the engine) | a persona on Claude is truthfully addressed so; 131 occurrences in 38 surviving files, none of them this item's |
| The Claude job family | `ClaudeCodeJob`, `ClaudeCodeDispatcher`, `cosa/agents/claude_code/`, `cosa/orchestration/claude_code/`, the stored job type `claude_code`, job identifiers beginning `cc-` (`job.py:678`), the two `claude code job …` keys, the `/api/claude-code/…` tombstones | the job launches Claude Code by name; its type is stored in rows; 118 occurrences in 20 files |
| The vendor's own names | `CLAUDE_CODE_…` environment variables, `~/.claude` | not ours to rename |

`cc-` as a job-identifier prefix is the one place the two letters survive on purpose. A name outside the three is renamed on the clock its family has below.

## 5. The listener socket name (ruling 4)

## 9. Internal and browser names, and the ratchet (ruling 8)

What no family above claims (roughly half of the survivors: Python and TypeScript identifiers, constants such as `CC_CONSOLE_…`, 19 style classes, about thirty element identifiers, two browser-storage keys) is renamed when its file is touched for another reason. No rename-only change is required and none is forbidden.

**The ratchet.** At the Switch, the inventory's `survivors_files_occurrences` is recorded as the ceiling. From then on a lupin check runs `t38_naming_inventory.sh <checkout> --ceiling <number>` (or the same count in a test) and fails when the survivors' occurrences exceed it; a change that lowers the count lowers the ceiling in the same commit. `engine_neutral_names.py`:

```python
"""Engine-neutral naming (T38 -> D71): the reference implementation. Python 3, no dependencies.

One pattern says what an engine's name inside an identifier looks like; the rest are the ten rulings as
functions: what is exempt (1), the replacement words (2), the configuration keys (3, 5), the listener socket
name (4), the transcript family (5), the broadcast route (6), host-held names (7), the ratchet (8), the
kernel package scan (9), and which files the rule reaches at all (10).
"""
import os
import re

# ---------------------------------------------------------------- the rule
# An engine's name inside an identifier: cc as a word-part, claude_code / claude.code / claude-code, CC_,
# ClaudeCode, Cc or CC opening a capitalized word. The same pattern as src/captures/t38_naming_inventory.sh.
ENGINE_NAME = re.compile(
    r"(?:^|(?<=[^A-Za-z0-9]))cc[_-](?=[a-z{$])"
    r"|[_-]cc[_-]"
    r"|[_-]cc(?=[^A-Za-z0-9_-]|$)"
    r"|claude[_.-]code"
    r"|(?:^|(?<=[^A-Za-z0-9]))CC_(?=[A-Z])"
    r"|_CC_"
    r"|ClaudeCode"
    r"|(?:^|(?<=[^A-Za-z0-9]))C[Cc](?=[A-Z][a-z])"
)
CONFIGURATION_KEY_WITH_ENGINE_NAME = re.compile( r"^(cc|claude code) " )
IDENTIFIER = re.compile( r"[A-Za-z0-9_.{}-]+" )


def engine_names( text ):
    """Every identifier in the text that carries an engine's name, in order, repeats kept."""
    return [ word for word in IDENTIFIER.findall( text ) if ENGINE_NAME.search( word ) ]


# ---------------------------------------------------------------- ruling 1: what the engine itself exempts
# Three exemptions and no fourth: the Claude adapter with its sender address, the Claude job family, the
# vendor's own names.
EXEMPT = (
    ( "claude adapter",  re.compile( r"^claude\.code(@|$)" ) ),
    ( "claude job",      re.compile( r"ClaudeCode(Job|Dispatcher)|^claude code job |(agents|orchestration)[./]claude_code|^claude_code(_tasks)?$|^claude\.code\.job$|^/api/claude-code/" ) ),
    ( "vendor name",     re.compile( r"^CLAUDE_CODE_[A-Z0-9_]+$|^~?/?\.claude(/|$)" ) ),
)


def exemption( name ):
    """The exemption a name falls under, or None when the name must be renamed."""
    for label, pattern in EXEMPT:
        if pattern.search( name ):
            return label
    return None


# ---------------------------------------------------------------- rulings 2, 3 and 5: configuration keys
# The words: persona (one persona's), kernel fleet (the fleet's), engine (the vendor's program in general);
# where dropping "cc session" leaves a clear name, it is dropped.
MOVED_BY_THE_SWITCH_OVER_LIST = ( "cc session fleet size cap", "cc session spawn ", "cc session skeleton crew enabled", "cc session reap memento " )


def configuration_key( key ):
    """( disposition, new name ) for one lupin-app.ini key.

    rename    the new name, at the clock key_clock() gives
    move key  already a row of the switch-over list (a kernel fleet key, named there), new name None
    exempt    the Claude job's keys, unchanged
    keep      carries no engine name
    """
    if not CONFIGURATION_KEY_WITH_ENGINE_NAME.search( key ):
        return ( "keep", key )
    if exemption( key ):
        return ( "exempt", key )
    if any( key == moved.strip() or key.startswith( moved ) for moved in MOVED_BY_THE_SWITCH_OVER_LIST ):
        return ( "move key", None )
    if key.startswith( "cc session voice persona " ) or key == "cc session worker default voice mode":
        return ( "rename", key[ len( "cc session " ): ] )
    if key.startswith( "cc transcript " ):
        return ( "rename", "persona log " + key[ len( "cc transcript " ): ] )
    raise ValueError( f"no ruling covers the configuration key {key!r}" )


def key_clock( key ):
    """When a renamed key changes: with the persona-name rewrite (ruling 3) or at Delete (ruling 5)."""
    disposition, _ = configuration_key( key )
    if disposition != "rename":
        return None
    return "delete" if key.startswith( "cc transcript " ) else "persona-name rewrite"


# ---------------------------------------------------------------- ruling 4: the listener socket name
NEW_LISTENER_PREFIX = "persona-listener-"
OLD_LISTENER_PREFIX = "cc-listener-"   # in the kernel: one constant in lupin_compat.py until the move, then gone
CLOCKS = ( "phase 1", "move", "switch", "delete" )


def accepted_listener_prefixes( clock ):
    """What Lupin accepts: the old name alone until the move, both through the soak, the new alone after Delete."""
    index = CLOCKS.index( clock )
    if index == 0:
        return ( OLD_LISTENER_PREFIX, )
    if index == len( CLOCKS ) - 1:
        return ( NEW_LISTENER_PREFIX, )
    return ( NEW_LISTENER_PREFIX, OLD_LISTENER_PREFIX )


def is_listener_session( session_id, clock = "move" ):
    """The one helper that replaces Lupin's six prefix tests: a persona's socket, or a browser's?"""
    return any( session_id.startswith( prefix ) and len( session_id ) > len( prefix ) for prefix in accepted_listener_prefixes( clock ) )


def listener_persona_id( session_id, clock = "move" ):
    """The persona id a listener session name carries, or None for a browser session."""
    for prefix in accepted_listener_prefixes( clock ):
        if session_id.startswith( prefix ) and len( session_id ) > len( prefix ):
            return session_id[ len( prefix ): ]
    return None


def listener_session_name( persona_id, clock ):
    """The name the kernel connects under: the old one against an unmodified Lupin, the new one from the move."""
    return ( OLD_LISTENER_PREFIX if clock == "phase 1" else NEW_LISTENER_PREFIX ) + persona_id


# ---------------------------------------------------------------- rulings 5 and 6: the wire
# The transcript family changes whole, at Delete; the broadcast route at the switch-over.
WIRE = {
    "/api/cc-transcript/{cc_session_id}":      ( "/api/persona-log/{persona_id}",  "delete" ),
    "/api/cc-transcript-roster":               ( "/api/persona-log-roster",        "delete" ),
    "cc_transcript_watch":                     ( "persona_log_watch",              "delete" ),
    "cc_transcript_unwatch":                   ( "persona_log_unwatch",            "delete" ),
    "cc_transcript_state":                     ( "persona_log_state",              "delete" ),
    "cc_transcript_append":                    ( "persona_log_append",             "delete" ),
    "cc_session_id":                           ( "persona_id",                     "delete" ),
    "/api/commons/broadcast-to-cc-sessions":   ( "/api/commons/broadcast",         "switch" ),
}


def wire_name( name, clock ):
    """The name on the wire at a clock: the old one until its clock arrives, the new one from then."""
    if name not in WIRE:
        return name
    new_name, at = WIRE[ name ]
    return new_name if CLOCKS.index( clock ) >= CLOCKS.index( at ) else name


# ---------------------------------------------------------------- ruling 7: names the hosts hold
HOST_HELD = {
    "notification-api-claude-code-dev": "when the shared key is next rotated or replaced",
    "LUPIN_CC_VENV":                    "when the hooks tree is deleted",
    "CC_VENV":                          "when the hooks tree is deleted",
}


# ---------------------------------------------------------------- ruling 8: the ratchet
def ratchet( occurrences, ceiling ):
    """( passes, new ceiling ): a count above the ceiling fails; a count below it lowers the ceiling."""
    return ( occurrences <= ceiling, min( occurrences, ceiling ) )


# ---------------------------------------------------------------- rulings 9 and 10: the kernel package scan
# Naming-1. Two entries and no third: the listener constant in the boundary module, the Claude adapter.
ALLOWED = {
    "lupin_compat.py":   ( OLD_LISTENER_PREFIX, ),
    "engines/claude.py": ( "claude.code", "CLAUDE_CODE_", ".claude" ),
}
SCANNED_SUFFIXES = ( ".py", ".sh", ".ini", ".json", ".toml", ".service" )   # code; documentation is history (ruling 10)


def violations_in( relative_path, text, allowed = ALLOWED ):
    """Engine names in one file of the kernel package that its allow-list entry does not cover."""
    permitted = allowed.get( relative_path.replace( os.sep, "/" ), () )
    found = []
    for line_number, line in enumerate( text.splitlines(), start = 1 ):
        for name in engine_names( line ):
            if not any( literal in name for literal in permitted ):
                found.append( ( relative_path, line_number, name ) )
    return found


def scan_package( root, allowed = ALLOWED ):
    """Naming-1: every violation under a package root, tests included (ruling 10: tests follow their code)."""
    found = []
    for directory, _, files in sorted( os.walk( root ) ):
        for file_name in sorted( files ):
            if not file_name.endswith( SCANNED_SUFFIXES ):
                continue
            path = os.path.join( directory, file_name )
            with open( path, encoding = "utf-8", errors = "replace" ) as handle:
                found.extend( violations_in( os.path.relpath( path, root ), handle.read(), allowed ) )
    return found
```
