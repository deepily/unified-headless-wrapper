# T23 · Context exhaustion: the engine's ceiling, the lines, the pressure re-spin, `watch.pressure` and `watch.compacted`

**As of:** 2026-11-09 · **Status:** ruled as **D57** (seven rulings, one click each; three re-put after the research step) · **Narrative:** `../narratives/2026.11.09-t23-context-exhaustion.md` (Claude doc `https://claude.ai/artifact/CTcmaVqHBQRwGL3oaD6MGF`) · **Framework:** Sections 5.1, 11.2, 14, 16, 18, 19, 20

## 1. Why this item changed shape in the session

T23 was a *measure* item: "what the engine does when its window fills; the context-pressure threshold that triggers a memento respin and writes `watch.pressure`". The first draft of the narrative proposed a capture that fills a one-million-token window on each engine and model. Rick ruled that a research step precedes any capture that burns context, since the behaviour might already be documented. It was. The design below rests on that record and the capture shrank to a confirmation.

## 2. The public record on `agy` (read 2026-11-09)

| Fact | Source |
|---|---|
| The Antigravity CLI auto-compacts at a fixed ceiling of about **256,000 tokens** whatever the model. Google staff, 2026-11-04 and 11-06: a fixed default, not user-configurable, chosen for latency, reliability and token efficiency. Users' session databases show `max_context_tokens = 256000`; 276 compactions had a median pre-compaction context of 255,070 (p10 247,360, p90 255,874) and a median post-compaction context of 45,304; a 94-turn run on agy 1.3.5 compacted at 276,110 and 249,867 prompt tokens down to 17,336 and 15,363 | forum thread 198430; `antigravity-cli` issues 878 and 1245 |
| The ceiling cannot be moved: `AGY_CLI_AUTO_COMPACT_OVERRIDE` is compiled out; a `contextWindow` setting is dropped for every model but one Gemini model; the disassembly shows `min(calculated, 256000)` in `cortex/utils.GetCheckpointConfig`. A third-party binary patch exists and does not survive self-update; not an option for a fleet host | forum 198430; `force-agy-cli-1m` |
| Compaction is **visible in the stream**: `checkpoint` is an observed `step_type` of `step_update`; `usage` rides `agent_response` and `checkpoint` steps ("per-step token usage, when known"); users' logs show the `checkpoint` step with no usage for the summary call. The resumed conversation opens under a marker beginning `# Resuming from a compaction` | headless reference (antigravity.google/docs/cli/headless); issue 1245 |
| **Occupancy** is `input_tokens + cache_read_tokens` of the newest `agent_response` step: the measured figures are stated as cached plus input (263,524 + 12,586 = 276,110). `result.usage` is cumulative across the session | issue 1245; headless reference |
| A compaction stalls the turn about **70 s** (median of 22; 35 to 224 s, one 602 s) and discards the prompt cache | issue 1245 |
| A second, silent **pre-flight truncation** may exist (`truncation_reason = 2` in the session database, no summary, no marker). Inferred by one contributor, unconfirmed | issue 1245 |
| Per-request records live in the engine's own session database `~/.gemini/antigravity-cli/conversations/<session-id>.db`, rows `ContextWindowMetadata` with `max_context_tokens` | issue 1245 |
| Nothing public states the window AGY grants a Claude model; the 256,000 clamp is an upper bound for every model | forum threads 135233, 132736 |
| Jetski has no public record; same binary family, frame vocabulary and `~/.gemini` layout as AGY | this spec |
| Claude Code compacts near the top of its effective window and marks it (`compact_boundary`) | lupin `2026.06.08-mementos-vs-compaction.md` |

**Consequence.** Rick's halfway line (500,000 on a one-million window, 2026-08-13) is unreachable on AGY: the engine compacts first, every time, and the memento would always be written from a summary. The lines are therefore ratios of the **engine's ceiling**, not the model's window; and there is no emergency interrupt, because reaching the ceiling on AGY is a stall and a summary, not a failure.

## 4. Configuration

Kernel config (`~/.lupin/kernel/config.ini`), two new sections. Values are the public record's until C19's verdict file replaces them.

```ini
[context windows]
; engine:model = window_tokens, ceiling_tokens   (ceiling = where the engine compacts on its own)
agy:fable-5.1-high        = 1000000, 256000
agy:opus-5.5-high         = 1000000, 256000
agy:gemini-3.8-flash-high = 1048576, 256000
jetski:fable-5.1-high     = 1000000, 256000
jetski:opus-5.5-high      = 1000000, 256000
claude:claude-fable-5-1   = 1000000, 987000     ; effective window minus the 13k auto-compact reserve (lupin research); C19c refines
claude:claude-opus-5-5    = 1000000, 987000

[context pressure]
notice ratio 1m class     = 0.40
respin ratio 1m class     = 0.50
notice ratio 200k class   = 0.60
respin ratio 200k class   = 0.75
class boundary tokens     = 500000      ; ceiling at or above → 1m class
compaction drop fraction  = 0.50        ; implicit compaction: occupancy falls by more than this fraction of the previous value
```

Persona manifest (optional):

```yaml
pressure:
  action: respin            # respin | advise
  respin_ratio: 0.75        # overrides the class value for this persona
  compaction_action: none   # none | interrupt
```

## 5. The detector (session task)

```python
# pressure.py — evaluated by the session task on every normalized `usage` event. No timer, no poller.
from dataclasses import dataclass

@dataclass
class Pressure:
    occupancy_tokens : int | None
    window_tokens    : int | None
    ceiling_tokens   : int | None
    ratio            : float | None
    status           : str            # ok | notice | over_budget | unknown

def occupancy_from_usage( engine, usage ):
    """Ensures: the prompt size of the newest model call, never a cumulative figure (Jetski family result.usage is skipped by the adapter)."""
    if engine == "claude":
        return usage.input + usage.cache_creation + usage.cache_read
    return usage.input_tokens + usage.cache_read_tokens            # Jetski family agent_response DONE step

def lines_for( ceiling, config, manifest ):
    cls = "1m" if ceiling >= config.class_boundary_tokens else "200k"
    notice = config.notice_ratio[ cls ]
    respin = manifest.pressure.respin_ratio or config.respin_ratio[ cls ]
    return notice, respin

def assess( session, usage, now ):
    row = session.config.context_windows.get( ( session.engine, session.model ) )
    if row is None:
        return Pressure( None, None, None, None, "unknown" )            # narrated once at spawn as pressure.window_unknown
    occ    = occupancy_from_usage( session.engine, usage )
    ratio  = occ / row.ceiling_tokens
    notice, respin = lines_for( row.ceiling_tokens, session.config.pressure, session.manifest )
    status = "over_budget" if ratio >= respin else "notice" if ratio >= notice else "ok"
    p = Pressure( occ, row.window_tokens, row.ceiling_tokens, ratio, status )
    session.registry.pressure = { "ratio": ratio, "status": status, "measured_at": now() }

    # implicit compaction: a drop of more than half with no kernel respawn between two model calls
    prev = session.last_occupancy
    if prev and not session.respawned_since( prev ) and occ < prev * ( 1 - session.config.pressure.compaction_drop_fraction ):
        on_compacted( session, before=prev, after=occ, explicit=False )
    session.last_occupancy = occ

    # one record per upward crossing per line; the respawn resets session.crossed
    for line, threshold in ( ( "notice", notice ), ( "respin", respin ) ):
        if ratio >= threshold and line not in session.crossed:
            session.crossed.add( line )
            action = "none"
            if line == "respin":
                action = session.manifest.pressure.action                      # respin | advise
            log( "watch.pressure", persona_id=session.persona_id, turn_id=session.turn_id, occupancy_tokens=occ,
                 window_tokens=row.window_tokens, ceiling_tokens=row.ceiling_tokens, ratio=round( ratio, 4 ),
                 line=line, action=action, model=session.model, source=usage.source )
            if line == "respin":
                if action == "respin":
                    session.kernel.schedule( respin, session.persona, trigger="pressure" )   # D54 handshake; waits for turn end
                session.kernel.narrate_chain( session.persona, type="info",
                    text=f"{session.persona.name} is at {ratio:.0%} of its {row.ceiling_tokens:,}-token ceiling; "
                         + ( "re-spinning at turn end." if action == "respin" else "re-spin advised." ) )
    return p

def on_checkpoint_step( session, step ):
    """The adapter lifts a Jetski-family `checkpoint` step (or a Claude compact_boundary) here."""
    on_compacted( session, before=session.last_occupancy, after=None, explicit=True, stall_seconds=step.duration_seconds )

def on_compacted( session, before, after, explicit, stall_seconds=None ):
    log( "watch.compacted", persona_id=session.persona_id, turn_id=session.turn_id,
         before_tokens=before, after_tokens=after, explicit=explicit, stall_seconds=stall_seconds )
    session.crossed.clear()                                                      # the lines are re-armed; the next climb is a new crossing
    session.kernel.inbox.write_kernel_block( session.persona, "memento",
        "Your engine compacted its context. At your next safe checkpoint, write your memento (memento_io.py write --slot io).",
        urgent=False )
    session.kernel.narrate_chain( session.persona, type="info", text=f"{session.persona.name}'s engine compacted its context." )
    if session.manifest.pressure.compaction_action == "interrupt":              # only for a model C19 shows to fail at the edge
        session.kernel.interrupt( session.persona, reason="pressure_compaction" )
```

`respin.py` (T18 spec Section 9) gains one keyword: `respin( kernel, persona, now, trigger="operator" )`; `respin.requested`, `respin.rehydrated` and `respin.without_memento` carry `trigger: operator | pressure | persona`. The pressure trigger waits for the **current** turn to end before writing the request block only on engines without mid-turn input (`accepts_input_mid_turn: no`); on Claude the block is written at once and absorbed.

## 6. Records (additions to the D56 catalogue, T17 spec Section 4.6)

| Kind | `data` | Written |
|---|---|---|
| `watch.pressure` | `{ occupancy_tokens, window_tokens, ceiling_tokens, ratio, line: notice \| respin, action: none \| respin \| advise, model, source: step_update \| result \| assistant }` | once per upward crossing per line; the lines re-arm on respawn and after a compaction |
| `watch.compacted` | `{ before_tokens, after_tokens, explicit, stall_seconds? }` | the `checkpoint` step (explicit) or a drop of more than half (implicit) |
| `pressure.window_unknown` | `{ engine, model }` | once at spawn when the model is not in `[context windows]` |
| `respin.*` | gains `trigger` | every handshake |

Roster field (`GET /personas`, `GET /personas/{id}`, the registry row): `pressure: { ratio, status: ok \| notice \| over_budget \| unknown, measured_at }`. The fleet-health module and the console render it; they compute nothing. `GET /api/arbiter/context-pressure` on Lupin serves this field under its old name until the T19 rename, the same way the fleet-state projection is served.

## 7. The capture: C19 `c19_context_edge.py`

Confirms the record on Rick's binaries and fills its one gap (the ceiling for the two Claude models under each Google engine). Does not block the Phase 1 build. Invocation at the top of `src/captures/RUNBOOK.md`.

| Leg | Does | Records | Verdict lines |
|---|---|---|---|
| C19a · survey and table read | two turns ("say hi"; "read `fill-00.txt` and say hi", ~30k tokens); then reads the engine's session database for `ContextWindowMetadata.max_context_tokens` | every frame with `usage`, by step type; the four token fields; the database value | `usage carried on`, `result.usage cumulative`, `cache_read beside input`, `db max_context_tokens` |
| C19b · the edge | `fill-NN.txt` files of ~40k tokens, one turn each ("read `fill-NN.txt` with `read_file`; reply with only its first line") until the first of: a `checkpoint` step; a drop of more than half; an error frame or non-zero exit; occupancy flat for three turns; 320,000 passed. Then "what was the first line of `fill-00.txt`?" | per turn: file, occupancy, ratio, wall time, stderr; the `checkpoint` step verbatim; the recall answer | `behaviour at the edge`, `edge tokens before/after`, `stall seconds`, `recall after edge` |
| C19c · Claude parity (optional) | C19b on the dev server with `claude -p` and the D4 flags, to one million | the same plus `compact_boundary` | sets `ceiling_tokens` for `claude` |

Models: C19a on every D44 model on both engines (six short calls). C19b first on `gemini-3.8-flash-high` to prove the harness against the record's 256,000; then on the D44 models **only if** C19a's database read does not already give their ceiling. A fill is about 320,000 input tokens plus cache reads.

Verdict → config: `db max_context_tokens` or `edge tokens before` → `ceiling_tokens`; `cache_read beside input` → the adapter's `usage` normalization; `behaviour: errored | exited` → `compaction_action: interrupt` for that model; `recall: lost` with no step and no drop → silent truncation confirmed, that model's respin ratio moves down.
