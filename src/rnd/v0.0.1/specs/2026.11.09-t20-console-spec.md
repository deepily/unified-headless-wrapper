## 3. The mapper (`uhw_kernel/log/mapper.py`)

One envelope in, one block or nothing out. The caller owns the bounded `call_id → tool` index (cap 4096, as in Lupin's Claude mapper). A kernel block has role `kernel`, kind `kernel`, `name` = the record's kind, and `level`.

### 3.1 The level table (closed)

| Level | Meaning | Records |
|---|---|---|
| `alert` | someone must act, or something was refused | `gate.deny`, `gate.ask`, `gate.unreachable`, `watch.held_turn`, `watch.pressure` with `line: respin`, `session.resume_mismatch`, `session.exited` with `expected: false`, `respin.without_memento`, `ask.escalated`, `ask.expired` |
| `notice` | worth knowing, nothing to do | `watch.pressure` with `line: notice`, `watch.compacted`, `session.interrupt`, `session.respawn`, `respin.requested`, `respin.rehydrated`, `voice.result` with `needs_repair`, `inbox.duplicate`, `inbox.rebuilt`, `log.truncated`, `ask.opened`, `ask.answered` |
| `info` | the harness narrating itself | `engine.frame[init]` (as name `engine.init`), `session.spawned`, `session.state`, `session.stopped`, `session.exited` with `expected: true`, `gate.would_deny`, `engine.stderr` |

Added to the T17 table: `ask.opened`, `ask.answered`, `ask.escalated`, `ask.expired`, `respin.requested`, `respin.rehydrated`, `respin.without_memento`, `gate.unreachable`, `gate.would_deny`, `log.truncated`. Everything else stays skipped.

### 3.2 Reference implementation

Run on a fixture on 2026-11-09 with the tests in Section 6.2; both passed.

```python
"""Kernel log record -> display block. Pure, standard library only."""
import json
ALERT, NOTICE, INFO = "alert", "notice", "info"

LEVELS = {  # closed: Console-1 fails on a level for a kind outside the catalogue
    "gate.deny": ALERT, "gate.ask": ALERT, "gate.unreachable": ALERT, "watch.held_turn": ALERT,
    "session.resume_mismatch": ALERT, "respin.without_memento": ALERT, "ask.escalated": ALERT, "ask.expired": ALERT,
    "watch.pressure": lambda data: ALERT if data.get( "line" ) == "respin" else NOTICE,
    "session.exited": lambda data: INFO if data.get( "expected" ) else ALERT,
    "watch.compacted": NOTICE, "session.interrupt": NOTICE, "session.respawn": NOTICE, "respin.requested": NOTICE,
    "respin.rehydrated": NOTICE, "inbox.duplicate": NOTICE, "inbox.rebuilt": NOTICE, "log.truncated": NOTICE,
    "ask.opened": NOTICE, "ask.answered": NOTICE,
    "voice.result": lambda data: NOTICE if data.get( "needs_repair" ) else None,
    "session.spawned": INFO, "session.state": INFO, "session.stopped": INFO, "gate.would_deny": INFO, "engine.stderr": INFO,
}

def _one_line( data, limit=200 ):
    text = " ".join( f"{key}={value}" for key, value in data.items() if key != "raw" )
    return text[ :limit ]

def text_of( data ):
    """Follow the adapter's text_at path into raw; returns (text, truncated). The mapper knows no engine's frame shape."""
    value = data.get( "raw" )
    for key in data.get( "text_at" ) or []:
        try: value = value[ key ]
        except ( KeyError, IndexError, TypeError ): return "", True     # the path fell in a record cut at 1 MiB
    if value is None: return "", False
    return ( value if isinstance( value, str ) else json.dumps( value, ensure_ascii=False ) ), False

def _block( record, role, kind, text, truncated=False, **extra ):
    return { "ts": record[ "timestamp" ], "role": role, "kind": kind, "text": text, "truncated": truncated, **extra }

def map_record( record, call_names, show_deltas=False ):
    """One envelope in; one block or None out. call_names is the caller's bounded call_id -> tool index."""
    kind, data = record[ "kind" ], record.get( "data" ) or {}
    if kind == "engine.stdin":
        return _block( record, "user", "text", *text_of( data ) )
    if kind == "engine.frame":
        event = data.get( "event_kind" )
        if event == "tool":
            call_names[ data.get( "call_id" ) ] = data.get( "tool" )
            return _block( record, "assistant", "tool_call", *text_of( data ), name=data.get( "tool" ) )
        if event == "tool_done":
            return _block( record, "assistant", "tool_result", *text_of( data ), name=call_names.get( data.get( "call_id" ) ) )
        if event == "result":
            return _block( record, "assistant", "text", *text_of( data ) )
        if event == "text":
            return _block( record, "assistant", "text", *text_of( data ), name="delta" ) if show_deltas else None
        if event == "init":
            return _block( record, "kernel", "kernel", _one_line( data ), name="engine.init", level=INFO )
        return None  # usage and anything unknown: skipped
    level = LEVELS.get( kind )
    if callable( level ): level = level( data )
    if level is None: return None
    text = data.get( "line" ) if kind == "engine.stderr" else _one_line( data )
    return _block( record, "kernel", "kernel", text, name=kind, level=level )
```

**Where the text comes from (ruled 2026-11-09, Section 14):** the adapter records `text_at`, a path into `raw`, beside the already-lifted `call_id` and `tool`. `text_of` follows it. The mapper parses no engine's frame and no text is stored twice.

## 4. Views

```python
def visible( block, view ):
    """conversation < work < everything; an alert passes every view."""
    if block.get( "level" ) == ALERT: return True
    if block[ "kind" ] == "text" and block.get( "name" ) != "delta": return True
    if view == "conversation": return False
    if block[ "kind" ] in ( "tool_call", "tool_result" ) or block.get( "level" ) == NOTICE: return True
    return view == "everything"
```

| View | Shows |
|---|---|
| `conversation` | user and assistant text, alerts |
| `work` (default) | adds tool calls, tool results, notices |
| `everything` | adds info lines, stderr (folded), deltas when `persona log show deltas` is on |

The view is applied by the reader. The tailer, the wire and the byte offsets are untouched; a switch re-renders loaded blocks with no request.

## 5. Style

| Level | Web (`[data-kind="kernel"][data-level=…]`) | Colour terminal | Not a terminal |
|---|---|---|---|
| `info` | dim monospace row, grey left rule | dim | plain |
| `notice` | dim monospace row, amber left rule | yellow | plain |
| `alert` | full-contrast monospace row, red left rule | bold red | plain |

Row text: time, `name`, one line. The `│` gutter and the name carry the meaning, so nothing depends on colour. Consecutive `engine.stderr` blocks fold into one row, "stderr × N": a `<details>` on the web; a counted row in the terminal.

Pressure uses the same amber and red: `ok` no colour, `notice` amber, `over_budget` red, `unknown` grey with a question mark. The ratio is printed as a number beside it. No reader computes a colour from the ratio.

## 6. `lupin persona watch <id> [view]` (Phase 1, with Kernel-3)

Runs on the kernel's host. Reads `log_dir` from `GET /personas/{id}`, follows segments in lexical order, hops when a newer segment exists, prints through the mapper and the view. No credential, no terminal library.

### 6.1 Reference implementation

```python
"""lupin persona watch <id>: read-only tail of a persona's log through the mapper."""
import http.client, json, os, socket, sys, time
from pathlib import Path
from mapper import map_record, visible

COLOUR = { "info": "\033[2m", "notice": "\033[33m", "alert": "\033[1;31m" }

class UnixConnection( http.client.HTTPConnection ):
    def __init__( self, path ): super().__init__( "kernel" ); self.path = path
    def connect( self ): self.sock = socket.socket( socket.AF_UNIX ); self.sock.connect( self.path )

def log_dir( persona_id, socket_path ):
    connection = UnixConnection( socket_path ); connection.request( "GET", f"/personas/{persona_id}" )
    return Path( json.load( connection.getresponse() )[ "log_dir" ] )

def records( directory, poll=0.25, follow=True ):
    """Yield every record, oldest segment first; hop when a newer segment appears."""
    done = set()
    while True:
        segments = sorted( path for path in directory.glob( "*.jsonl" ) if path not in done )
        if not segments:
            if not follow: return
            time.sleep( poll ); continue
        current = segments[ 0 ]
        with current.open() as handle:
            while True:
                line = handle.readline()
                if line.endswith( "\n" ): yield json.loads( line ); continue
                newer = any( path > current for path in directory.glob( "*.jsonl" ) )
                if newer or not follow: break          # a partial last line is left for the writer to finish
                handle.seek( handle.tell() - len( line ) ); time.sleep( poll )
        done.add( current )

def render( block, colour ):
    clock = block[ "ts" ][ 11:19 ]
    if block[ "kind" ] == "kernel":
        row = f"{clock} │ {block[ 'name' ]:<18} {block[ 'text' ]}"
        return f"{COLOUR[ block[ 'level' ] ]}{row}\033[0m" if colour else row
    mark = { "tool_call": "▸", "tool_result": "◂" }.get( block[ "kind" ], "you:" if block[ "role" ] == "user" else "said:" )
    return f"{clock} {mark} {block.get( 'name' ) or ''} {block[ 'text' ]}".replace( "  ", " " )

def watch( directory, view="work", follow=True, out=sys.stdout ):
    call_names, stderr_run, colour = {}, 0, out.isatty()
    def flush():
        nonlocal stderr_run
        if stderr_run and view == "everything": print( f"         │ stderr × {stderr_run}", file=out )
        stderr_run = 0
    for record in records( directory, follow=follow ):
        block = map_record( record, call_names )
        if block is None or not visible( block, view ): continue
        if block.get( "name" ) == "engine.stderr": stderr_run += 1; continue
        flush(); print( render( block, colour ), file=out, flush=True )
    flush()

if __name__ == "__main__":
    socket_path = os.environ.get( "LUPIN_KERNEL_SOCKET", os.path.expanduser( "~/.lupin/kernel/kernel.sock" ) )
    watch( log_dir( sys.argv[ 1 ], socket_path ), view=sys.argv[ 2 ] if len( sys.argv ) > 2 else "work" )
```

## 7. The interactive console (`lupin console <id>`, after Kernel-8)

### 7.1 Where it runs and what it connects to

It runs on Rick's laptop, never on a fleet host.

| Connection | Carries | How |
|---|---|---|
| Kernel socket | roster, `GET /personas/{id}`, `POST /personas/{id}/messages`, respin, stop | SSH Unix-socket forward: `-L <local.sock>:<remote ~/.lupin/kernel/kernel.sock>`, through IAP on the test VM |

| Lupin | ticket answers, as Rick | the existing tunnel to `:7999`, `Authorization: Bearer <access token>` |

**Rick's token never passes through the kernel socket or the SSH command line.** The kernel runs as the persona account; a persona with root could read it from the kernel's memory.

### 7.2 Layout (`prompt_toolkit` with `patch_stdout`)

History scrolls into normal terminal scrollback. Two fixed lines sit above the prompt.

```
12:04:07 │ gate.ask   git push origin main  (rule branch_lock, ticket 7f3a)
12:04:07 ▸ ask_wait( 7f3a )

said: "Nothing is pushed yet. I need your go-ahead for main."
María · a1b2c3d4 · agy fable-5.1-high · awaiting human · pressure 0.61 notice · queue 0 · 1 ticket
> _
```

| Line | Source |
|---|---|
| Mirror | the newest of `voice.result` (the spoken line, prefix `said:`) and `inbox.received` from a human (prefix `heard:`) |
| Status | the roster row: display name, `persona_id`, engine and model, state, `pressure.ratio` and `pressure.status`, queue length; the count of `ask.opened` without a later `ask.answered`, `ask.expired` or `ask.escalated` |

### 7.3 Input grammar

| The line begins | What happens |
|---|---|
| anything else | `POST /personas/{id}/messages { text, urgent: false }`; logged `channel: console` |
| `!` | the console prints the open call's tool and age ("interrupting read_file, open 41 s"), then posts `urgent: true` |
| `/name` | sent verbatim; it is a skill for the persona (D52) |
| `:` | a console command, never sent |

A lone `!` or `:` is refused with the help line. A message that must begin with `:` or `!` takes a leading space.

| Command | Does |

| `:stop` | `DELETE /personas/{id}` after a typed confirmation |

## 8. The credential on the laptop

- The console logs in to the Lupin instance interactively once and keeps the refresh token (7 days on the test instance) in the laptop's operating-system keychain; the access token (30 minutes) is held in memory and refreshed as needed.
- The keychain is a proposal, not a tested mechanism. On macOS it would be the login keychain through the `keyring` package; nothing has been built.
- The token is sent only to Lupin, only for acts that must be Rick's. In this specification that is ticket answers and nothing else.
- D50's invariant stands unchanged and is now understood narrowly: no `[owner]` section on a host that runs personas.

## 9. Tickets (after the ticket store lands in lupin)

- An open ticket is an `alert` row (`gate.ask` or `ask.opened`) and a count on the status line, on every reader.
- `lupin persona watch` on the host shows tickets and cannot answer them.
- `:answer <ticket> <reply>` on the laptop console posts to Lupin's ticket route with Rick's token. The kernel learns of it the way it learns of any answer, from Lupin.
- A plain typed line while a ticket is open goes to the persona as a message. It is never taken as an answer.
- Until the ticket store exists, `:answer` replies "tickets are answered on the web or the phone for now".
