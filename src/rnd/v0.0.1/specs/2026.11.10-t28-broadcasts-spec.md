## 2. Addressing at the door

### 2.1 Grammar

```
mention      := "@" name
name         := single_token | multi_word ":"          ; the colon ends a name that holds spaces
single_token := one run of characters with no whitespace, "@", ":" or sentence punctuation
multi_word   := any characters except "@", ":" and newline, trimmed      ; `@mr radio:`
all          := "@all" | "@everyone"
```

- Mentions are read over the **whole message**. The set of names is the recipient set.
- `all`, or **no mention at all**, means every live persona. `all` beside names still means all (the names are then ordinary prose).
- A general notice plus a directive to one persona is two broadcasts.
- A colon form consumes its span so its words are not re-read as single tokens. A trailing period on a single token is not part of the name.

### 2.2 Resolution

The door resolves each name against the kernel roster (live personas: running or hibernated) with `normalize_name` (Section 9): case folded, accents stripped, runs of space, underscore, hyphen and period collapsed to one space. `Mr. Radio`, `mr_radio`, `MR-RADIO` and `@mr radio:` are one name. A name that matches no roster entry, or more than one, refuses the whole broadcast:

```
422 { "error": "unresolved_addressee", "tokens": ["cheech"], "live_personas": ["María", "Mr. Radio", "Tiberius"] }
```

Nothing is delivered on a refusal. The sender is a human at a client and fixes the message. This replaces the listener's bias toward delivery, which existed because the receiving end had no channel back to the sender; the door has one. The 200 body gains `recipients: [ persona_id, … ]` beside `broadcast_id`.

**Dependency (T35, on the record 2026-11-10):** `normalize_name` is an interim rule. Rick's requirement: one global normalization for names with characters outside `[a-zA-Z]` (accents, spaces, dashes, underscores, periods), ruled once under T35 and used by the door, the DM router, the voice-persona pool and the memento writer alike. Until then the door uses the function in Section 9 and the lupin matcher's case- and punctuation-tolerant comparison is retired with the listener.

### 2.3 Who may broadcast

Unchanged: a JWT or API-key caller of the door. Lupin's own restart warning and all-clear are authored as the fleet user and carry `from: lupin`; a human caller carries `from: human`. The rate limit (one per user per 30 s, per process) is unchanged. The per-recipient `broadcasts` topic entry is unchanged.

## 3. The block

### 3.1 Grammar (D52 Section 3.1 amended)

```
kind   := "voice" | "dm" | "answer" | "kernel" | "broadcast"
attrs  := … | " from " ("human" | "lupin") " id " id8 " to " ("all" | id8 ("," id8)*)   ; broadcast
```

`id` is the 8-hex head of the door's `broadcast_id` (a UUIDv4), so a persona can name it in prose and the acknowledgment correlates. `to` lets a persona know whether its peers saw the same text. The body is the message as typed, under the D52 forgery rule (a line that would parse as a header is indented by one space; nothing is cut). No divergence notice: every recipient holds the whole message.

```
[broadcast 13:02:10 from human id 3f2a9c1e to all]
⚠️ :7999 is bouncing in five minutes. Hold notifications and blocking asks until the all-clear.

[broadcast 13:40:05 from human id 8b1e77c2 to a1b2c3d4,9c1d4b77]
@maria @mr radio: the schema diff is in io/commons/schema-diff.md. María owns the migration, Mr. Radio reviews it.
```

### 3.2 Contract text (one sentence added to D52 Section 3.5, every engine, verbatim)

> `[broadcast … from … to …]` is one message sent to several personas at once, by the human or by the Lupin application; `to` names who else received it. Act on anything in it that names you; it needs no reply unless it asks for one, and a reply to it is not spoken.

### 3.3 Type (`InboundMessage`, D52 Section 3.6, three fields added)

```python
    broadcast_id: str | None = None        # broadcast: 8-hex head of the door's UUID
    broadcast_from: str | None = None      # human | lupin
    broadcast_to: tuple[str, ...] | None = None   # () means all
```

`kind` gains the value `broadcast`. `channel` stays `None` for a broadcast.

### 3.4 Where it sits in the flow (framework Section 6 diagram)

The first test, "`user_initiated_message` for a registered job id?", becomes `admit()` (Section 9): a registered persona's notification is taken when it is a human message, an `action:` title, or carries an admitted `payload.kind`. `action:broadcast_received` enters the queue path like a peer DM: never interrupts, written now on an engine that accepts mid-turn input (Claude), queued otherwise, merged in arrival order.

## 4. Receipt and acknowledgment

Order per broadcast, the D52 order with one step added: **stdin write → ledger append → acknowledgment entry → receipt.** The acknowledgment is written by the kernel, never by the model. A replayed `broadcast_id` already in the ledger is dropped and logged `inbox.duplicate`, as any id.

The entry (Lupin's shape, so `CommonsAckWatcher` and the restart script's `poll_acks_until_satisfied` read it unchanged):

```
## <iso ts> | <persona name> <icon> #<persona_id>
**metadata**: `{"kind":"ack","broadcast_id":"<uuid>","status":"completed","body_summary":"<first 200 chars>","_persona_color":…,"_session_id":"<persona_id>"}`

completed
```

- Statuses: `completed` (written to stdin), `deferred` (queued for a hibernated persona, `deferred_reason: hibernated`). A deferred broadcast is acknowledged again as `completed` when it is written on wake; the watcher's dedupe key `(broadcast_id, sender, status)` yields two rows, which is the record wanted.
- **Phase 1:** a forty-line writer in the kernel (`lupin.root/io/commons/broadcast-acks.md`, `fcntl.flock`, `ENTRY_SEPARATOR`, frontmatter on an empty file), the one place the kernel writes a Lupin-owned file before the move; it is listed in the D29 partition as an interim. **After the move (D38):** `CommonsStore.post`.
- The door's `<system-reminder>` tag check stays; it costs nothing and guards the Claude engine, whose stdin would otherwise take the tag as real.

## 5. Hibernated addressees (D59 Section 10.5 extended)

| The persona is | Broadcast `to` | Action | Acknowledgment |
| --- | --- | --- | --- |
| running | any | write now or queue (Section 3.4) | `completed` at the write |
| hibernated | names it | wake (D59 wake path; a reservation re-acquired under D60, deferred when there is none); the envelope is the first turn | `completed` at the write |
| hibernated | `all` | queue; written on the next wake, whatever causes it | `deferred` now, `completed` later |

A restart warning to all reaches a hibernated persona after the restart it warned about. That is harmless: a hibernated persona holds no in-flight call, and the all-clear arrives in the same envelope.

## 6. The turn's result

When every block in an envelope is a `broadcast`, the kernel posts the one D13 result notification with `priority: low` and `suppress_ding: true`; the voice client speaks nothing, the card and the record keep the reply. A mixed envelope (a broadcast beside a voice or DM block) is posted as its other blocks require. The persona's `notify` calls during the turn are untouched: work a broadcast causes is narrated as usual (D28). `voice.result` gains `broadcast_only: true | false`.

## 7. The DM tutor's two signals

### 7.1 The rewrite (Decision 6; a D55 addendum, Section 18 dm row)

`POST /api/dm/send` 201 gains `rewrite`, the same object D55 stamps on the delivered message: `{ applied, rule_version, chars_before, chars_after, outcome }`; absent when no rewriter ran. The `dm_send` tool wrapper appends one line to its result when `applied` is true: `delivered as a rewrite (1,412 to 388 characters); dm_get shows the delivered text.` The trigger height is still never disclosed.

### 7.2 The grade (Decision 7)

**Finding, to confirm before the Lupin change:** `push_dm_grade_to_sender` pushes `type: task`; the terminal listener accepts only `user_initiated_message` (the type filter precedes the direction check), so no seat has received a grade since 2026-08-19. Check on the development server, zero tokens: `grep -rl 'grade for DM' ~/.claude/projects/` across the seats' transcripts; empty confirms.

Lupin side (Section 18 dm row): the push carries `payload: { kind: "dm_grade", message_id, recipient_persona_id, quality }` and no sender persona; `_DM_GRADE_SENDER_ID`, `_DM_GRADE_PERSONA`, `_DM_GRADE_ICON` retire; `type: task` stays.

Kernel side:

- `admit()` takes a registered persona's notification whose `payload.kind` is in `[inbox] admitted payload kinds` (default `dm_grade`). Everything else of type `task` is dropped, as today.
- The block: `[kernel HH:MM:SS] Grade for your DM <message_id> to <recipient name>: length +1 · directness −1 · tone — · overall +0.` A withheld dimension (weight `None`) shows as `—`. No emoji, no count of the original.
- Queued, never interrupts; written now on Claude, merged at the next turn on the Jetski family (D52 policy).
- **Runtime switch:** `[inbox] dm_grades = on | off` (default `on`) is the host default; the registry row field `inbox.dm_grades` overrides it per persona and is set through the control API (`PATCH /personas/{id}`, the route T09 names) without a re-spin; re-read at every delivery. With `off` the notification is logged `inbox.received` and dropped (`inbox.suppressed { kind: dm_grade }`), never queued.
- **Measurement:** `inbox.written` records the block's `kind` list and `dm_grades` as it stood; the corpus row and the sender's `gate.allow` records of `dm_send` carry the message id. The effect of a delivered grade on a sender is a join: that sender's `tutor_words_in` and `tutor_outcome` before and after its first `inbox.written` carrying a `dm_grade`, against personas running `off` as the control. No new record is needed for the join.

## 8. The two remaining actions

- `action:set_session_topic` → the kernel sets `topic` on the persona's registry row (`registry.updated { field: topic }`); the roster and the console show it; no inbox write. The bridge-file write retires with the bridge files (T31).
- `action:disable_speakerphone` → not carried. D28: speech is a client-side decision by priority and sender; the persona's notify rules are the format layer (D53); nothing is left to tell the engine. `_inject_exit_conversation_reminder`, `speakerphone_exit_reminder` and the route's injection in `routers/speakerphone.py` are deletion-list rows (T19). A per-session quiet mode, if wanted again, is a format-rules change, not a message.

## 9. Reference implementation (runs; eight tests pass on 2026-11-10)

`broadcast.py` — standard library only.

```python
"""broadcast.py — system broadcasts and application notices (D61, T28).

Standard library only. Pure functions; the kernel wires them to the socket,
the ledger, the engine's stdin and the acknowledgment file.

Four jobs:
  1. addressing at the door   : parse_addressees, normalize_name, resolve
  2. the inbox block           : render_broadcast_block, render_grade_block
  3. delivery decisions        : delivery_action, broadcast_only, admit
  4. the acknowledgment entry  : ack_entry

Lupin house style: spaces inside parentheses, Requires/Ensures docstrings.
"""

import re
import unicodedata
from dataclasses import dataclass, field
from typing import Dict, Iterable, List, Optional, Tuple

ALL_ALIASES            = ( "all", "everyone" )
ACK_SUMMARY_CHARS      = 200
ADMITTED_PAYLOAD_KINDS = ( "dm_grade", )

# `@mr radio:` — a colon-delimited name that may hold spaces (Rick, 2026-11-10).
# `@maria`     — a single token, ended by whitespace or sentence punctuation.
_COLON_FORM  = re.compile( r"@([^\s@:][^@:\n]*?):" )
_SINGLE_FORM = re.compile( r"@([^\s@:,;!?()\[\]]+)" )
_HEADER_LIKE = re.compile( r"^\[(voice|dm|answer|kernel|broadcast|inbox)\b" )


@dataclass( frozen=True )
class Addressing:
    all   : bool
    names : Tuple[ str, ... ]


@dataclass( frozen=True )
class Recipients:
    all         : bool
    persona_ids : Tuple[ str, ... ]


class Unresolved( ValueError ):
    """A token matched no roster name, or more than one. The door answers 422 with this."""

    def __init__( self, tokens : List[ str ], roster_names : List[ str ] ):
        self.tokens       = list( tokens )
        self.roster_names = list( roster_names )
        super().__init__( f"unresolved: {', '.join( tokens )}; live personas: {', '.join( roster_names )}" )


def normalize_name( name : str ) -> str:
    """
    Interim normalization until T35 rules the canonical persona name.

    Requires:
        - name is a string

    Ensures:
        - case-folded, accents stripped (NFKD, combining marks removed),
          runs of space / underscore / hyphen / period collapsed to one space,
          leading and trailing space removed
        - `Mr. Radio`, `mr_radio`, `MR-RADIO` and `mr radio` are equal
    """
    decomposed = unicodedata.normalize( "NFKD", name )
    stripped   = "".join( c for c in decomposed if not unicodedata.combining( c ) )
    collapsed  = re.sub( r"[\s_\-.]+", " ", stripped )
    return collapsed.strip().casefold()


def parse_addressees( text : str ) -> Addressing:
    """
    Read every `@` mention in the whole message.

    Requires:
        - text is the broadcast body as typed

    Ensures:
        - `all` is true when any mention is `@all` / `@everyone`, OR when the
          message carries no mention at all
        - `names` are the raw mention strings, colon forms first, in order,
          without duplicates; empty when `all` came from "no mention"
        - a colon form consumes its span so its words are not re-read as
          single tokens
    """
    names   : List[ str ] = [ ]
    scratch = text
    for match in _COLON_FORM.finditer( text ):
        names.append( match.group( 1 ).strip() )
    scratch = _COLON_FORM.sub( " ", scratch )
    for match in _SINGLE_FORM.finditer( scratch ):
        names.append( match.group( 1 ).rstrip( "." ) )
    unique : List[ str ] = [ ]
    for n in names:
        if n and n not in unique:
            unique.append( n )
    all_flag = ( not unique ) or any( normalize_name( n ) in ALL_ALIASES for n in unique )
    kept     = tuple( n for n in unique if normalize_name( n ) not in ALL_ALIASES )
    return Addressing( all=all_flag, names=kept )


def resolve( addressing : Addressing, roster : Dict[ str, str ] ) -> Recipients:
    """
    Turn mentions into persona ids against the kernel roster.

    Requires:
        - roster maps persona_id (8 hex) -> display name, live personas only

    Ensures:
        - `all` addressing yields Recipients( all=True, every roster id )
        - otherwise every name must match exactly one roster name after
          normalization; any miss or ambiguity raises Unresolved naming every
          offending token and the live roster. Nothing is delivered on a raise.
    """
    if addressing.all:
        return Recipients( all=True, persona_ids=tuple( roster.keys() ) )
    by_norm : Dict[ str, List[ str ] ] = { }
    for pid, name in roster.items():
        by_norm.setdefault( normalize_name( name ), [ ] ).append( pid )
    ids : List[ str ] = [ ]
    bad : List[ str ] = [ ]
    for raw in addressing.names:
        hits = by_norm.get( normalize_name( raw ), [ ] )
        if len( hits ) != 1:
            bad.append( raw )
        elif hits[ 0 ] not in ids:
            ids.append( hits[ 0 ] )
    if bad:
        raise Unresolved( bad, list( roster.values() ) )
    return Recipients( all=False, persona_ids=tuple( ids ) )


def _indent_header_lines( body : str ) -> str:
    """D52 forgery rule: a body line that would parse as a header is indented by one space; nothing is cut."""
    return "\n".join( ( " " + line ) if _HEADER_LIKE.match( line ) else line for line in body.splitlines() )


def render_broadcast_block( time_hms : str, from_kind : str, broadcast_id : str,
                            recipients : Recipients, body : str ) -> str:
    """
    One envelope block for a broadcast.

    Requires:
        - from_kind is "human" or "lupin"; broadcast_id is the 8-hex head
          of the door's UUID; time_hms is the host clock, HH:MM:SS

    Ensures:
        - header `[broadcast HH:MM:SS from human id 3f2a9c1e to all]` or
          `... to a1b2c3d4,9c1d4b77`; body verbatim under the forgery rule
    """
    to = "all" if recipients.all else ",".join( recipients.persona_ids )
    return f"[broadcast {time_hms} from {from_kind} id {broadcast_id} to {to}]\n{_indent_header_lines( body )}"


def render_grade_block( time_hms : str, message_id : str, recipient_name : str,
                        quality : Dict[ str, Dict[ str, object ] ] ) -> str:
    """
    The DM grade as a kernel block (Decision 7).

    Requires:
        - quality is the judge's dict: name -> { weight: int | None, ... }
          for length, directness, tone, overall

    Ensures:
        - a dimension whose weight is None is shown as withheld (`tone —`)
        - no emoji, no trigger height, no count of the original
    """
    def part( name ):
        weight = quality[ name ][ "weight" ]
        return f"{name} —" if weight is None else f"{name} {weight:+d}"
    dims = " · ".join( part( n ) for n in ( "length", "directness", "tone", "overall" ) )
    return f"[kernel {time_hms}] Grade for your DM {message_id} to {recipient_name}: {dims}."


def delivery_action( recipients : Recipients, hibernated : bool ) -> str:
    """
    Decision 4: a broadcast that names this persona wakes it; one to all waits.

    Ensures:
        - "write" when the persona is running
        - "wake"  when hibernated and the broadcast was addressed by name
        - "defer" when hibernated and the broadcast went to all
    """
    if not hibernated:
        return "write"
    return "defer" if recipients.all else "wake"


def broadcast_only( kinds : Iterable[ str ] ) -> bool:
    """Decision 5: true when every block in the envelope is a broadcast, so the result goes out at low priority with the ding suppressed."""
    kinds = list( kinds )
    return bool( kinds ) and all( k == "broadcast" for k in kinds )


def admit( notification : Dict[ str, object ], registered_ids : Iterable[ str ],
           admitted_payload_kinds : Tuple[ str, ... ] = ADMITTED_PAYLOAD_KINDS ) -> Optional[ str ]:
    """
    The inbox filter with its one stated exception (Decision 7).

    Ensures:
        - None when job_id is not a registered persona
        - "message"   for a user_initiated_message
        - "action"    for a title `action:<name>`
        - the payload kind (e.g. "dm_grade") when `payload.kind` is in the admitted list
        - None otherwise (type `task` with no admitted kind is dropped, as today)
    """
    if notification.get( "job_id" ) not in set( registered_ids ):
        return None
    title = str( notification.get( "title" ) or "" )
    if title.startswith( "action:" ):
        return "action"
    if notification.get( "type" ) == "user_initiated_message":
        return "message"
    payload = notification.get( "payload" ) or { }
    kind    = payload.get( "kind" ) if isinstance( payload, dict ) else None
    return kind if kind in admitted_payload_kinds else None


def ack_entry( broadcast_id : str, status : str, body : str, persona_id : str,
               persona_name : str, deferred_reason : Optional[ str ] = None ) -> Dict[ str, object ]:
    """
    The `broadcast-acks` entry the kernel appends at stdin-write time (Decision 3).

    Requires:
        - status in ( "completed", "deferred" ); nothing else survives whole-message addressing

    Ensures:
        - the same shape Lupin's ack watcher parses today: body = status,
          metadata { kind: ack, broadcast_id, status, body_summary }, plus
          `deferred_reason` ("hibernated") when deferred
    """
    assert status in ( "completed", "deferred" ), status
    summary = body if len( body ) <= ACK_SUMMARY_CHARS else body[ :ACK_SUMMARY_CHARS - 3 ] + "..."
    metadata = { "kind": "ack", "broadcast_id": broadcast_id, "status": status, "body_summary": summary }
    if deferred_reason:
        metadata[ "deferred_reason" ] = deferred_reason
    return {
        "topic"             : "broadcast-acks",
        "body"              : status,
        "sender_session_id" : persona_id,
        "persona_name"      : persona_name,
        "metadata"          : metadata,
    }
```

ROSTER = { "a1b2c3d4": "María", "9c1d4b77": "Mr. Radio", "5e6f7a8b": "Tiberius" }


def test_no_mention_means_all():
    a = parse_addressees( "Server bouncing in five minutes, hold your asks." )
