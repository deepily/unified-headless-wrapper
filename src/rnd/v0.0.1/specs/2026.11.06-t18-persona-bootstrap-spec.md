# T18 · Persona bootstrap: the kit in the worktree, the mandates file, the memento port, the first turn, the respin handshake, the provisioner

**As of:** 2026-11-06 · **Resolves:** T18 (framework Section 13) · **Ruling:** D54 (persona bootstrap), six parts, all taken as recommended on 2026-11-06 · **Source read:** `planning-is-prompting` at `9d8bf4f` and `lupin` (laptop clones, read-only) · **Narrative for cold readers:** `narratives/2026.11.06-t18-persona-bootstrap.md` · **Builds on:** D47 (launch per persona, the six layers), D51 (convention parity: the kit, the port, gate G1.5), D41 (commands become skills), D43 (instruction files in worktrees), D46 (persona id), D52 (inbox envelope), D49 (tool approval)

## 1. What this decides

Launch per persona (D47) rendered layers 1–4 and named the channels for layer 5 (project mandates) and layer 6 (the first turn) without saying what they contain. Convention parity (D51) made the kit the AGY handoff's precondition and left "T18 supplies the rules". This spec supplies them: where the kit lives for a persona, how the global mandates reach every engine with no global file, what changes in the memento writer, what the first turn is, what `lupin persona respin` does, and what installs all of it.

## 2. Rulings (D54), six parts

| # | Ruling | Why |
|---|---|---|
| 1 | **The kit is rendered into the worktree from a pinned commit.** One planning-is-prompting checkout per fleet host at `~/.lupin/kit/`, at the commit in `~/.lupin/kernel/kit.lock`. Each kit skill is a folder under `$LUPIN_SKILLS_DIR` holding `SKILL.md` (rendered wrapper) and `WORKFLOW.md` (the canonical workflow, verbatim). Project values from `<repo>/.lupin/project.yaml`, required. `kit_commit` recorded per spawn | every read is inside the workspace, so the unmeasured outside-workspace question never arises; the text a persona followed is recorded; a kit update is one lock change and a respawn |
| 2 | **Layer 5 is a kernel-rendered mandates file.** `<worktree>/.lupin/mandates.md` = kit `global/CLAUDE.md` + project `CLAUDE.md` + `CLAUDE.local.md`; it is `$LUPIN_MANDATES_FILE` on every engine. Jetski family: copied to `AGENTS.md` (D43). Claude: project files load natively, the global part is the fifth block of `--append-system-prompt`. `mandates_sha256` logged. The host's `~/.claude/CLAUDE.md` is nobody's dependency; the T11 spec's C15b conditional is withdrawn | identical text from one pinned source; no host file is load-bearing; the conditional contradicted D47's own no-global-file rule |
| 3 | **The memento writer stays, with three changes.** `memento_io.py` reads `LUPIN_PERSONA_ID` before any bridge file and refuses with neither; mirror root `$LUPIN_MEMENTO_MIRROR`, default `~/.lupin/mementos/<repo>/`; stamp key `persona_id=` replaces `session_id=`, every reader accepts both. Slots, record/pointer/mirror and the nine-element contract unchanged. No on-disk migration | the value is the same eight hex either way (D46); records and pointers stay where the harvest step, the sweep and the post-game arming expect them |
| 4 | **The kernel composes the first turn; the memento arrives as content, last.** One `[kernel first-turn …]` block: spawn line; the session-start skill expanded; the brief if any; "Prior context" with the record's full content, resolved by the kernel, with age. `memento.rehydrated` logged | Convention-1 becomes a mechanism; the heading says content and carries content; the kernel logs what was rehydrated; the task leads, the memento follows (lupin's standing directive) |
| 5 | **Respin is a kernel handshake.** `lupin persona respin <id>` sends a `[kernel respin …]` block, waits for turn end within `respin.timeout` (600 s), looks for a record stamped with this persona id and newer than the request; found → respawn with it; not found → repeat once; still none → respawn cold, narrate and log `respin_without_memento`. Default slot `io`. A persona's own request is a ticket to its approver (D49), then the same handshake | the only acknowledgment is one the kernel can verify; a persona that cannot write a memento is still respawned; `tmp` is boot-wiped and a kernel persona resumes across reboots (Kernel-8) |
| 6 | **The provisioner is the installer.** `lupin persona spawn` renders everything (parts 1 and 2), writes `.git/info/exclude`, records `kit_commit` and `mandates_sha256`. `lupin kit pin <commit>` rewrites the lock. New gate rule `kernel_owned_file`, mode `enforce`. `doc_deploy_parity` gains the rendered copy as a deployed location. The wizard is not ported | a persona can be spawned into any repo with a project file; it cannot rewrite its own conventions; the wizard is 4,367 lines of Claude-only interaction for a decision the project file makes once |

## 3. Provisioning

**Amended 2026-11-09 (D59):** the worktree itself is created by `worktree.py` (T16 spec Section 6) at `<worktree_root>/<repository>/<persona_id>`, detached and locked, before anything below runs; `project.yaml` gains an optional `worktree_setup:` list of shell commands run in the new tree (lupin: its virtual-environment link script).

Runs inside `lupin persona spawn`, before the launch (T11 spec Section 6), idempotently on every spawn and respawn.

```
~/.lupin/kit/                          one planning-is-prompting checkout per fleet host
~/.lupin/kernel/kit.lock               { "commit": "9d8bf4f…", "pinned_at": "…", "pinned_by": "rick" }
<repo>/.lupin/project.yaml             committed; required
<worktree>/.lupin/mandates.md          layer 5, file of record ($LUPIN_MANDATES_FILE)
<worktree>/$LUPIN_SKILLS_DIR/<skill>/  SKILL.md + WORKFLOW.md per kit skill
```

`.lupin/project.yaml`:

```yaml
prefix: "[LUPIN]"                      # the short project prefix every notification carries
history_file: history.md               # relative to the repo root
todo_file: TODO.md
kit_groups: [ session, planning, doing, talking ]   # T37 spec Section 3; default all four
```

Validation refuses a missing file or field by name before any process starts (Bootstrap-2). Absolute paths are refused: the wrapper's values are resolved against `$LUPIN_WORKSPACE` at render time, so one project file serves every worktree of the repo.

`SKILL.md`, rendered from one template per kit skill:

```markdown
---
name: plan-session-start
description: Session-start ritual for {prefix}: notification, configuration, workflow discovery, manifest entry, memento reconciliation.
---
Project prefix: {prefix} · History: {workspace}/{history_file} · To-do: {workspace}/{todo_file}
Read `WORKFLOW.md` beside this file in full before doing anything. It is the only authoritative source for this ritual.
Kit commit: {kit_commit}
```

`WORKFLOW.md` is `~/.lupin/kit/workflow/<name>.md` at the lock's commit, copied byte for byte after the D51 port (verbs, not engine primitives). The skill's frontmatter is the form both engines load natively (C11; Claude's skill loader). `.git/info/exclude` gets `.lupin/`, `$LUPIN_SKILLS_DIR`, `AGENTS.md`, `.agents/`, `.claude/settings*.json` (D43 extended).

Spawn environment gains `LUPIN_WORKSPACE`, `LUPIN_SKILLS_DIR`, `LUPIN_MANDATES_FILE`, `LUPIN_MEMENTO_MIRROR`, `LUPIN_KIT_COMMIT` beside the D47 set.

## 4. Layer 5: the mandates file

```
.lupin/mandates.md = kit/global/CLAUDE.md  +  <worktree>/CLAUDE.md  +  <worktree>/CLAUDE.local.md (if present)
```

| Engine | What the model reads | Channel |
|---|---|---|
| Jetski family | the whole file | `<worktree>/AGENTS.md`, a byte-identical copy (D43) |
| Claude | the global part | block 5 of `--append-system-prompt`, after the format rules |
| Claude | the project parts | `CLAUDE.md` and `CLAUDE.local.md`, loaded natively from the worktree |

`system-prompt.md` (the record of what the model was told, T11 spec Section 3) therefore has five blocks on Claude and four on the Jetski family, with `AGENTS.md` as the fifth's record there. `mandates_sha256` is the hash of the whole file and travels in the registry row, the spawn log and the first turn's spawn line.

**T11 spec Section 8, last row, corrected.** The question C15b answers is no longer where the mandates live: it is whether a Claude persona on a host that still deploys `~/.claude/CLAUDE.md` sees the global part twice. Either answer is tolerated and logged (`mandates.duplicate_global: true|false`); the deploy of that file to fleet hosts stops at switch-over (a T19 deletion-list row).

The file is the whole of `global/CLAUDE.md` after the port, never a subset.

## 5. The memento writer port (`memento_io.py`)

| Today | After the port |
|---|---|
| `resolve_session_id()` reads lupin's bridge files when `--session-id` is omitted | reads `LUPIN_PERSONA_ID` first; then the bridge (AH4L until switch-over); neither → exit 2 naming both |
| mirror under `~/.claude/mementos/<repo>/` | `$LUPIN_MEMENTO_MIRROR`, default `~/.lupin/mementos/<repo>/` |
| line 1: `<!-- memento-record: persona=… session_id=<hex8> written_at=… slot=… -->` | `<!-- memento-record: persona=… persona_id=<hex8> written_at=… slot=… -->` |
| readers parse `session_id=` | readers accept `persona_id=` or `session_id=`; the value is the same eight hex (D46) |

Unchanged: the three slots (`io`, `root`, `tmp`), the immutable record, the derived pointer, the refusal to overwrite (exit 3), `amend`, `adopt`, `resolve`, `regenerate-pointer`, `migrate`, `verify`, the nine-element contract, the session-end harvest step and sweep. The kernel never writes a memento.

## 6. Layer 6: the first turn

One headed block in the D52 grammar, prepended to the first user turn of a fresh conversation (the Phase 1 spec's `first_message` path):

```
[kernel first-turn 2026-11-06T22:10:04Z persona=a1b2c3d4 role=implementer spawn=rehydrate kit=9d8bf4f mandates=3f9c…e1]

<the session-start skill, expanded exactly as /plan-session-start would be (D41)>

# Brief
<manifest brief: or the spawn call's brief, when present; Phase 2: the seat's charter section>

# Prior context (memento written 2026-11-06T21:40:12Z, 30 minutes ago; verify before you carry it)
<!-- memento-record: persona=María persona_id=a1b2c3d4 written_at=2026-11-06T21:40:12Z slot=io -->
<the record's full content>
```

Rules:

- `spawn=cold` when no record resolves; the "Prior context" section is then absent.
- The resolver: (1) a record whose stamp carries this persona id, newest `written_at`; (2) else the newest record for the persona's slug across `io`, `root`, `tmp` and the mirror; (3) else none. Pointers are never returned, only records (a pointer is stale by at most one amendment, and the record is what the stamp identifies).
- A record older than `memento.stale_after` (86,400 s) is still inlined, with `; STALE` after the age in the heading. Nothing is silently dropped.
- The persona's verification of the record and its reconciliation of owed work against the task store stay in the kit (session-start's reconciliation step). The kernel does not grade testimony.
- Log record `memento.rehydrated`: `persona_id`, `record_path`, `record_sha256`, `written_at`, `age_seconds`, `stale`, `match: id | slug`, `slot`. A cold spawn logs `memento.none` with `persona_id` and `slug`.
- **Names under D56 (11-08):** `memento.rehydrated`, `memento.none` and `mandates.duplicate_global` are unchanged; the respin records are `respin.requested`, `respin.rehydrated` and `respin.without_memento` (dotted, not `respin_without_memento`); `kit_commit` and `mandates_sha256` are fields of the `session.spawned` record, not records of their own; `persona_id` moves from each record's body to the envelope.

Order rationale: the ritual and the brief are the task; the memento is reference. Lupin's directive of 2026-05-29 (append, never prepend) stands.

## 7. The respin handshake

```
lupin persona respin <id>
   │
   ├─ 1. write [kernel respin <time> request=<rid>] block to the inbox (urgent):
   │       "Prepare for re-spin: reach a safe checkpoint, write your memento
   │        (python3 $LUPIN_SKILLS_DIR/plan-memento/WORKFLOW.md says how; memento_io.py write --slot io),
   │        then end your turn. Do not commit."
   ├─ 2. wait for turn end, at most respin.timeout (600 s)
   ├─ 3. resolve: a record stamped persona_id=<id> with written_at > request time?
   │       yes → stop the process, respawn with first-turn spawn=rehydrate (Section 6); log respin.rehydrated
   │       no, first miss → repeat step 1 once (request=<rid>, attempt=2); back to 2
   │       no, second miss, or timeout → stop, respawn spawn=cold; narrate and log respin_without_memento
   └─ state: respinning from step 1 to the respawn; inbound non-urgent messages queue (D52 mid-turn rule)
```

- Log records (each with `trigger: operator | pressure | persona`, **D57 11-09**): `respin.requested` (`request_id`, `attempt`), `respin.rehydrated` (`record_path`, `record_sha256`, `wait_seconds`), `respin_without_memento` (`reason: timeout | no_record`, `wait_seconds`).
- Narration on the cold fallback, spoken: "<persona> was re-spun without a memento; it will start from the task store."
- A persona asking for its own re-spin (the kit's first-person phrasing) calls `respin_request()`; the gate opens a `tool_approval` ticket (D49, `approver: manager`, fallback chain D27). An answered yes runs steps 1–3. Phase 1 exposes the tool to every role; the rule's mode is `ask`.
- `respin.timeout` is a guess; C-measurement after the first week (how long a persona takes from request to record) decides whether it moves.

## 8. Gate rule `kernel_owned_file`

| Field | Value |
|---|---|
| mode | `enforce` |
| matches | common-shape `write` or `edit` whose path is under `$LUPIN_SKILLS_DIR`, `.lupin/`, `.agents/`, or is `AGENTS.md` or `.claude/settings*.json`, in the persona's own worktree |
| deny reason | `kernel_owned_file: <path> is rendered by the kernel at provisioning; a convention changes in the kit (lupin kit pin), never in a worktree` |

## 9. Code: `provision.py`, `first_turn.py`, `respin.py`

```python
# provision.py — renders one persona's worktree from the pinned kit and the project file. Runs before launch.py.
import hashlib, subprocess, yaml
from pathlib import Path

KIT_DIR    = Path.home() / ".lupin" / "kit"
KIT_LOCK   = Path.home() / ".lupin" / "kernel" / "kit.lock"
SKILLS_DIR = { "agy": ".agents/skills", "jetski": ".agents/skills", "claude": ".claude/skills" }     # D41
EXCLUDES   = ( ".lupin/", ".agents/", ".claude/skills/", "AGENTS.md", ".claude/settings*.json" )   # D43 extended
REQUIRED   = ( "prefix", "history_file", "todo_file" )


class ProjectError( ValueError ): pass


def project( workspace ):
    """
    Requires: workspace is a git worktree root
    Ensures: returns the parsed .lupin/project.yaml; raises ProjectError naming the file or the first missing field
    """
    path = workspace / ".lupin" / "project.yaml"
    if not path.exists(): raise ProjectError( f"{path} is missing (D54); a persona cannot be provisioned without it" )
    values = yaml.safe_load( path.read_text() ) or {}
    for field in REQUIRED:
        if field not in values: raise ProjectError( f"{path}: field {field!r} is missing" )
        if field.endswith( "_file" ) and Path( values[ field ] ).is_absolute(): raise ProjectError( f"{path}: {field} must be relative to the repo root" )
    values.setdefault( "kit_groups", [ "session", "planning", "doing", "talking" ] )
    return values


def kit_commit():
    """
    Ensures: ~/.lupin/kit is at the lock's commit; returns that commit
    """
    commit = yaml.safe_load( KIT_LOCK.read_text() )[ "commit" ]
    head   = subprocess.run( [ "git", "-C", KIT_DIR, "rev-parse", "HEAD" ], capture_output=True, text=True ).stdout.strip()
    if not head.startswith( commit ):
        subprocess.run( [ "git", "-C", KIT_DIR, "fetch", "--quiet" ], check=True )
        subprocess.run( [ "git", "-C", KIT_DIR, "checkout", "--quiet", commit ], check=True )
    return commit


def skill_files( kit, workspace, engine, values, commit ):
    """
    Ensures: { Path → text } for every kit skill in the project's groups: SKILL.md rendered, WORKFLOW.md verbatim
    """
    files = {}
    for group, skills in kit_manifest( kit ).items():            # T37 spec Section 3, read from kit/workflow/KIT.yaml
        if group not in values[ "kit_groups" ]: continue
        for name, workflow in skills.items():
            folder   = workspace / SKILLS_DIR[ engine ] / name
            template = ( kit / "workflow" / "skill-templates" / f"{name}.md" ).read_text()
            files[ folder / "SKILL.md" ]    = template.format( workspace=workspace, kit_commit=commit, **values )
            files[ folder / "WORKFLOW.md" ] = ( kit / "workflow" / workflow ).read_text()
    return files


def mandates( kit, workspace ):
    """
    Ensures: layer 5 text: kit global mandates, then the project's CLAUDE.md and CLAUDE.local.md when present
    """
    parts = [ ( kit / "global" / "CLAUDE.md" ).read_text() ]
    parts += [ p.read_text() for p in ( workspace / "CLAUDE.md", workspace / "CLAUDE.local.md" ) if p.exists() ]
    return "\n\n".join( p.strip() for p in parts ) + "\n"


def provision( persona, manifest, workspace ):
    """
    Requires: manifest.engine in SKILLS_DIR; workspace exists
    Ensures: every rendered file written idempotently; .git/info/exclude carries EXCLUDES;
             returns ( kit_commit, mandates_sha256 ) for the registry row, the spawn log and the first turn
    """
    values   = project( workspace )
    commit   = kit_commit()
    text     = mandates( KIT_DIR, workspace )
    files    = skill_files( KIT_DIR, workspace, manifest.engine, values, commit )
    files[ workspace / ".lupin" / "mandates.md" ] = text
    if manifest.engine != "claude": files[ workspace / "AGENTS.md" ] = text                      # D43: a byte-identical copy
    for path, body in files.items():
        path.parent.mkdir( parents=True, exist_ok=True ); path.write_text( body )
    exclude = workspace / ".git" / "info" / "exclude"
    present = exclude.read_text().splitlines() if exclude.exists() else []
    exclude.write_text( "\n".join( present + [ e for e in EXCLUDES if e not in present ] ) + "\n" )
    return commit, hashlib.sha256( text.encode() ).hexdigest()
```

```python
# first_turn.py — composes layer 6. Pure: no I/O beyond reading the resolved record.
import datetime, hashlib
from pathlib import Path

STALE_AFTER_SECONDS = 86_400


def resolve_record( persona_id, slug, workspace, mirror ):
    """
    Ensures: the newest record stamped with persona_id, else the newest for slug across io, root, tmp and mirror, else None;
             never a pointer (a record's name carries an eight-hex suffix; a pointer's does not)
    """
    candidates = [ p for p in record_paths( workspace, mirror ) if is_record( p ) ]
    by_id   = [ p for p in candidates if stamp( p ).get( "persona_id", stamp( p ).get( "session_id" ) ) == persona_id ]
    by_slug = [ p for p in candidates if stamp( p ).get( "persona" ) and slugify( stamp( p )[ "persona" ] ) == slug ]
    for pool, match in ( ( by_id, "id" ), ( by_slug, "slug" ) ):
        if pool: return max( pool, key=lambda p: stamp( p )[ "written_at" ] ), match
    return None, None


def first_turn( persona, manifest, kit_commit, mandates_sha256, expanded_session_start, brief, record, match, now ):
    """
    Requires: expanded_session_start is the kit skill's text after the D41 /name expansion
    Ensures: one [kernel first-turn …] block: spawn line, ritual, brief if any, prior context if any; logs memento.rehydrated or memento.none
    """
    spawn = "rehydrate" if record else "cold"
    head  = ( f"[kernel first-turn {now.isoformat()} persona={persona.persona_id} role={manifest.role} "
              f"spawn={spawn} kit={kit_commit[:7]} mandates={mandates_sha256[:12]}]" )
    parts = [ head, expanded_session_start ]
    if brief: parts.append( "# Brief\n" + brief.strip() )
    if record:
        meta  = stamp( record ); age = ( now - datetime.datetime.fromisoformat( meta[ "written_at" ] ) ).total_seconds()
        stale = "; STALE" if age > STALE_AFTER_SECONDS else ""
        parts.append( f"# Prior context (memento written {meta[ 'written_at' ]}, {describe( age )} ago{stale}; verify before you carry it)\n"
                      + record.read_text().strip() )
        log( "memento.rehydrated", persona_id=persona.persona_id, record_path=str( record ), record_sha256=sha256( record ),
             written_at=meta[ "written_at" ], age_seconds=int( age ), stale=bool( stale ), match=match, slot=meta[ "slot" ] )
    else:
        log( "memento.none", persona_id=persona.persona_id, slug=persona.slug )
    return "\n\n".join( parts ) + "\n"
```

```python
# respin.py — the handshake behind `lupin persona respin <id>`. State lives in the registry row (status=respinning).
RESPIN_TIMEOUT_SECONDS = 600
REQUEST = ( "Prepare for re-spin: reach a safe checkpoint, write your memento "
            "(memento_io.py write --slot io; the plan-memento skill says how), then end your turn. Do not commit." )


def respin( kernel, persona, now, trigger="operator" ):      # trigger: operator | pressure | persona (D57)
    """
    Ensures: the persona is respawned exactly once: with a record newer than the first request when one appears
             within two turns and the timeout, otherwise cold with respin_without_memento narrated and logged
    """
    request_at = now()
    for attempt in ( 1, 2 ):
        request_id = kernel.inbox.write_kernel_block( persona, "respin", REQUEST, urgent=True, attrs={ "attempt": attempt } )
        log( "respin.requested", persona_id=persona.persona_id, request_id=request_id, attempt=attempt, trigger=trigger )
        ended = kernel.wait_turn_end( persona, timeout=RESPIN_TIMEOUT_SECONDS )
        record, _ = resolve_record( persona.persona_id, persona.slug, persona.workspace, kernel.memento_mirror )
        if record and stamp( record )[ "written_at" ] > request_at.isoformat():
            log( "respin.rehydrated", persona_id=persona.persona_id, record_path=str( record ), record_sha256=sha256( record ),
                 wait_seconds=int( ( now() - request_at ).total_seconds() ) )
            return kernel.respawn( persona, record=record )
        if not ended: break                                      # timeout: do not ask again
    reason = "no_record" if ended else "timeout"
    log( "respin_without_memento", persona_id=persona.persona_id, reason=reason, wait_seconds=int( ( now() - request_at ).total_seconds() ) )
    kernel.narrate( f"{persona.name} was re-spun without a memento; it will start from the task store." )
    return kernel.respawn( persona, record=None )
```

`kit_manifest` reads a `workflow/KIT.yaml` the D51 port adds to planning-is-prompting (group → skill name → workflow file), so the kit's membership is data in the kit, not a list in the kernel. `record_paths`, `is_record`, `stamp`, `slugify`, `describe`, `sha256` and `log` are the obvious helpers; `slugify` is `memento_io.slugify` imported, not copied.
