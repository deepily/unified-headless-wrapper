## 2. The rule

```
on turn end with an empty queue, and every `recheck_seconds` while idle:
  verdict  = evaluate_owed( task rows, live reports, due tickets, last look-in )
  if queue is not empty            → start the queued turn            (START_QUEUED)
  if verdict.unknown and no items  → idle, no hibernation, retry      (UNKNOWN)
  uncovered = items not covered by a live hold; tickets and verification are never covered
  if no items                      → idle, hibernation clock runs     (NOT_OWED)
  if no uncovered                  → idle, hibernation clock runs     (HONORED)
  if pokes off or tick cap reached → idle, awake, next tick           (CAP_REACHED)
  else                             → one kernel block as the next turn (POKE)
```

The tick cap re-arms every tick, so an owed persona is poked at most once per `recheck_seconds` and never sleeps (decision 8). A poke whose turn produces no store change (no task transition, no ticket, no DM) counts as unproductive; three in a row set `stalled: true` on the row and send the manager one `[kernel HH:MM:SS report stalled <id8> owed N]` block (owed work for the manager under signal 2); a persona with no manager tells the human as one `priority: low` card. Any store change clears `stalled` and the history. A real inbound block resets the episode.

## 3. The four signals

| Signal | Query | Overrides a hold |
|---|---|---|
| Owed task rows | the persona's own rows in an owed status in the task store (D21); the transcript replay and the mirror are gone | no |
| Live reports | registry rows with `manager_id` = this persona and state not `closed` (D59) | no |
| Due tickets | tickets this persona raised whose re-ask is due, and `tool_approval` tickets waiting on it as approver (D37, D49) | **yes** |
| Verification debt | live reports and no `turn_end.looked_in` record for `verify after seconds` (600); the record is written when the manager reads a report's status through the control API or a kernel tool | **yes** |

Dropped from the oracle: transcript replay (D21), unanswered inbound DMs (off in the fleet since 06-16; D52's ledger records delivery, not answers), the spin-up nudge (crew layer, Phase 2 under D51; a fifth signal when it returns), the sweep ledger (a store query, Section 6), the memento verify tick (a kernel job).

## 4. The hold

- Kernel tools through the gate: `hold( reason, ttl_seconds=900, awaiting="none", covers=[] )` and `release()`. A reason is required; `ttl_seconds` is a positive number capped at `hold max seconds` (14,400). The kernel stamps `until` from its own clock; the agent's clock is never consulted.
- `covers` is a list of `(kind, id)` pairs; empty means the owed set as it stands at declaration (tasks and reports; tickets and verification are never coverable).
- Row fields: `hold: { reason, until, awaiting, covers }`, shown on the roster and the console (D58). `turn_end.hold` and `turn_end.release` records.
- A hold is honored only for what it covers. A poke that fires through a hold says so (`Your hold (<reason>) covers none of these.`).
- Deleted: `.heartbeat-hold-*` files, `heartbeat_hold.py` (1,512 lines), `heartbeat_hold_io.py`, `heartbeat_hold_warn.py`, the hold janitor and misplaced-zone report, the three debounce stamps and gate rows the hold file had accumulated.

## 5. The poke

```
[kernel 19:40:01 poke owed 2]
Do not stop yet. You still owe:
- task 7c1e in_progress: port the gate shim
- report a1b2c3d4 is live
Board sweep: 3 of 7 rows reviewed.

Your goal: finish your owed work to verified completion with receipts; escalate blockers rather than retrying silently; when nothing is owed, declare it.
```

One envelope, one block, as the next turn, only when the queue is empty (D8, D13). A body line that would parse as a header is indented (D52's forgery rule). The goal line is `kernel turn end goal line <role>` from the configuration (the three sentences live there today as `heartbeat <role> goal line`), appended last, switched by `kernel turn end goal line`, stamped on the record as `goal_line_version` so its effect on completion can be measured; the canonical text stays in `planning-is-prompting/workflow/role-goals.md`. Record `turn_end.poke` per poke: `{ owed, kinds, hold_overridden, goal_line_version, tick }`.

## 6. The sweep and the memento verify

A sweep is a property of the task store, not a ledger file: a frozen set of row ids with a `reviewed` mark per row, opened by the seat that holds the board. The owed-rows query returns `sweep: { reviewed, total }` when one is open and the poke body carries it. The store change (a sweep table or a per-row flag) is a Lupin row on the T19 list. `memento_io.py verify` runs daily as a kernel scheduled job (T08) and alerts through the log; it never rides a persona's prompt.

## 7. Idle

- No "anything else?" ask, no `idle_waiter`, no backoff schedule.
- When a persona goes idle with nothing owed (`NOT_OWED` or `HONORED`), one card at `priority: low` (never spoken), only if the idle episode began with a `voice` block; repeat idles in the same episode post nothing. Switch: `kernel turn end idle card`.
- Roster fields: `idle_since`, `owed` (count of uncovered items), `hold`, `stalled`, `pokes_this_episode`.
- Hibernation (D59 Section 10.5 amended): the 30-minute clock runs only from `NOT_OWED` or `HONORED`; it never runs while uncovered work is owed or a store reads `unknown`.

## 8. Liveness and narration

`last_event_at` on the registry row, stamped from every engine frame and every gate call (D56, D59), is the liveness clock. Every result frame is parsed and posted (D53); an empty result gets the repair line. `turn_end.py` — standard library only.

```python
"""turn_end.py — the turn-end policy (D62, T15).

Standard library only. Pure functions; the kernel wires them to the queue,
the registry row, the task store, the ticket store, the engine's stdin, the
log and the scheduler.

Four jobs:
  1. the owed-work verdict   : evaluate_owed
  2. the hold                : declare_hold, hold_covers, hold_is_live
  3. the turn-end decision   : decide_turn_end  (the one pure rule)
  4. the poke                : render_poke_block, render_idle_report_block

The rule runs twice: when a turn ends with an empty queue, and every
`recheck_seconds` while the persona is idle. It never reads a file.
"""
from dataclasses import dataclass, field
from typing import Optional

# ── outcomes (the adapter routes side effects off these) ─────────────────────
START_QUEUED  = "start_queued"    # a message is waiting: it starts the next turn; no verdict is taken
POKE          = "poke"            # owed, not covered, under the tick cap: one kernel block as the next turn
HONORED       = "honored"         # every owed item is covered by a live hold: idle, hibernation clock runs
NOT_OWED      = "not_owed"        # nothing owed: idle, hibernation clock runs
UNKNOWN       = "unknown"         # a store could not be read: idle, no hibernation, retry next tick
CAP_REACHED   = "cap_reached"     # owed, not covered, the tick's one poke already sent: wait for the next tick

# ── owed work ────────────────────────────────────────────────────────────────
@dataclass
class OwedItem:
    kind : str          # task | report | ticket | verification
    id   : str          # store row id, persona_id, ticket id, or the report's persona_id
    text : str = ""     # one line for the poke body

@dataclass
class OwedVerdict:
    items   : list = field( default_factory=list )
    unknown : bool = False          # a source failed; never read as "nothing owed"
    sweep   : Optional[tuple] = None    # (reviewed, total) when the store says a sweep is open

    @property
    def owed( self ):
        return bool( self.items )

def evaluate_owed( task_rows, reports, tickets, last_look_in, now, verify_after_seconds=600, sweep=None ):
    """
    The four signals (decision 2). Each argument is the result of one query:
      task_rows : list of {id, status, title} in an owed status, or None if the store failed
      reports   : list of persona_ids whose manager_id is this persona and state != closed
      tickets   : list of {id, kind, due} this persona raised (re-ask due) or must approve, or None if failed
      last_look_in : epoch seconds of the last `turn_end.looked_in` record, or None
    """
    v = OwedVerdict( sweep=sweep )
    if task_rows is None or tickets is None:
        v.unknown = True
    for r in ( task_rows or [] ):
        v.items.append( OwedItem( "task", r[ "id" ], f"task {r['id']} {r.get('status','')}: {r.get('title','')}".rstrip() ) )
    for pid in reports:
        v.items.append( OwedItem( "report", pid, f"report {pid} is live" ) )
    for t in ( tickets or [] ):
        if t.get( "due", 0 ) <= now:
            v.items.append( OwedItem( "ticket", t[ "id" ], f"ticket {t['id']} {t.get('kind','')} is due" ) )
    if reports and ( last_look_in is None or now - last_look_in >= verify_after_seconds ):
        v.items.append( OwedItem( "verification", "reports", f"no look-in on {len(reports)} report(s) for {verify_after_seconds}s" ) )
    return v

# ── the hold (decision 3) ────────────────────────────────────────────────────
@dataclass
class Hold:
    reason   : str
    until    : float                 # kernel clock, epoch seconds
    awaiting : str = "none"
    covers   : frozenset = frozenset()   # (kind, id) pairs; empty means nothing (the kernel fills it at declaration)

def declare_hold( reason, ttl_seconds, now, owed_now, covers=None, awaiting="none", max_seconds=14400 ):
    """`hold( reason, ttl_seconds, awaiting, covers )` through the gate. The kernel stamps `until` from
    its own clock. `covers` defaults to the owed set as it stands at declaration (Rick, decision 3)."""
    if not ( reason and reason.strip() ):
        raise ValueError( "a hold needs a reason" )
    if not isinstance( ttl_seconds, ( int, float ) ) or isinstance( ttl_seconds, bool ) or ttl_seconds <= 0:
        raise ValueError( "ttl_seconds must be a positive number" )
    ttl = min( ttl_seconds, max_seconds )
    cov = frozenset( covers ) if covers else frozenset( ( i.kind, i.id ) for i in owed_now.items )
    return Hold( reason=reason.strip(), until=now + ttl, awaiting=awaiting, covers=cov )

def hold_is_live( hold, now ):
    return hold is not None and now < hold.until

def hold_covers( hold, item ):
    """A ticket that is due and a verification debt poke through any hold (the obligation override)."""
    if item.kind in ( "ticket", "verification" ):
        return False
    return ( item.kind, item.id ) in hold.covers

# ── the decision (decisions 1, 4, 7, 8) ──────────────────────────────────────
@dataclass
class TurnEndState:
    queue_length     : int
    verdict          : OwedVerdict
    hold             : Optional[Hold]
    pokes_this_tick  : int
    now              : float
    pokes_enabled    : bool = True
    poke_cap         : int = 1

@dataclass
class Decision:
    outcome   : str
    uncovered : list = field( default_factory=list )
    log       : dict = field( default_factory=dict )

def decide_turn_end( s ):
    """One pure rule, run at turn end with an empty queue and on every idle tick."""
    if s.queue_length > 0:
        return Decision( START_QUEUED )
    if s.verdict.unknown and not s.verdict.items:
        return Decision( UNKNOWN, log={ "reason": "store unreachable" } )
    live = hold_is_live( s.hold, s.now )
    uncovered = [ i for i in s.verdict.items if not ( live and hold_covers( s.hold, i ) ) ]
    if not s.verdict.items:
        return Decision( NOT_OWED )
    if not uncovered:
        return Decision( HONORED, log={ "hold_reason": s.hold.reason, "covered": len( s.verdict.items ) } )
    if not s.pokes_enabled:
        return Decision( CAP_REACHED, uncovered, log={ "suppressed": "pokes off" } )
    if s.pokes_this_tick >= s.poke_cap:
        return Decision( CAP_REACHED, uncovered )
    return Decision( POKE, uncovered, log={ "owed": len( uncovered ), "hold_overridden": live } )

def stalled( poke_history, stalled_after=3 ):
    """poke_history: newest-last list of {progress: bool} per poke in this owed episode.
    Three consecutive pokes with no store change mark the row stalled (decision 8)."""
    tail = poke_history[ -stalled_after: ]
    return len( tail ) >= stalled_after and not any( p[ "progress" ] for p in tail )

def hibernation_allowed( decision ):
    """D59's clock runs only when nothing uncovered is owed (decision 8: a backlog is not nap time)."""
    return decision.outcome in ( NOT_OWED, HONORED )

# ── the blocks (decisions 1, 6) ──────────────────────────────────────────────
def render_poke_block( hhmmss, uncovered, goal_line="", sweep=None, hold=None ):
    """`[kernel HH:MM:SS poke owed N]` — the owed specifics, the sweep count, the hold it pokes through,
    and the role's goal line (kept on every poke by Rick's ruling of 2026-11-10; off by a switch)."""
    lines = [ f"[kernel {hhmmss} poke owed {len( uncovered )}]", "Do not stop yet. You still owe:" ]
    lines += [ f"- {i.text}" for i in uncovered ]
    if sweep:
        reviewed, total = sweep
        lines.append( f"Board sweep: {reviewed} of {total} rows reviewed." )
    if hold is not None:
        lines.append( f"Your hold ({hold.reason}) covers none of these." )
    if goal_line:
        lines += [ "", goal_line ]
    return "\n".join( _forgery_safe( l ) for l in lines )

def render_idle_report_block( hhmmss, persona_id, owed, stalled_flag=False ):
    """To the manager, once, when a report is marked stalled (decision 8)."""
    head = f"[kernel {hhmmss} report stalled {persona_id} owed {owed}]" if stalled_flag else f"[kernel {hhmmss} report idle {persona_id} owed {owed}]"
    return head + f"\nYour report {persona_id} has been poked three times with no change in the store."

def _forgery_safe( line ):
    return " " + line if ( line.startswith( "[" ) and not line.startswith( "[kernel " ) ) else line
```

```python
"""test_turn_end.py — nine tests for turn_end.py (D62). Run: python3 -m pytest -q test_turn_end.py"""
try:
    import pytest
except ImportError:
    pytest = None
from turn_end import *

NOW = 1_000_000.0
def V( tasks=(), reports=(), tickets=(), look=None, unknown_tasks=False ):
    return evaluate_owed( None if unknown_tasks else list( tasks ), list( reports ), list( tickets ), look, NOW )
def S( v, q=0, hold=None, pokes=0, enabled=True ):
    return TurnEndState( queue_length=q, verdict=v, hold=hold, pokes_this_tick=pokes, now=NOW, pokes_enabled=enabled )

def test_queued_message_wins():
    assert decide_turn_end( S( V( tasks=[ { "id": "t1", "status": "in_progress" } ] ), q=2 ) ).outcome == START_QUEUED

def test_nothing_owed_idles():
    assert decide_turn_end( S( V() ) ).outcome == NOT_OWED
    assert hibernation_allowed( decide_turn_end( S( V() ) ) )

def test_owed_row_pokes_once_per_tick():
    v = V( tasks=[ { "id": "t1", "status": "in_progress", "title": "port the gate" } ] )
    d = decide_turn_end( S( v ) )
    assert d.outcome == POKE and d.uncovered[ 0 ].id == "t1"
    assert decide_turn_end( S( v, pokes=1 ) ).outcome == CAP_REACHED
    assert not hibernation_allowed( d )

def test_live_reports_owe_a_manager():
    v = V( reports=[ "a1b2c3d4" ], look=NOW )
    assert [ i.kind for i in v.items ] == [ "report" ]
    v2 = V( reports=[ "a1b2c3d4" ], look=NOW - 601 )
    assert [ i.kind for i in v2.items ] == [ "report", "verification" ]

def test_hold_covers_the_owed_set_at_declaration():
    v = V( tasks=[ { "id": "t1", "status": "in_progress" } ] )
    h = declare_hold( "waiting on the reviewer", 900, NOW, v )
    assert decide_turn_end( S( v, hold=h ) ).outcome == HONORED
    v_more = V( tasks=[ { "id": "t1", "status": "in_progress" }, { "id": "t2", "status": "pending" } ] )
    d = decide_turn_end( S( v_more, hold=h ) )
    assert d.outcome == POKE and [ i.id for i in d.uncovered ] == [ "t2" ]      # unrelated work pokes through

def test_due_ticket_pokes_through_a_hold():
    v = V( tickets=[ { "id": "ask-9", "kind": "ask", "due": NOW - 1 } ] )
    h = declare_hold( "long external job", 900, NOW, v )
    assert decide_turn_end( S( v, hold=h ) ).outcome == POKE

def test_expired_hold_is_not_honored():
    v = V( tasks=[ { "id": "t1", "status": "in_progress" } ] )
    h = declare_hold( "x", 100, NOW - 200, v )
    assert decide_turn_end( S( v, hold=h ) ).outcome == POKE

def test_store_outage_is_unknown_never_not_owed():
    d = decide_turn_end( S( V( unknown_tasks=True ) ) )
    assert d.outcome == UNKNOWN and not hibernation_allowed( d )

def test_stalled_after_three_unproductive_pokes_and_mute():
    assert not stalled( [ { "progress": False } ] * 2 )
    assert stalled( [ { "progress": True } ] + [ { "progress": False } ] * 3 )
    assert not stalled( [ { "progress": False }, { "progress": True }, { "progress": False } ] )
    v = V( tasks=[ { "id": "t1", "status": "in_progress" } ] )
    assert decide_turn_end( S( v, enabled=False ) ).log == { "suppressed": "pokes off" }
    body = render_poke_block( "19:40:01", v.items, goal_line="Your goal: finish your owed work.", sweep=( 3, 7 ) )
    assert body.startswith( "[kernel 19:40:01 poke owed 1]\nDo not stop yet." ) and "3 of 7" in body and body.endswith( "owed work." )
```

## Amendment (2026-11-16, row 57: the flat-key form of a configuration table)

Ruling 10 put every kernel setting in lupin's `lupin-app.ini` as a lowercase space-separated key, and Section 9 said the earlier specs' sections "are read as key prefixes". That converts a single-valued setting. It does not convert a table, and the record holds two: the context-window table of the context-exhaustion decision (D57), seven rows of two numbers by engine and model, and the memory table of the host-capacity decision (D60), three rows of three numbers by engine. Neither can be written in `lupin-app.ini` as its spec wrote it: Python's `ConfigParser`, which the ConfigurationManager builds with no arguments (`cosa/config/configuration_manager.py:246`, lupin at `aabadd221`), ends a key at a colon, so `agy:fable-5.1-high = …` reads as key `agy` and the second such row is a duplicate-key error; and it keeps a comment after a value as part of the value.

Ruled by Rick on 2026-11-16, four for four as recommended, one click each, after the narrative `narratives/2026.11.16-row57-configuration-table-keys.md`. No decision number: the four rulings are detail under D62 part 10, as row 26's was. No value and no behavior of D57 or D60 changes.

### The four rulings

1. **One key per number, the row named in the key.** The form of the sixty-five `cc session voice persona …` keys and the forty-two `external repo <name> <kind>` keys already in `lupin-app.ini`. A child block overrides its parent one key at a time (`configuration_manager.py:490`), so a host's block can change one number and inherit the rest. A value that a row lacks by design has no key (Claude has no heap key); nothing is spelled `none`. Not chosen: one key per row with a comma list (positional; the manager's list reader splits only on comma-space); one key per table with a JSON value (a host's override restates the whole table; one stray comma loses every row).
2. **The row first, then the quantity.**

   ```ini
   kernel context windows <engine> <model> window tokens   = 1000000
   kernel context windows <engine> <model> ceiling tokens  = 256000
   kernel memory <engine> reserve bytes                    = 2147483648
   kernel memory <engine> cap bytes                        = 8589934592
   kernel memory <engine> heap mebibytes                   = 6144
   ```

   The per-engine memory keys share the prefix `kernel memory` with three single-valued keys (`kernel memory notice ratio`, `kernel memory respin ratio`, `kernel memory respin window hours`); the loader knows those three, and no engine may be named `notice` or `respin`.
3. **The model's name is normalized for the key:** lowercase, and a hyphen for each colon, each equals sign and each run of spaces. The file is written with the normalized name and the lookup normalizes the same way; the persona's own model name is untouched everywhere else. Two names that differ only in those characters share a row.
4. **A row that is incomplete or unreadable is refused.** At start the kernel reads every key under the two prefixes; a key that is not a known engine and quantity, a row lacking a required quantity, a value that is not a positive whole number, a ceiling above its window or a reserve above its cap stops the start with the key named. On the memory table's re-read at an admission the same check runs; a failure refuses that admission with the key named and leaves running personas as they are. An absent row stays what it was: a model with no row reads `unknown` (`pressure.window_unknown`, Pressure-4); an engine with no row is not admitted.

The full tables in this form are in the context-exhaustion spec, Section 4, and the host-capacity spec, Section 6, rewritten in place the same day with the fleet and log specs' single-valued keys; each carries an amendment listing what was and what is.

`configuration_tables.py`:

```python
"""
configuration_tables.py: the kernel's two configuration tables, read from flat keys.

Ruled 2026-11-16 (rows 57 and 59 of "Outstanding actions", under D62 part 10): one key per number, the row first and
the quantity last, the model's name normalized, and a refusal for any row that is incomplete or unreadable. The nine
single-valued keys beside the tables (three `kernel memory ...`, six `kernel context pressure ...`) are required and bounded.

    kernel context windows <engine> <model> window tokens   = 1000000
    kernel context windows <engine> <model> ceiling tokens  = 256000
    kernel memory <engine> reserve bytes                    = 2147483648
    kernel memory <engine> cap bytes                        = 8589934592
    kernel memory <engine> heap mebibytes                   = 6144          (optional)

Dependency-free. `pairs` is every key in force with its value, as strings: on lupin's ConfigurationManager,
`{ key: manager.get( key ) for key in manager.get_keys() }`.
"""
import re
from dataclasses import dataclass

CONTEXT_PREFIX     = "kernel context windows"
MEMORY_PREFIX      = "kernel memory"
CONTEXT_QUANTITIES = ( "window tokens", "ceiling tokens" )
MEMORY_REQUIRED    = ( "reserve bytes", "cap bytes" )
MEMORY_OPTIONAL    = ( "heap mebibytes", )
MEMORY_SINGLE_KEYS = ( "notice ratio", "respin ratio", "respin window hours" )     # single-valued keys under the same prefix
PRESSURE_PREFIX    = "kernel context pressure"
PRESSURE_CLASSES   = ( "1m", "200k" )

class ConfigurationError( Exception ):
    """A key under one of the two prefixes cannot be read. The kernel refuses its start, or the admission on a re-read."""
    def __init__( self, key, reason ):
        super().__init__( f"{key}: {reason}" )
        self.key    = key
        self.reason = reason

@dataclass( frozen=True )
class ContextWindow:
    window_tokens  : int
    ceiling_tokens : int

@dataclass( frozen=True )
class EngineMemory:
    reserve_bytes  : int
    cap_bytes      : int
    heap_mebibytes : int | None = None

@dataclass( frozen=True )
class MemorySettings:
    notice_ratio        : float
    respin_ratio        : float
    respin_window_hours : int

@dataclass( frozen=True )
class ContextPressure:
    notice_ratio             : dict          # class ("1m", "200k") to ratio
    respin_ratio             : dict
    class_boundary_tokens    : int
    compaction_drop_fraction : float

def normalize_model_name( name ):
    """
    Ensures: the form of a model's name inside a key: lowercase, a hyphen for each colon, each equals sign and
    each run of spaces. The persona's own model name is untouched everywhere else.
    """
    name = name.strip().lower()
    name = re.sub( r"\s+", "-", name )
    return name.replace( ":", "-" ).replace( "=", "-" )

def context_key( engine, model, quantity ):
    return f"{CONTEXT_PREFIX} {engine} {normalize_model_name( model )} {quantity}"

def memory_key( engine, quantity ):
    return f"{MEMORY_PREFIX} {engine} {quantity}"

def _under( pairs, prefix ):
    return sorted( ( key, value ) for key, value in pairs.items() if key.startswith( prefix + " " ) )

def _whole_number( key, value ):
    if not re.fullmatch( r"[0-9]+", value.strip() ) or int( value ) == 0:
        raise ConfigurationError( key, f"not a positive whole number: {value!r}" )
    return int( value )

def _split( key, words, engines, quantities ):
    """Requires: words is the key after its prefix and before nothing. Ensures: ( row words, quantity ), or a refusal."""
    quantity = " ".join( words[ -2: ] )
    if len( words ) < 3 or quantity not in quantities:
        raise ConfigurationError( key, f"not one of the quantities {list( quantities )}" )
    if words[ 0 ] not in engines:
        raise ConfigurationError( key, f"unknown engine {words[ 0 ]!r}" )
    return words[ :-2 ], quantity

def load_context_windows( pairs, engines ):
    """
    Requires: engines is the kernel's own list of engine names.
    Ensures: { ( engine, model ): ContextWindow } for every row under the prefix.
    Raises: ConfigurationError, naming the key, for an unknown quantity or engine, a model's name that is not
            one normalized word, a value that is not a positive whole number, a row lacking either quantity,
            or a ceiling above its window.
    """
    cells = {}
    for key, value in _under( pairs, CONTEXT_PREFIX ):
        row, quantity = _split( key, key[ len( CONTEXT_PREFIX ): ].split(), engines, CONTEXT_QUANTITIES )
        if len( row ) != 2 or row[ 1 ] != normalize_model_name( row[ 1 ] ):
            raise ConfigurationError( key, "the row is one engine and one normalized model name" )
        cells.setdefault( tuple( row ), {} )[ quantity ] = _whole_number( key, value )
    table = {}
    for ( engine, model ), found in cells.items():
        for quantity in CONTEXT_QUANTITIES:
            if quantity not in found:
                raise ConfigurationError( context_key( engine, model, quantity ), "missing: the row is incomplete" )
        if found[ "ceiling tokens" ] > found[ "window tokens" ]:
            raise ConfigurationError( context_key( engine, model, "ceiling tokens" ), "the ceiling is above the window" )
        table[ ( engine, model ) ] = ContextWindow( found[ "window tokens" ], found[ "ceiling tokens" ] )
    return table

def context_window_for( table, engine, model ):
    """Ensures: the row, or None for a model the table does not list (`pressure.window_unknown`, Pressure-4)."""
    return table.get( ( engine, normalize_model_name( model ) ) )

def load_memory( pairs, engines ):
    """
    Ensures: { engine: EngineMemory } for every engine with keys under the prefix; the single-valued keys are passed over.
    Raises: ConfigurationError, naming the key, for an unknown quantity or engine, a value that is not a positive
            whole number, a row lacking its reserve or its cap, or a reserve above its cap.
    """
    cells = {}
    for key, value in _under( pairs, MEMORY_PREFIX ):
        rest = key[ len( MEMORY_PREFIX ): ].strip()
        if rest in MEMORY_SINGLE_KEYS: continue
        row, quantity = _split( key, rest.split(), engines, MEMORY_REQUIRED + MEMORY_OPTIONAL )
        if len( row ) != 1:
            raise ConfigurationError( key, "the row is one engine" )
        cells.setdefault( row[ 0 ], {} )[ quantity ] = _whole_number( key, value )
    table = {}
    for engine, found in cells.items():
        for quantity in MEMORY_REQUIRED:
            if quantity not in found:
                raise ConfigurationError( memory_key( engine, quantity ), "missing: the row is incomplete" )
        if found[ "reserve bytes" ] > found[ "cap bytes" ]:
            raise ConfigurationError( memory_key( engine, "reserve bytes" ), "the reserve is above the cap" )
        table[ engine ] = EngineMemory( found[ "reserve bytes" ], found[ "cap bytes" ], found.get( "heap mebibytes" ) )
    return table

def memory_for( table, engine ):
    """Raises: ConfigurationError for an engine with no row: nothing can be reserved for it, so it is not admitted."""
    if engine not in table:
        raise ConfigurationError( memory_key( engine, "reserve bytes" ), "missing: the engine has no row" )
    return table[ engine ]

def _required( pairs, key ):
    if key not in pairs:
        raise ConfigurationError( key, "missing: the key is required" )
    return pairs[ key ]

def _fraction( pairs, key, closed ):
    """Ensures: a number above 0 and at most 1 (closed) or below 1 (not closed)."""
    value = _required( pairs, key )
    try:
        number = float( value )
    except ValueError:
        raise ConfigurationError( key, f"not a number: {value!r}" ) from None
    if not ( 0 < number <= 1 if closed else 0 < number < 1 ):
        raise ConfigurationError( key, f"outside the range above 0 and {'at most' if closed else 'below'} 1: {value!r}" )
    return number

def _notice_below_respin( pairs, notice_key, respin_key ):
    notice, respin = _fraction( pairs, notice_key, True ), _fraction( pairs, respin_key, True )
    if not notice < respin:
        raise ConfigurationError( notice_key, "the notice ratio is not below the respin ratio" )
    return notice, respin

def load_memory_settings( pairs ):
    """
    Ensures: the three single-valued `kernel memory ...` keys, each present and in range.
    Raises: ConfigurationError, naming the key, for a missing key, a ratio outside ( 0, 1 ], a notice ratio not below
            the respin ratio, or a window that is not a positive whole number of hours.
    """
    notice, respin = _notice_below_respin( pairs, f"{MEMORY_PREFIX} notice ratio", f"{MEMORY_PREFIX} respin ratio" )
    key = f"{MEMORY_PREFIX} respin window hours"
    return MemorySettings( notice, respin, _whole_number( key, _required( pairs, key ) ) )

def load_context_pressure( pairs ):
    """
    Ensures: the six `kernel context pressure ...` keys, each present and in range.
    Raises: ConfigurationError, naming the key, for a missing key, a ratio outside ( 0, 1 ], a class whose notice ratio
            is not below its respin ratio, a boundary that is not a positive whole number, or a drop fraction outside ( 0, 1 ).
    """
    notice, respin = {}, {}
    for name in PRESSURE_CLASSES:
        notice[ name ], respin[ name ] = _notice_below_respin( pairs, f"{PRESSURE_PREFIX} notice ratio {name} class", f"{PRESSURE_PREFIX} respin ratio {name} class" )
    boundary = f"{PRESSURE_PREFIX} class boundary tokens"
    return ContextPressure( notice, respin, _whole_number( boundary, _required( pairs, boundary ) ),
                            _fraction( pairs, f"{PRESSURE_PREFIX} compaction drop fraction", False ) )

def context_lines( rows ):
    """Requires: rows of ( engine, model, window, ceiling ). Ensures: the file's lines, two per row, aligned."""
    keys = [ ( context_key( e, m, q ), v ) for e, m, w, c in rows for q, v in zip( CONTEXT_QUANTITIES, ( w, c ) ) ]
    return _aligned( keys )

def memory_lines( rows ):
    """Requires: rows of ( engine, reserve, cap, heap or None ). Ensures: the file's lines; no line for an absent heap."""
    keys = [ ( memory_key( e, q ), v ) for e, r, c, h in rows for q, v in zip( MEMORY_REQUIRED + MEMORY_OPTIONAL, ( r, c, h ) ) if v is not None ]
    return _aligned( keys )

def _aligned( keys ):
    width = max( len( key ) for key, _ in keys )
    return [ f"{key.ljust( width )} = {value}" for key, value in keys ]
```

### What follows from them

- The three values that identify the file are stored only after a read that passed its checks. A read refused for a bad key is therefore made again at the next admission though the file has not changed, and the configuration in hand stays the last one that passed: running personas are as they were (the amendment above, ruling 4).
- An atomic replacement changes the file's inode and an edit in place its modification time (the script: `inode changed=True … mtime_ns changed=True` for identical bytes), so both are seen. A value that expands an environment variable can change with the file untouched; the check does not see that, and the kernel's environment does not change while it runs.
- After a good read the kept manager holds the file's present contents for any code that asks it. Ruling 3 is what keeps that from mattering: no kernel code but the start and the admission reads the manager.
- An engine's reservation is charged from the fresh memory table to personas already running (host-capacity spec, Section 10: the sum reads the table), which is how that dial moves.
- With a launch override in force, lupin's manager prints a few lines on `init()` even when silent (six in one trial with one override): once per changed file, not per admission.
- Cost on the test VM (2,750 lines, 961 keys in force): the comparison 0.003 ms; a read, when the file has changed, about 23 ms.

```python
"""
configuration_reread.py: the admission's settings, read again when the settings file has changed.

Ruled 2026-11-16 (row 60 of "Outstanding actions", under D62 part 10):
  1   the kernel calls `init()` on the one kept ConfigurationManager; no second instance, no guard
  1b  quietly, with the overrides the manager was first built with: `init( silent=True, cli_args=<launch overrides> )`
  1c  the kernel keeps those overrides itself until lupin's manager remembers its own
  2   only when the file has changed: inode, size and modification time compared at each admission
  3   the loader's frozen records are built again; the check list and the persona it admits use the new ones;
      every other consumer keeps the values it took at the start
  4   the six admission keys are required and bounded, like the nine single-valued keys of row 59

Dependency-free. `manager` is lupin's ConfigurationManager or anything with `init( silent, cli_args )`, `get_keys()`,
`get( key )` and `config_path`.
"""
import os
import re
from dataclasses import dataclass

from configuration_tables import ConfigurationError, _required, _whole_number, load_memory, load_memory_settings

SIZE_CAP            = "kernel fleet size cap"
SIZE_CAP_MAXIMUM    = "kernel fleet size cap maximum"
BATCH_CAP           = "kernel fleet batch cap"
SKELETON_CREW       = "kernel fleet skeleton crew"
RESERVE_RATIO       = "kernel host reserve ratio"
RESERVE_FLOOR_BYTES = "kernel host reserve floor bytes"

@dataclass( frozen=True )
class AdmissionSettings:
    size_cap                 : int
    size_cap_maximum         : int
    batch_cap                : int
    skeleton_crew            : bool
    host_reserve_ratio       : float
    host_reserve_floor_bytes : int

@dataclass( frozen=True )
class AdmissionConfiguration:
    """What one admission decides on: the six dials, the memory table and the three memory settings checked with it."""
    settings        : AdmissionSettings
    memory          : dict
    memory_settings : object

def load_admission_settings( pairs ):
    """
    Ensures: the six admission keys, each present and in range.
    Raises: ConfigurationError, naming the key, for a missing key, a limit that is not a positive whole number, a fleet
            limit above its maximum, a switch that is not `true` or `false`, a ratio outside [ 0, 1 ), or a floor that
            is not a whole number of bytes.
    """
    maximum  = _whole_number( SIZE_CAP_MAXIMUM, _required( pairs, SIZE_CAP_MAXIMUM ) )
    size_cap = _whole_number( SIZE_CAP, _required( pairs, SIZE_CAP ) )
    if size_cap > maximum:
        raise ConfigurationError( SIZE_CAP, f"above its maximum of {maximum}: {size_cap}" )
    batch_cap = _whole_number( BATCH_CAP, _required( pairs, BATCH_CAP ) )
    switch    = _required( pairs, SKELETON_CREW ).strip().lower()
    if switch not in ( "true", "false" ):
        raise ConfigurationError( SKELETON_CREW, f"not true or false: {pairs[ SKELETON_CREW ]!r}" )
    value = _required( pairs, RESERVE_RATIO )
    try:
        ratio = float( value )
    except ValueError:
        raise ConfigurationError( RESERVE_RATIO, f"not a number: {value!r}" ) from None
    if not 0 <= ratio < 1:
        raise ConfigurationError( RESERVE_RATIO, f"outside the range from 0 to below 1: {value!r}" )
    floor = _required( pairs, RESERVE_FLOOR_BYTES )
    if not re.fullmatch( r"[0-9]+", floor.strip() ):
        raise ConfigurationError( RESERVE_FLOOR_BYTES, f"not a whole number of bytes: {floor!r}" )
    return AdmissionSettings( size_cap, maximum, batch_cap, switch == "true", ratio, int( floor ) )

def load_admission_configuration( pairs, engines ):
    return AdmissionConfiguration( load_admission_settings( pairs ), load_memory( pairs, engines ), load_memory_settings( pairs ) )

def file_identity( path ):
    """Ensures: ( inode, size, modification time in nanoseconds ). An atomic replacement changes the inode; an edit in place, the time."""
    status = os.stat( path )
    return ( status.st_ino, status.st_size, status.st_mtime_ns )

class AdmissionConfigurationReader:
    """
    Requires: `manager` is built; `launch_overrides` is the `cli_args` it was built with, or None.
    Ensures:  `current()` returns the configuration for one admission: the one in hand while the file's identity is the
              one last read successfully, otherwise the result of `init()` and a fresh load.
              The identity is stored only after a load that passed its checks, so a refused read is tried again
              at the next admission, and the configuration in hand is the last one that passed.
    Raises:   ConfigurationError from the constructor (the kernel does not start) or from `current()` (that admission
              is refused, `detail.check: configuration`). Whatever `init()` itself raises is not caught.
    Call `current()` inside the registry lock, before the first check.
    """
    def __init__( self, manager, engines, launch_overrides=None ):
        self.manager          = manager
        self.engines          = engines
        self.launch_overrides = launch_overrides
        self.reads            = 0
        self.identity         = file_identity( manager.config_path )
        self.configuration    = self._load()

    def _load( self ):
        pairs = { key: self.manager.get( key ) for key in self.manager.get_keys() }
        return load_admission_configuration( pairs, self.engines )

    def current( self ):
        identity = file_identity( self.manager.config_path )
        if identity != self.identity:
            self.manager.init( silent=True, cli_args=self.launch_overrides )
            self.reads += 1
            self.configuration = self._load()
            self.identity      = identity
        return self.configuration
```

### What follows from them

- **Superseded in the amendment above** ("What follows from them", first bullet): "A read refused for a bad key is therefore made again at the next admission though the file has not changed." It is not: the refused file is read once (ruling 6). The rest of that bullet stands: the configuration in hand is the last one that passed, and running personas are as they were. Its fifth bullet ("once per changed file, not per admission") now holds for a refused file as well.
- **Tables-4** stands; its reference form is now `ABadKeyRefusesTheAdmissionUntilTheFileChanges` in the tests below.
- Measured before the rulings (the probe): one bad key and twenty retries with the file untouched made twenty calls to `init()`; with the module below, one. A wake retried every 15 seconds while the file stays wrong therefore costs the comparison (0.003 ms) and nothing else.
- A repair is seen at the next admission or retry, because any repair changes the file's inode or its modification time. A second bad edit is read once and refused for its own key, and is announced once.
- The kernel calls `announce()` after `get_current()` has raised, in the spawn path and the wake path alike, and speaks the line when one is returned. At the start a bad key stops the kernel (the constructor raises) and nothing is spoken: there is no kernel to speak.
- A deferred wake writes `session.resume_deferred` once and advises its manager once, as a wake deferred for memory does; the retries write nothing.
- "Identity" in `get_file_identity` means which file this is (inode, size, modification time), not who a persona is proven to be (D70, proven persona identity). Rick weighed the two senses at ruling 7 and kept the word.

```python
"""
configuration_reread.py: the admission's settings, read again when the settings file has changed.

Ruled 2026-11-16 (row 60 of "Outstanding actions", under D62 part 10):
  1   the kernel calls `init()` on the one kept ConfigurationManager; no second instance, no guard
  1b  quietly, with the overrides the manager was first built with: `init( silent=True, cli_args=<launch overrides> )`
  1c  the kernel keeps those overrides itself until lupin's manager remembers its own
  2   only when the file has changed: inode, size and modification time compared at each admission
  3   the loader's frozen records are built again; the check list and the persona it admits use the new ones;
      every other consumer keeps the values it took at the start
  4   the six admission keys are required and bounded, like the nine single-valued keys of row 59

Ruled 2026-11-18 (row 71 of "Outstanding actions"; the details the rulings above left unstated):
  1   a refusal for a bad key is `admission_refused` with `detail.check: configuration`, not retryable
  2   its message is one sentence built from the key and the reason; `detail` carries `key` and `reason`
  3   a wake met by a bad key is deferred: `session.resume_deferred { reason: configuration, key }`
  4   any bad admission key defers a wake, whether or not a wake reads it: one record or one error
  5   the human hears one spoken line for each refused state of the file, from a spawn or a wake, whichever is first
  6   a refused file is remembered and not read again until it changes
  7   the names stand

Dependency-free. `manager` is lupin's ConfigurationManager or anything with `init( silent, cli_args )`, `get_keys()`,
`get( key )` and `config_path`.
"""
import os
import re
from dataclasses import dataclass

from configuration_tables import ConfigurationError, _required, _whole_number, load_memory, load_memory_settings

SIZE_CAP            = "kernel fleet size cap"
SIZE_CAP_MAXIMUM    = "kernel fleet size cap maximum"
BATCH_CAP           = "kernel fleet batch cap"
SKELETON_CREW       = "kernel fleet skeleton crew"
RESERVE_RATIO       = "kernel host reserve ratio"
RESERVE_FLOOR_BYTES = "kernel host reserve floor bytes"

@dataclass( frozen=True )
class AdmissionSettings:
    size_cap                 : int
    size_cap_maximum         : int
    batch_cap                : int
    skeleton_crew            : bool
    host_reserve_ratio       : float
    host_reserve_floor_bytes : int

@dataclass( frozen=True )
class AdmissionConfiguration:
    """What one admission decides on: the six dials, the memory table and the three memory settings checked with it."""
    settings        : AdmissionSettings
    memory          : dict
    memory_settings : object

def load_admission_settings( pairs ):
    """
    Ensures: the six admission keys, each present and in range.
    Raises: ConfigurationError, naming the key, for a missing key, a limit that is not a positive whole number, a fleet
            limit above its maximum, a switch that is not `true` or `false`, a ratio outside [ 0, 1 ), or a floor that
            is not a whole number of bytes.
    """
    maximum  = _whole_number( SIZE_CAP_MAXIMUM, _required( pairs, SIZE_CAP_MAXIMUM ) )
    size_cap = _whole_number( SIZE_CAP, _required( pairs, SIZE_CAP ) )
    if size_cap > maximum:
        raise ConfigurationError( SIZE_CAP, f"above its maximum of {maximum}: {size_cap}" )
    batch_cap = _whole_number( BATCH_CAP, _required( pairs, BATCH_CAP ) )
    switch    = _required( pairs, SKELETON_CREW ).strip().lower()
    if switch not in ( "true", "false" ):
        raise ConfigurationError( SKELETON_CREW, f"not true or false: {pairs[ SKELETON_CREW ]!r}" )
    value = _required( pairs, RESERVE_RATIO )
    try:
        ratio = float( value )
    except ValueError:
        raise ConfigurationError( RESERVE_RATIO, f"not a number: {value!r}" ) from None
    if not 0 <= ratio < 1:
        raise ConfigurationError( RESERVE_RATIO, f"outside the range from 0 to below 1: {value!r}" )
    floor = _required( pairs, RESERVE_FLOOR_BYTES )
    if not re.fullmatch( r"[0-9]+", floor.strip() ):
        raise ConfigurationError( RESERVE_FLOOR_BYTES, f"not a whole number of bytes: {floor!r}" )
    return AdmissionSettings( size_cap, maximum, batch_cap, switch == "true", ratio, int( floor ) )

def load_admission_configuration( pairs, engines ):
    return AdmissionConfiguration( load_admission_settings( pairs ), load_memory( pairs, engines ), load_memory_settings( pairs ) )

def get_file_identity( path ):
    """Ensures: ( inode, size, modification time in nanoseconds ). An atomic replacement changes the inode; an edit in place, the time."""
    status = os.stat( path )
    return ( status.st_ino, status.st_size, status.st_mtime_ns )

def build_refusal_message( error ):
    """Ensures: the one sentence a caller is given (control API contract: `message` is a sentence; nothing parses it)."""
    return f'The settings file cannot be used, so nothing is admitted until the key "{error.key}" is corrected ({error.reason}).'

def build_refusal_detail( error ):
    """Ensures: the `detail` of `admission_refused`, which `fleet.refused` carries as its `refusal`."""
    return { "check": "configuration", "key": error.key, "reason": error.reason }

def build_deferred_wake_record( error ):
    """Ensures: the fields of `session.resume_deferred` for a wake met by a bad key."""
    return { "reason": "configuration", "key": error.key }

def build_spoken_line( error ):
    return f"The kernel's settings file has a bad key, {error.key}. Nothing is admitted until it is corrected."

class AdmissionConfigurationReader:
    """
    Requires: `manager` is built; `launch_overrides` is the `cli_args` it was built with, or None.
    Ensures:  `get_current()` returns the configuration for one admission: the one in hand while the file's identity is the
              one last read successfully, otherwise the result of `init()` and a fresh load.
              A load that fails its checks is remembered too, with its error: while the file's identity is the one
              last refused, `get_current()` raises that error again and `init()` is not called. A file is therefore read
              once for each change, good or bad, and the configuration in hand is the last one that passed.
              `announce()` returns the spoken line once for each refused state of the file, then None.
    Raises:   ConfigurationError from the constructor (the kernel does not start) or from `get_current()` (that admission
              is refused, `detail.check: configuration`). Whatever `init()` itself raises is not caught.
    Call `get_current()` inside the registry lock, before the first check.
    """
    def __init__( self, manager, engines, launch_overrides=None ):
        self.manager          = manager
        self.engines          = engines
        self.launch_overrides = launch_overrides
        self.reads            = 0
        self.refused_identity = None
        self.refused_error    = None
        self.announced        = False
        self.identity         = get_file_identity( manager.config_path )
        self.configuration    = self._load()

    def _load( self ):
        pairs = { key: self.manager.get( key ) for key in self.manager.get_keys() }
        return load_admission_configuration( pairs, self.engines )

    def get_current( self ):
        identity = get_file_identity( self.manager.config_path )
        if identity == self.identity:
            self.refused_identity = self.refused_error = None
            return self.configuration
        if identity == self.refused_identity:
            raise ConfigurationError( self.refused_error.key, self.refused_error.reason )
        self.manager.init( silent=True, cli_args=self.launch_overrides )
        self.reads += 1
        try:
            configuration = self._load()
        except ConfigurationError as error:
            self.refused_identity, self.refused_error, self.announced = identity, error, False
            raise
        self.configuration, self.identity = configuration, identity
        self.refused_identity = self.refused_error = None
        return configuration

    def announce( self ):
        """Call after `get_current()` has raised, from a spawn or a wake alike. Ensures: the line to speak, or None."""
        if self.refused_error is None or self.announced:
            return None
        self.announced = True
        return build_spoken_line( self.refused_error )
```

```python
"""
configuration_tables.py: the kernel's two configuration tables, read from flat keys.

Ruled 2026-11-16 (rows 57 and 59 of "Outstanding actions", under D62 part 10): one key per number, the row first and
the quantity last, the model's name normalized, and a refusal for any row that is incomplete or unreadable. The nine
single-valued keys beside the tables (three `kernel memory ...`, six `kernel context pressure ...`) are required and bounded.

    kernel context windows <engine> <model> window tokens   = 1000000
    kernel context windows <engine> <model> ceiling tokens  = 256000
    kernel memory <engine> reserve bytes                    = 2147483648
    kernel memory <engine> cap bytes                        = 8589934592
    kernel memory <engine> heap mebibytes                   = 6144          (optional)

Dependency-free. `pairs` is every key in force with its value, as strings: on lupin's ConfigurationManager,
`{ key: manager.get( key ) for key in manager.get_keys() }`.
"""
import re
from dataclasses import dataclass

CONTEXT_PREFIX     = "kernel context windows"
MEMORY_PREFIX      = "kernel memory"
CONTEXT_QUANTITIES = ( "window tokens", "ceiling tokens" )
MEMORY_REQUIRED    = ( "reserve bytes", "cap bytes" )
MEMORY_OPTIONAL    = ( "heap mebibytes", )
MEMORY_SINGLE_KEYS = ( "notice ratio", "respin ratio", "respin window hours" )     # single-valued keys under the same prefix
PRESSURE_PREFIX    = "kernel context pressure"
PRESSURE_CLASSES   = ( "1m", "200k" )

class ConfigurationError( Exception ):
    """A key under one of the two prefixes cannot be read. The kernel refuses its start, or the admission on a re-read."""
    def __init__( self, key, reason ):
        super().__init__( f"{key}: {reason}" )
        self.key    = key
        self.reason = reason

@dataclass( frozen=True )
class ContextWindow:
    window_tokens  : int
    ceiling_tokens : int

@dataclass( frozen=True )
class EngineMemory:
    reserve_bytes  : int
    cap_bytes      : int
    heap_mebibytes : int | None = None

@dataclass( frozen=True )
class MemorySettings:
    notice_ratio        : float
    respin_ratio        : float
    respin_window_hours : int

@dataclass( frozen=True )
class ContextPressure:
    notice_ratio             : dict          # class ("1m", "200k") to ratio
    respin_ratio             : dict
    class_boundary_tokens    : int
    compaction_drop_fraction : float

def normalize_model_name( name ):
    """
    Ensures: the form of a model's name inside a key: lowercase, a hyphen for each colon, each equals sign and
    each run of spaces. The persona's own model name is untouched everywhere else.
    """
    name = name.strip().lower()
    name = re.sub( r"\s+", "-", name )
    return name.replace( ":", "-" ).replace( "=", "-" )

def build_context_key( engine, model, quantity ):
    return f"{CONTEXT_PREFIX} {engine} {normalize_model_name( model )} {quantity}"

def build_memory_key( engine, quantity ):
    return f"{MEMORY_PREFIX} {engine} {quantity}"

def _select_under( pairs, prefix ):
    return sorted( ( key, value ) for key, value in pairs.items() if key.startswith( prefix + " " ) )

def parse_whole_number( key, value ):
    if not re.fullmatch( r"[0-9]+", value.strip() ) or int( value ) == 0:
        raise ConfigurationError( key, f"not a positive whole number: {value!r}" )
    return int( value )

def _split( key, words, engines, quantities ):
    """Requires: words is the key after its prefix and before nothing. Ensures: ( row words, quantity ), or a refusal."""
    quantity = " ".join( words[ -2: ] )
    if len( words ) < 3 or quantity not in quantities:
        raise ConfigurationError( key, f"not one of the quantities {list( quantities )}" )
    if words[ 0 ] not in engines:
        raise ConfigurationError( key, f"unknown engine {words[ 0 ]!r}" )
    return words[ :-2 ], quantity

def load_context_windows( pairs, engines ):
    """
    Requires: engines is the kernel's own list of engine names.
    Ensures: { ( engine, model ): ContextWindow } for every row under the prefix.
    Raises: ConfigurationError, naming the key, for an unknown quantity or engine, a model's name that is not
            one normalized word, a value that is not a positive whole number, a row lacking either quantity,
            or a ceiling above its window.
    """
    cells = {}
    for key, value in _select_under( pairs, CONTEXT_PREFIX ):
        row, quantity = _split( key, key[ len( CONTEXT_PREFIX ): ].split(), engines, CONTEXT_QUANTITIES )
        if len( row ) != 2 or row[ 1 ] != normalize_model_name( row[ 1 ] ):
            raise ConfigurationError( key, "the row is one engine and one normalized model name" )
        cells.setdefault( tuple( row ), {} )[ quantity ] = parse_whole_number( key, value )
    table = {}
    for ( engine, model ), found in cells.items():
        for quantity in CONTEXT_QUANTITIES:
            if quantity not in found:
                raise ConfigurationError( build_context_key( engine, model, quantity ), "missing: the row is incomplete" )
        if found[ "ceiling tokens" ] > found[ "window tokens" ]:
            raise ConfigurationError( build_context_key( engine, model, "ceiling tokens" ), "the ceiling is above the window" )
        table[ ( engine, model ) ] = ContextWindow( found[ "window tokens" ], found[ "ceiling tokens" ] )
    return table

def get_context_window( table, engine, model ):
    """Ensures: the row, or None for a model the table does not list (`pressure.window_unknown`, Pressure-4)."""
    return table.get( ( engine, normalize_model_name( model ) ) )

def load_memory( pairs, engines ):
    """
    Ensures: { engine: EngineMemory } for every engine with keys under the prefix; the single-valued keys are passed over.
    Raises: ConfigurationError, naming the key, for an unknown quantity or engine, a value that is not a positive
            whole number, a row lacking its reserve or its cap, or a reserve above its cap.
    """
    cells = {}
    for key, value in _select_under( pairs, MEMORY_PREFIX ):
        rest = key[ len( MEMORY_PREFIX ): ].strip()
        if rest in MEMORY_SINGLE_KEYS: continue
        row, quantity = _split( key, rest.split(), engines, MEMORY_REQUIRED + MEMORY_OPTIONAL )
        if len( row ) != 1:
            raise ConfigurationError( key, "the row is one engine" )
        cells.setdefault( row[ 0 ], {} )[ quantity ] = parse_whole_number( key, value )
    table = {}
    for engine, found in cells.items():
        for quantity in MEMORY_REQUIRED:
            if quantity not in found:
                raise ConfigurationError( build_memory_key( engine, quantity ), "missing: the row is incomplete" )
        if found[ "reserve bytes" ] > found[ "cap bytes" ]:
            raise ConfigurationError( build_memory_key( engine, "reserve bytes" ), "the reserve is above the cap" )
        table[ engine ] = EngineMemory( found[ "reserve bytes" ], found[ "cap bytes" ], found.get( "heap mebibytes" ) )
    return table

def get_engine_memory( table, engine ):
    """Raises: ConfigurationError for an engine with no row: nothing can be reserved for it, so it is not admitted."""
    if engine not in table:
        raise ConfigurationError( build_memory_key( engine, "reserve bytes" ), "missing: the engine has no row" )
    return table[ engine ]

def get_required_value( pairs, key ):
    if key not in pairs:
        raise ConfigurationError( key, "missing: the key is required" )
    return pairs[ key ]

def _parse_fraction( pairs, key, closed ):
    """Ensures: a number above 0 and at most 1 (closed) or below 1 (not closed)."""
    value = get_required_value( pairs, key )
    try:
        number = float( value )
    except ValueError:
        raise ConfigurationError( key, f"not a number: {value!r}" ) from None
    if not ( 0 < number <= 1 if closed else 0 < number < 1 ):
        raise ConfigurationError( key, f"outside the range above 0 and {'at most' if closed else 'below'} 1: {value!r}" )
    return number

def _check_notice_below_respin( pairs, notice_key, respin_key ):
    notice, respin = _parse_fraction( pairs, notice_key, True ), _parse_fraction( pairs, respin_key, True )
    if not notice < respin:
        raise ConfigurationError( notice_key, "the notice ratio is not below the respin ratio" )
    return notice, respin

def load_memory_settings( pairs ):
    """
    Ensures: the three single-valued `kernel memory ...` keys, each present and in range.
    Raises: ConfigurationError, naming the key, for a missing key, a ratio outside ( 0, 1 ], a notice ratio not below
            the respin ratio, or a window that is not a positive whole number of hours.
    """
    notice, respin = _check_notice_below_respin( pairs, f"{MEMORY_PREFIX} notice ratio", f"{MEMORY_PREFIX} respin ratio" )
    key = f"{MEMORY_PREFIX} respin window hours"
    return MemorySettings( notice, respin, parse_whole_number( key, get_required_value( pairs, key ) ) )

def load_context_pressure( pairs ):
    """
    Ensures: the six `kernel context pressure ...` keys, each present and in range.
    Raises: ConfigurationError, naming the key, for a missing key, a ratio outside ( 0, 1 ], a class whose notice ratio
            is not below its respin ratio, a boundary that is not a positive whole number, or a drop fraction outside ( 0, 1 ).
    """
    notice, respin = {}, {}
    for name in PRESSURE_CLASSES:
        notice[ name ], respin[ name ] = _check_notice_below_respin( pairs, f"{PRESSURE_PREFIX} notice ratio {name} class", f"{PRESSURE_PREFIX} respin ratio {name} class" )
    boundary = f"{PRESSURE_PREFIX} class boundary tokens"
    return ContextPressure( notice, respin, parse_whole_number( boundary, get_required_value( pairs, boundary ) ),
                            _parse_fraction( pairs, f"{PRESSURE_PREFIX} compaction drop fraction", False ) )

def build_context_lines( rows ):
    """Requires: rows of ( engine, model, window, ceiling ). Ensures: the file's lines, two per row, aligned."""
    keys = [ ( build_context_key( e, m, q ), v ) for e, m, w, c in rows for q, v in zip( CONTEXT_QUANTITIES, ( w, c ) ) ]
    return _align_lines( keys )

def build_memory_lines( rows ):
    """Requires: rows of ( engine, reserve, cap, heap or None ). Ensures: the file's lines; no line for an absent heap."""
    keys = [ ( build_memory_key( e, q ), v ) for e, r, c, h in rows for q, v in zip( MEMORY_REQUIRED + MEMORY_OPTIONAL, ( r, c, h ) ) if v is not None ]
    return _align_lines( keys )

def _align_lines( keys ):
    width = max( len( key ) for key, _ in keys )
    return [ f"{key.ljust( width )} = {value}" for key, value in keys ]
```

```python
    size_cap_maximum         : int

def load_admission_settings( pairs ):
    """
    Ensures: the six admission keys, each present and in range.
    Raises: ConfigurationError, naming the key, for a missing key, a limit that is not a positive whole number, a fleet
            limit above its maximum, a switch that is not `true` or `false`, a ratio outside [ 0, 1 ), or a floor that
            is not a whole number of bytes.
    """
    maximum  = parse_whole_number( SIZE_CAP_MAXIMUM, get_required_value( pairs, SIZE_CAP_MAXIMUM ) )
    size_cap = parse_whole_number( SIZE_CAP, get_required_value( pairs, SIZE_CAP ) )
    if size_cap > maximum:
        raise ConfigurationError( SIZE_CAP, f"above its maximum of {maximum}: {size_cap}" )
    batch_cap = parse_whole_number( BATCH_CAP, get_required_value( pairs, BATCH_CAP ) )
    switch    = get_required_value( pairs, SKELETON_CREW ).strip().lower()
    if switch not in ( "true", "false" ):
        raise ConfigurationError( SKELETON_CREW, f"not true or false: {pairs[ SKELETON_CREW ]!r}" )
    value = get_required_value( pairs, RESERVE_RATIO )
    try:
        ratio = float( value )
    except ValueError:
        raise ConfigurationError( RESERVE_RATIO, f"not a number: {value!r}" ) from None
    if not 0 <= ratio < 1:
        raise ConfigurationError( RESERVE_RATIO, f"outside the range from 0 to below 1: {value!r}" )
    floor = get_required_value( pairs, RESERVE_FLOOR_BYTES )
    if not re.fullmatch( r"[0-9]+", floor.strip() ):
        raise ConfigurationError( RESERVE_FLOOR_BYTES, f"not a whole number of bytes: {floor!r}" )
    return AdmissionSettings( size_cap, maximum, batch_cap, switch == "true", ratio, int( floor ) )

def get_file_identity( path ):
    """Ensures: ( inode, size, modification time in nanoseconds ). An atomic replacement changes the inode; an edit in place, the time."""
    status = os.stat( path )
    return ( status.st_ino, status.st_size, status.st_mtime_ns )

    return f"The kernel's settings file has a bad key, {error.key}. Nothing is admitted until it is corrected."

class AdmissionConfigurationReader:
    """
    Requires: `manager` is built; `launch_overrides` is the `cli_args` it was built with, or None.
    Ensures:  `get_current()` returns the configuration for one admission: the one in hand while the file's identity is the
              one last read successfully, otherwise the result of `init()` and a fresh load.
              A load that fails its checks is remembered too, with its error: while the file's identity is the one
              last refused, `get_current()` raises that error again and `init()` is not called. A file is therefore read
              once for each change, good or bad, and the configuration in hand is the last one that passed.
              `announce()` returns the spoken line once for each refused state of the file, then None.
    Raises:   ConfigurationError from the constructor (the kernel does not start) or from `get_current()` (that admission
              is refused, `detail.check: configuration`). Whatever `init()` itself raises is not caught.
    Call `get_current()` inside the registry lock, before the first check.
    """
    def __init__( self, manager, engines, launch_overrides=None ):
        self.manager          = manager
        self.engines          = engines
        self.launch_overrides = launch_overrides
        self.reads            = 0
        self.refused_identity = None
        self.refused_error    = None
        self.announced        = False
        self.identity         = get_file_identity( manager.config_path )
        self.configuration    = self._load()

    def _load( self ):
        pairs = { key: self.manager.get( key ) for key in self.manager.get_keys() }
        return load_admission_configuration( pairs, self.engines )

    def get_current( self ):
        identity = get_file_identity( self.manager.config_path )
        if identity == self.identity:
            self.refused_identity = self.refused_error = None
            return self.configuration
        if identity == self.refused_identity:
            raise ConfigurationError( self.refused_error.key, self.refused_error.reason )
        self.manager.init( silent=True, cli_args=self.launch_overrides )
        self.reads += 1
        try:
            configuration = self._load()
        except ConfigurationError as error:
            self.refused_identity, self.refused_error, self.announced = identity, error, False
            raise
        self.configuration, self.identity = configuration, identity
        self.refused_identity = self.refused_error = None
        return configuration

    def announce( self ):
        """Call after `get_current()` has raised, from a spawn or a wake alike. Ensures: the line to speak, or None."""
        if self.refused_error is None or self.announced:
            return None
        self.announced = True
        return build_spoken_line( self.refused_error )
```

```python
"""
deferred_wake.py: what a deferred wake says, to whom and how loudly, by its cause.

Ruled 2026-11-20 (row 104 of "Outstanding actions", under D62 part 10):
  2   the manager's line has one form: whose wake, why, that the message is kept, what ends the wait; it asks for nothing
  3   by cause, without interrupting the manager: a broken settings file is `priority: high`, `type: alert`, and the manager's
      `kernel` block is headed `alert deferred`; no room on the host is `priority: low`, `type: info`, and the block is headed
      `report deferred`; a persona with no manager tells the human by one card at the same priority

Worded for the two causes Kernel-1 builds. The two sign-in and quota causes (`engine_login`, `engine_quota`) have no ruled
words yet and are refused here, so that nothing invents them.

Dependency-free.
"""
CONFIGURATION = "configuration"
HOST_CAPACITY = "host_capacity"

NOTICE_LEVELS = { CONFIGURATION: ( "high", "alert" ), HOST_CAPACITY: ( "low", "info" ) }
BLOCK_WORDS   = { CONFIGURATION: "alert deferred", HOST_CAPACITY: "report deferred" }
CAUSES        = { CONFIGURATION: "the kernel's settings file has a bad key, {key}", HOST_CAPACITY: "the host has no room for it" }
REMEDIES      = { CONFIGURATION: "the file is corrected", HOST_CAPACITY: "room is freed" }

def check_reason( reason ):
    """Raises: ValueError for a cause whose words are not ruled."""
    if reason not in NOTICE_LEVELS:
        raise ValueError( f"no line is ruled for a wake deferred by {reason!r}" )

def get_notice_level( reason ):
    """Ensures: ( priority, type ) of the line the human hears and of the card that stands in for a missing manager."""
    check_reason( reason )
    return NOTICE_LEVELS[ reason ]

def build_manager_sentence( name, reason, key=None ):
    """Ensures: the body of the manager's block, two sentences. `key` is the key at fault, for `configuration` alone."""
    check_reason( reason )
    if ( reason == CONFIGURATION ) != ( key is not None ):
        raise ValueError( "a key is named for a broken settings file and for nothing else" )
    return f"{name}'s wake is deferred: {CAUSES[ reason ].format( key=key )}. Its message is kept, and it wakes when {REMEDIES[ reason ]}."

def build_manager_block( hhmmss, persona_id, name, reason, key=None ):
    """Ensures: the `kernel` block written to the manager's inbox, not urgent: it never interrupts a turn."""
    return f"[kernel {hhmmss} {BLOCK_WORDS[ reason ]} {persona_id}]\n" + build_manager_sentence( name, reason, key )

def build_human_card( name, reason, key=None ):
    """Ensures: the one card for a deferred persona that has no manager."""
    priority, kind = get_notice_level( reason )
    return { "text": build_manager_sentence( name, reason, key ), "priority": priority, "type": kind }
```

```ini
kernel engine pool name third party models  = The name in words the kernel uses for the usage meter's pool "Third-Party Models". Optional; a blank value is refused. Without this setting the pool goes by the meter's own name.
kernel lupin url                            = The Lupin server the kernel speaks to: http or https, a host, and a port when one is needed, as in http://localhost:8000. Required, with no default, so that no kernel reaches a server by omission. Nothing follows the port, and no credential is written here. Read at the kernel's start.
kernel lupin key file                       = The full path of the file that holds the key the kernel sends to Lupin; a leading ~ is the home folder. The key itself is never written in configuration. Required, with no default. The file holds one key and nothing else. Read at the kernel's start.
```

```python
"""
configuration_splainer.py: what a refusal of a kernel setting says about the setting, from lupin's splainer file.

Ruling of 2026-11-24 (rows 133 and 136 of "Outstanding actions", decision 16, raised by Rick; recorded under D62,
turn-end policy, part 10): every refusal of a kernel setting carries the setting's line from `lupin-app-splainer.ini`
after the kernel's own sentence, whether the setting is missing, blank or holds a bad value; and every amendment that
adds a setting writes its line.

The kernel's modules are handed every setting at once and raise `ConfigurationError( key, reason )`; none of them
changes. The line is joined where a refusal is reported: the kernel's start prints `build_refusal_text`, and the
`detail` of a refused admission carries `get_splainer_line` as its `splainer` field.

A setting is looked up by its exact name, as lupin's own splainer holds one line for each setting (995 of the 999
settings in `lupin-app.ini` at `89d6a56115`, the 65 `cc session voice persona …` settings among them, and no name
with a placeholder). Whoever writes a setting writes its line; a setting with none is said to have none, and
`find_unexplained_settings` is what a test of the two files asserts is empty.

Dependency-free. `lines` maps each name in the splainer's `[default]` section to its line, as lupin's reader holds it
(`dict( manager.splainer.items( "default" ) )`).
"""
SPLAINER_FILE = "lupin-app-splainer.ini"

def get_splainer_line( lines, key ):
    """Ensures: the setting's own line, or None when the splainer has none or a blank one: the `splainer` field of a
    refused admission's `detail`."""
    return lines.get( key, "" ).strip() or None

def build_refusal_text( error, lines ):
    """
    Requires: error is a ConfigurationError (its `key` and `reason`)
    Ensures : what the operator reads when the kernel refuses a setting: the kernel's own sentence, then the
              splainer's line in Lupin's own form, or the statement that the splainer has none
    """
    line = get_splainer_line( lines, error.key )
    if line is None:
        return f"{error.key}: {error.reason}\n'Splainer says: no line for [{error.key}] in {SPLAINER_FILE}"
    return f"{error.key}: {error.reason}\n'Splainer says: [{error.key}] = {line}"

def find_unexplained_settings( lines, keys ):
    """Ensures: the settings among `keys` that have no line, in order: what a test of the two files asserts is empty."""
    return [ key for key in keys if get_splainer_line( lines, key ) is None ]
```

```python
import configparser
import os
import unittest

def read_lines():
    """As lupin's reader loads its splainer: one ConfigParser, the `[default]` section."""
    parser = configparser.ConfigParser()
    parser.read( os.path.join( os.path.dirname( os.path.abspath( __file__ ) ), "kernel_splainer_lines.ini" ) )
    return dict( parser.items( "default" ) )

LINES    = read_lines()
REQUIRED = ( *TIMING_KEYS, OVERAGE, LUPIN_URL, LUPIN_KEY_FILE )
POOL     = "kernel engine pool name third party models"

class TheLinesOfTheSettingsRuledOn20261123( unittest.TestCase ):

    def test_eight_lines_parse_as_lupins_reader_parses_them( self ):
        self.assertEqual( sorted( LINES ), sorted( ( *REQUIRED, POOL ) ) )
        for name, line in LINES.items():
            self.assertTrue( line.endswith( "." ), name )

    def test_each_of_the_seven_required_settings_and_the_one_pool_name_has_a_line_of_its_own( self ):
        self.assertEqual( find_unexplained_settings( LINES, ( *REQUIRED, POOL ) ), [] )

    def test_no_name_in_the_splainer_holds_a_placeholder( self ):
        for name in LINES:
            self.assertNotRegex( name, r"[<>{}*\[\]]" )

class ASettingIsExplainedByItsOwnLineAndNoOther( unittest.TestCase ):

    def test_a_setting_with_no_line_is_never_explained_by_a_sibling( self ):
        lines = { "kernel engine quota reserve": "The share of the lowest clock held back." }
        self.assertIsNone( get_splainer_line( lines, "kernel engine quota reserve mode" ) )
        self.assertEqual( find_unexplained_settings( lines, [ "kernel engine quota reserve", "kernel engine quota reserve mode" ] ), [ "kernel engine quota reserve mode" ] )

    def test_a_pool_or_a_price_that_is_written_without_its_line_is_unexplained( self ):
        keys = [ "kernel engine pool name gemini pro next", *( build_price_key( "claude-fable-5.2", quantity ) for quantity in ( "input", "output", "cache read" ) ) ]
        self.assertEqual( find_unexplained_settings( LINES, keys ), keys )

    def test_a_blank_line_is_no_line( self ):
        self.assertIsNone( get_splainer_line( { LUPIN_URL: "  " }, LUPIN_URL ) )

class ARefusalCarriesTheSettingsLine( unittest.TestCase ):

    def get_refusal( self, load, pairs ):
        with self.assertRaises( ConfigurationError ) as caught: load( pairs )
        return caught.exception

    def test_a_missing_setting_is_refused_in_the_kernels_sentence_then_the_splainers( self ):
        text = build_refusal_text( self.get_refusal( load_lupin_connection, {} ), LINES )
        self.assertEqual( text, f"kernel lupin url: missing: the key is required\n'Splainer says: [kernel lupin url] = {LINES[ LUPIN_URL ]}" )

    def test_a_bad_value_carries_the_line_as_a_missing_setting_does( self ):

        text    = build_refusal_text( self.get_refusal( load_account_timings, timings ), LINES )
        self.assertEqual( text.splitlines(), [ "kernel engine meter seconds: not a whole number of at least 60: '59'",
                                               f"'Splainer says: [kernel engine meter seconds] = {LINES[ TIMING_KEYS[ 0 ] ]}" ] )

        error = ConfigurationError( "kernel fleet size cap", "missing: the key is required" )
        self.assertEqual( build_refusal_text( error, LINES ), f"kernel fleet size cap: missing: the key is required\n'Splainer says: no line for [kernel fleet size cap] in {SPLAINER_FILE}" )

        error  = self.get_refusal( parse_overage, { OVERAGE: "sometimes" } )
        detail = { **build_refusal_detail( error ), "splainer": get_splainer_line( LINES, error.key ) }
        self.assertEqual( detail, { "check": "configuration", "key": OVERAGE, "reason": "not one of never, allow: 'sometimes'", "splainer": LINES[ OVERAGE ] } )
        self.assertIsNone( get_splainer_line( {}, OVERAGE ) )

if __name__ == "__main__":
    unittest.main()
```
