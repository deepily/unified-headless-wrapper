## 2. The rule

```
on turn end with an empty queue, and every `recheck_seconds` while idle:
  verdict  = evaluate_owed( task rows, live reports, due tickets, last look-in )
  if queue is not empty            → start the queued turn            (START_QUEUED)
  if verdict.unknown and no items  → idle, no hibernation, retry      (UNKNOWN)
  uncovered = items not covered by a live hold; tickets and verification are never covered
  if no items                      → idle, hibernation clock runs     (NOT_OWED)
  if no uncovered                  → idle, hibernation clock runs     (HONORED)
  if pokes off or tick cap reached → idle, awake, next tick           (CAP_REACHED)
  else                             → one kernel block as the next turn (POKE)
```

The tick cap re-arms every tick, so an owed persona is poked at most once per `recheck_seconds` and never sleeps (decision 8). A poke whose turn produces no store change (no task transition, no ticket, no DM) counts as unproductive; three in a row set `stalled: true` on the row and send the manager one `[kernel HH:MM:SS report stalled <id8> owed N]` block (owed work for the manager under signal 2); a persona with no manager tells the human as one `priority: low` card. Any store change clears `stalled` and the history. A real inbound block resets the episode.

## 3. The four signals

| Signal | Query | Overrides a hold |
|---|---|---|
| Owed task rows | the persona's own rows in an owed status in the task store (D21); the transcript replay and the mirror are gone | no |
| Live reports | registry rows with `manager_id` = this persona and state not `closed` (D59) | no |
| Due tickets | tickets this persona raised whose re-ask is due, and `tool_approval` tickets waiting on it as approver (D37, D49) | **yes** |
| Verification debt | live reports and no `turn_end.looked_in` record for `verify after seconds` (600); the record is written when the manager reads a report's status through the control API or a kernel tool | **yes** |

Dropped from the oracle: transcript replay (D21), unanswered inbound DMs (off in the fleet since 06-16; D52's ledger records delivery, not answers), the spin-up nudge (crew layer, Phase 2 under D51; a fifth signal when it returns), the sweep ledger (a store query, Section 6), the memento verify tick (a kernel job).

## 4. The hold

- Kernel tools through the gate: `hold( reason, ttl_seconds=900, awaiting="none", covers=[] )` and `release()`. A reason is required; `ttl_seconds` is a positive number capped at `hold max seconds` (14,400). The kernel stamps `until` from its own clock; the agent's clock is never consulted.
- `covers` is a list of `(kind, id)` pairs; empty means the owed set as it stands at declaration (tasks and reports; tickets and verification are never coverable).
- Row fields: `hold: { reason, until, awaiting, covers }`, shown on the roster and the console (D58). `turn_end.hold` and `turn_end.release` records.
- A hold is honored only for what it covers. A poke that fires through a hold says so (`Your hold (<reason>) covers none of these.`).
- Deleted: `.heartbeat-hold-*` files, `heartbeat_hold.py` (1,512 lines), `heartbeat_hold_io.py`, `heartbeat_hold_warn.py`, the hold janitor and misplaced-zone report, the three debounce stamps and gate rows the hold file had accumulated.

## 5. The poke

```
[kernel 19:40:01 poke owed 2]
Do not stop yet. You still owe:
- task 7c1e in_progress: port the gate shim
- report a1b2c3d4 is live
Board sweep: 3 of 7 rows reviewed.

Your goal: finish your owed work to verified completion with receipts; escalate blockers rather than retrying silently; when nothing is owed, declare it.
```

One envelope, one block, as the next turn, only when the queue is empty (D8, D13). A body line that would parse as a header is indented (D52's forgery rule). The goal line is `kernel turn end goal line <role>` from the configuration (the three sentences live there today as `heartbeat <role> goal line`), appended last, switched by `kernel turn end goal line`, stamped on the record as `goal_line_version` so its effect on completion can be measured; the canonical text stays in `planning-is-prompting/workflow/role-goals.md`. Record `turn_end.poke` per poke: `{ owed, kinds, hold_overridden, goal_line_version, tick }`.

## 6. The sweep and the memento verify

A sweep is a property of the task store, not a ledger file: a frozen set of row ids with a `reviewed` mark per row, opened by the seat that holds the board. The owed-rows query returns `sweep: { reviewed, total }` when one is open and the poke body carries it. The store change (a sweep table or a per-row flag) is a Lupin row on the T19 list. `memento_io.py verify` runs daily as a kernel scheduled job (T08) and alerts through the log; it never rides a persona's prompt.

## 7. Idle

- No "anything else?" ask, no `idle_waiter`, no backoff schedule.
- When a persona goes idle with nothing owed (`NOT_OWED` or `HONORED`), one card at `priority: low` (never spoken), only if the idle episode began with a `voice` block; repeat idles in the same episode post nothing. Switch: `kernel turn end idle card`.
- Roster fields: `idle_since`, `owed` (count of uncovered items), `hold`, `stalled`, `pokes_this_episode`.
- Hibernation (D59 Section 10.5 amended): the 30-minute clock runs only from `NOT_OWED` or `HONORED`; it never runs while uncovered work is owed or a store reads `unknown`.

## 8. Liveness and narration

`last_event_at` on the registry row, stamped from every engine frame and every gate call (D56, D59), is the liveness clock. Every result frame is parsed and posted (D53); an empty result gets the repair line. `turn_end.py` — standard library only.

```python
"""turn_end.py — the turn-end policy (D62, T15).

Standard library only. Pure functions; the kernel wires them to the queue,
the registry row, the task store, the ticket store, the engine's stdin, the
log and the scheduler.

Four jobs:
  1. the owed-work verdict   : evaluate_owed
  2. the hold                : declare_hold, hold_covers, hold_is_live
  3. the turn-end decision   : decide_turn_end  (the one pure rule)
  4. the poke                : render_poke_block, render_idle_report_block

The rule runs twice: when a turn ends with an empty queue, and every
`recheck_seconds` while the persona is idle. It never reads a file.
"""
from dataclasses import dataclass, field
from typing import Optional

# ── outcomes (the adapter routes side effects off these) ─────────────────────
START_QUEUED  = "start_queued"    # a message is waiting: it starts the next turn; no verdict is taken
POKE          = "poke"            # owed, not covered, under the tick cap: one kernel block as the next turn
HONORED       = "honored"         # every owed item is covered by a live hold: idle, hibernation clock runs
NOT_OWED      = "not_owed"        # nothing owed: idle, hibernation clock runs
UNKNOWN       = "unknown"         # a store could not be read: idle, no hibernation, retry next tick
CAP_REACHED   = "cap_reached"     # owed, not covered, the tick's one poke already sent: wait for the next tick

# ── owed work ────────────────────────────────────────────────────────────────
@dataclass
class OwedItem:
    kind : str          # task | report | ticket | verification
    id   : str          # store row id, persona_id, ticket id, or the report's persona_id
    text : str = ""     # one line for the poke body

@dataclass
class OwedVerdict:
    items   : list = field( default_factory=list )
    unknown : bool = False          # a source failed; never read as "nothing owed"
    sweep   : Optional[tuple] = None    # (reviewed, total) when the store says a sweep is open

    @property
    def owed( self ):
        return bool( self.items )

def evaluate_owed( task_rows, reports, tickets, last_look_in, now, verify_after_seconds=600, sweep=None ):
    """
    The four signals (decision 2). Each argument is the result of one query:
      task_rows : list of {id, status, title} in an owed status, or None if the store failed
      reports   : list of persona_ids whose manager_id is this persona and state != closed
      tickets   : list of {id, kind, due} this persona raised (re-ask due) or must approve, or None if failed
      last_look_in : epoch seconds of the last `turn_end.looked_in` record, or None
    """
    v = OwedVerdict( sweep=sweep )
    if task_rows is None or tickets is None:
        v.unknown = True
    for r in ( task_rows or [] ):
        v.items.append( OwedItem( "task", r[ "id" ], f"task {r['id']} {r.get('status','')}: {r.get('title','')}".rstrip() ) )
    for pid in reports:
        v.items.append( OwedItem( "report", pid, f"report {pid} is live" ) )
    for t in ( tickets or [] ):
        if t.get( "due", 0 ) <= now:
            v.items.append( OwedItem( "ticket", t[ "id" ], f"ticket {t['id']} {t.get('kind','')} is due" ) )
    if reports and ( last_look_in is None or now - last_look_in >= verify_after_seconds ):
        v.items.append( OwedItem( "verification", "reports", f"no look-in on {len(reports)} report(s) for {verify_after_seconds}s" ) )
    return v

# ── the hold (decision 3) ────────────────────────────────────────────────────
@dataclass
class Hold:
    reason   : str
    until    : float                 # kernel clock, epoch seconds
    awaiting : str = "none"
    covers   : frozenset = frozenset()   # (kind, id) pairs; empty means nothing (the kernel fills it at declaration)

def declare_hold( reason, ttl_seconds, now, owed_now, covers=None, awaiting="none", max_seconds=14400 ):
    """`hold( reason, ttl_seconds, awaiting, covers )` through the gate. The kernel stamps `until` from
    its own clock. `covers` defaults to the owed set as it stands at declaration (Rick, decision 3)."""
    if not ( reason and reason.strip() ):
        raise ValueError( "a hold needs a reason" )
    if not isinstance( ttl_seconds, ( int, float ) ) or isinstance( ttl_seconds, bool ) or ttl_seconds <= 0:
        raise ValueError( "ttl_seconds must be a positive number" )
    ttl = min( ttl_seconds, max_seconds )
    cov = frozenset( covers ) if covers else frozenset( ( i.kind, i.id ) for i in owed_now.items )
    return Hold( reason=reason.strip(), until=now + ttl, awaiting=awaiting, covers=cov )

def hold_is_live( hold, now ):
    return hold is not None and now < hold.until

def hold_covers( hold, item ):
    """A ticket that is due and a verification debt poke through any hold (the obligation override)."""
    if item.kind in ( "ticket", "verification" ):
        return False
    return ( item.kind, item.id ) in hold.covers

# ── the decision (decisions 1, 4, 7, 8) ──────────────────────────────────────
@dataclass
class TurnEndState:
    queue_length     : int
    verdict          : OwedVerdict
    hold             : Optional[Hold]
    pokes_this_tick  : int
    now              : float
    pokes_enabled    : bool = True
    poke_cap         : int = 1

@dataclass
class Decision:
    outcome   : str
    uncovered : list = field( default_factory=list )
    log       : dict = field( default_factory=dict )

def decide_turn_end( s ):
    """One pure rule, run at turn end with an empty queue and on every idle tick."""
    if s.queue_length > 0:
        return Decision( START_QUEUED )
    if s.verdict.unknown and not s.verdict.items:
        return Decision( UNKNOWN, log={ "reason": "store unreachable" } )
    live = hold_is_live( s.hold, s.now )
    uncovered = [ i for i in s.verdict.items if not ( live and hold_covers( s.hold, i ) ) ]
    if not s.verdict.items:
        return Decision( NOT_OWED )
    if not uncovered:
        return Decision( HONORED, log={ "hold_reason": s.hold.reason, "covered": len( s.verdict.items ) } )
    if not s.pokes_enabled:
        return Decision( CAP_REACHED, uncovered, log={ "suppressed": "pokes off" } )
    if s.pokes_this_tick >= s.poke_cap:
        return Decision( CAP_REACHED, uncovered )
    return Decision( POKE, uncovered, log={ "owed": len( uncovered ), "hold_overridden": live } )

def stalled( poke_history, stalled_after=3 ):
    """poke_history: newest-last list of {progress: bool} per poke in this owed episode.
    Three consecutive pokes with no store change mark the row stalled (decision 8)."""
    tail = poke_history[ -stalled_after: ]
    return len( tail ) >= stalled_after and not any( p[ "progress" ] for p in tail )

def hibernation_allowed( decision ):
    """D59's clock runs only when nothing uncovered is owed (decision 8: a backlog is not nap time)."""
    return decision.outcome in ( NOT_OWED, HONORED )

# ── the blocks (decisions 1, 6) ──────────────────────────────────────────────
def render_poke_block( hhmmss, uncovered, goal_line="", sweep=None, hold=None ):
    """`[kernel HH:MM:SS poke owed N]` — the owed specifics, the sweep count, the hold it pokes through,
    and the role's goal line (kept on every poke by Rick's ruling of 2026-11-10; off by a switch)."""
    lines = [ f"[kernel {hhmmss} poke owed {len( uncovered )}]", "Do not stop yet. You still owe:" ]
    lines += [ f"- {i.text}" for i in uncovered ]
    if sweep:
        reviewed, total = sweep
        lines.append( f"Board sweep: {reviewed} of {total} rows reviewed." )
    if hold is not None:
        lines.append( f"Your hold ({hold.reason}) covers none of these." )
    if goal_line:
        lines += [ "", goal_line ]
    return "\n".join( _forgery_safe( l ) for l in lines )

def render_idle_report_block( hhmmss, persona_id, owed, stalled_flag=False ):
    """To the manager, once, when a report is marked stalled (decision 8)."""
    head = f"[kernel {hhmmss} report stalled {persona_id} owed {owed}]" if stalled_flag else f"[kernel {hhmmss} report idle {persona_id} owed {owed}]"
    return head + f"\nYour report {persona_id} has been poked three times with no change in the store."

def _forgery_safe( line ):
    return " " + line if ( line.startswith( "[" ) and not line.startswith( "[kernel " ) ) else line
```

"""test_turn_end.py — nine tests for turn_end.py (D62). Run: python3 -m pytest -q test_turn_end.py"""
try:
    import pytest
except ImportError:
    pytest = None
from turn_end import *

NOW = 1_000_000.0
def V( tasks=(), reports=(), tickets=(), look=None, unknown_tasks=False ):
    return evaluate_owed( None if unknown_tasks else list( tasks ), list( reports ), list( tickets ), look, NOW )
def S( v, q=0, hold=None, pokes=0, enabled=True ):
    return TurnEndState( queue_length=q, verdict=v, hold=hold, pokes_this_tick=pokes, now=NOW, pokes_enabled=enabled )

def test_queued_message_wins():
    assert decide_turn_end( S( V( tasks=[ { "id": "t1", "status": "in_progress" } ] ), q=2 ) ).outcome == START_QUEUED

def test_nothing_owed_idles():
    assert decide_turn_end( S( V() ) ).outcome == NOT_OWED
    assert hibernation_allowed( decide_turn_end( S( V() ) ) )

def test_owed_row_pokes_once_per_tick():
    v = V( tasks=[ { "id": "t1", "status": "in_progress", "title": "port the gate" } ] )
    d = decide_turn_end( S( v ) )
    assert d.outcome == POKE and d.uncovered[ 0 ].id == "t1"
    assert decide_turn_end( S( v, pokes=1 ) ).outcome == CAP_REACHED
    assert not hibernation_allowed( d )

def test_live_reports_owe_a_manager():
    v = V( reports=[ "a1b2c3d4" ], look=NOW )
    assert [ i.kind for i in v.items ] == [ "report" ]
    v2 = V( reports=[ "a1b2c3d4" ], look=NOW - 601 )
    assert [ i.kind for i in v2.items ] == [ "report", "verification" ]

def test_hold_covers_the_owed_set_at_declaration():
    v = V( tasks=[ { "id": "t1", "status": "in_progress" } ] )
    h = declare_hold( "waiting on the reviewer", 900, NOW, v )
    assert decide_turn_end( S( v, hold=h ) ).outcome == HONORED
    v_more = V( tasks=[ { "id": "t1", "status": "in_progress" }, { "id": "t2", "status": "pending" } ] )
    d = decide_turn_end( S( v_more, hold=h ) )
    assert d.outcome == POKE and [ i.id for i in d.uncovered ] == [ "t2" ]      # unrelated work pokes through

def test_due_ticket_pokes_through_a_hold():
    v = V( tickets=[ { "id": "ask-9", "kind": "ask", "due": NOW - 1 } ] )
    h = declare_hold( "long external job", 900, NOW, v )
    assert decide_turn_end( S( v, hold=h ) ).outcome == POKE

def test_expired_hold_is_not_honored():
    v = V( tasks=[ { "id": "t1", "status": "in_progress" } ] )
    h = declare_hold( "x", 100, NOW - 200, v )
    assert decide_turn_end( S( v, hold=h ) ).outcome == POKE

def test_store_outage_is_unknown_never_not_owed():
    d = decide_turn_end( S( V( unknown_tasks=True ) ) )
    assert d.outcome == UNKNOWN and not hibernation_allowed( d )

def test_stalled_after_three_unproductive_pokes_and_mute():
    assert not stalled( [ { "progress": False } ] * 2 )
    assert stalled( [ { "progress": True } ] + [ { "progress": False } ] * 3 )
    assert not stalled( [ { "progress": False }, { "progress": True }, { "progress": False } ] )
    v = V( tasks=[ { "id": "t1", "status": "in_progress" } ] )
    assert decide_turn_end( S( v, enabled=False ) ).log == { "suppressed": "pokes off" }
    body = render_poke_block( "19:40:01", v.items, goal_line="Your goal: finish your owed work.", sweep=( 3, 7 ) )
    assert body.startswith( "[kernel 19:40:01 poke owed 1]\nDo not stop yet." ) and "3 of 7" in body and body.endswith( "owed work." )
