## 1. Summary of the rulings

| # | Ruling | Section |
| --- | --- | --- |
| 1 | **One error body.** `{ error: { code, message, retryable, detail } }`, an HTTP status by class, a closed catalogue of codes. *Refused before anything changed* is an error; *done, with an outcome worth reading* is a 200 with a status word. `message` is one sentence, handed to a model unchanged. | 4 |
| 2 | **Three kernel states,** `starting \| ready \| stopping`, on `/health`. Starting: all else 503 `kernel_starting`. Stopping: reads, `/gate` and the hold answer until the last engine ends; fleet-changing routes 503 `kernel_stopping`. A retry budget per caller. | 5 |
| 3 | **One contract number,** an integer from 1. Additions are free; a removal, rename or retype raises it. `api_version` and `api_minimum` on `/health` and in `Lupin-Kernel-Api`; every caller sends `Lupin-Client: <name>/<build> api=<n>`; out of range is 426. A schema test holds the rule. | 6 |
| 4 | **The kernel serves the previous contract and re-spins stragglers when idle.** `client_api` on the row; after a start, older rows are `upgrade_pending` and re-spun through the D54 handshake, `trigger: upgrade`, one at a time; below the minimum, re-spun at once. | 7 |
| 5 | **The caller is read from the socket.** `SO_PEERCRED` gives the calling process; its control group names the persona scope. Other callers declare a name. Operator-only routes refuse a caller inside a persona scope. Gate claims (D59) stay. | 8 |
| 6 | **A bare interrupt that holds.** `POST /personas/{id}/interrupt { reason, hold_seconds = 900 }`; an operator hold over everything owed; lifted by the next human message. | 9 |

## 4. The error body

```json
{ "error": { "code": "admission_refused",
             "message": "The fleet is full: 14 of 14 personas are running, and 2 were requested.",
             "retryable": false,
             "detail": { "check": "fleet_cap", "running": 14, "cap": 14, "requested": 2 } } }
```

- `code` is from the catalogue below; `KernelError` asserts membership, so an uncatalogued code fails the first test that reaches it.
- `message` is one sentence in plain words. The tool server returns it to the model as the tool's result; the command line prints it; nothing parses it.
- `retryable: true` carries `Retry-After`. The two 503s are retryable in contract 1; so is `admission_refused` when `detail.check` is `engine_quota` (`Retry-After` = seconds to the stated reset or the bucket's refill) or `engine_login` (retryable, no `Retry-After`: the retry time is a person's) (D68, 11-11).
- `detail` is per code and additive.

| Status | Codes |
| --- | --- |
| 400 | `malformed_request` |
| 403 | `claim_refused`, `operator_only`, `not_your_persona` |
| 404 | `persona_not_found` |
| 409 | `admission_refused` (`detail.check`: `fleet_cap`, `batch_cap`, `skeleton_crew`, `host_capacity`, `engine_quota`, `engine_login` (D68)), `persona_closed`, `persona_has_reports`, `respawn_blocked`, `state_conflict` |
| 413 | `message_too_large` |
| 422 | `unknown_field`, `invalid_value` |
| 426 | `api_version_unsupported` |
| 500 | `internal_error` |
| 503 | `kernel_starting`, `kernel_stopping` |

**Refusal or outcome.** The line is whether anything changed.

| Case | Before D66 | Now |
| --- | --- | --- |
| a batch that does not fit | 200 `{ admitted: false, refusal }` | 409 `admission_refused`; `message` is the admission sentence verbatim (`capacity_refusal`, D60) |
| an unknown override key | "refused by name" | 422 `unknown_field` |
| a persona caller without a claim | 403 | 403 `claim_refused` |
| dismissing a manager with live reports, `reports: refuse` | 200 `status: refused_has_reports` | 409 `persona_has_reports` |
| dismissing a closed persona | 200 `status: already_closed` | unchanged: 200, an outcome |
| a dismissal withheld for want of a memento | 200 `status: withheld_no_memento` | unchanged in kind: the request was accepted (202) and the row later reads `dismiss.status: withheld_no_memento`; the manager is told (Section 11) |
| a batch child that fails after admission | a row with `status: failed` | unchanged: a row, and a `kernel` block to the manager |
| interrupting a persona that is not busy | — | 200 `{ interrupted: false }` |

**Command-line exit codes:** 0 done; 1 refused (any error body); 2 usage; 3 the kernel is unreachable or not ready.

## 5. Starting, ready, stopping

| State | From, to | Answers |
| --- | --- | --- |
| `starting` | the socket bound (D65 start step 5) to `READY=1` | `/health` only; all else 503 `kernel_starting`, `Retry-After: 1` |
| `ready` | `READY=1` to SIGTERM | everything |
| `stopping` | SIGTERM to the last engine's end | every `GET`, `POST /gate`, the hold, the interrupt; all else 503 `kernel_stopping` |

| Caller | Budget | Then |
| --- | --- | --- |
| shim | `kernel gate retry seconds` (30), one try a second; a 503 counts as a refused connection | `allow` on `test`, `deny` on `production` (D65) |
| tool server | `kernel client retry seconds` (30) | the error's `message` to the model as the tool result |
| command line | none | prints the state, exit 3 |
| Lupin | none | serves its last roster with `stale: true` and the age |
| console | reconnects every 2 s | a banner while not `ready` |

## 6. The contract number

- `API_VERSION` and `API_MINIMUM` are two integers in `control_api.py`. Contract 1 is this document.
- **Free:** a new route, a new field in a reply, a new optional field in a body, a new enum value, a new error code, a new `detail` key.
- **Raises the number:** removing or renaming a route or a field, changing a type, making an optional body field required, changing a status code, changing what an existing enum value means.
- **Callers:** ignore unknown fields; treat an unknown enum value as `unknown`, never as a crash; send `Lupin-Client: <name>/<build> api=<n>`. A caller that sends no header is accepted and logged as `unknown` (curl at the socket stays possible).
- **The kernel:** answers `Lupin-Kernel-Api: <minimum>-<version>` on every reply; refuses a declared contract outside the range with 426, naming all three numbers.
- **The test (Contract-3):** the generated OpenAPI document is committed as `control-api.contract-<n>.json`; the suite fails when a path, a field or an enum value present in the committed file is absent from the generated one and `API_VERSION` is unchanged.

## 7. Old callers after an upgrade

- The provisioner stamps `client_api` on the row at spawn and at every re-spin: the contract the rendered shim and tool server speak.
- **A re-spin re-renders the shim and restarts the tool server** (stated here because the rule depends on it; the T18 provisioner already renders the kit at re-spin).
- At a start, after the reattach plan (D65 start step 6): `upgrade_plan( rows )`.
  - `current`: nothing.
  - `upgrade_pending` (`minimum ≤ client_api < version`): the row is marked; the kernel re-spins it through the D54 handshake with `trigger: upgrade` the next time it is idle with nothing owed, one persona per `kernel upgrade respin spacing seconds` (120). A re-spin for any other reason clears the mark.
  - `respin_now` (`client_api < minimum`): its gate calls are denied with `reason: "The kernel was upgraded and this persona's tools are too old; it is being restarted."`, and the handshake starts at once.
- The kernel keeps handlers for contract N−1 for exactly one release: `API_MINIMUM` rises to N in the release after N ships.
- `respin.requested` gains `trigger: upgrade` (the D54 record set; T18 spec, fleet spec route table).

## 8. Who is calling

```
caller in lupin-persona-<id>.scope      → persona <id>, identity: witnessed      (whatever the request says)
caller elsewhere, host can make scopes  → operator, name from Lupin-Client, identity: declared
caller elsewhere, host cannot (test)    → the Lupin-Persona-Id header if present, identity: asserted; else operator
```

- `PeerProtocol` reads `SO_PEERCRED` at `connection_made` and puts `( user id, process id )` in the request scope; `caller_of` reads `/proc/<pid>/cgroup` once per request. Run on uvicorn 0.54.0 on 2026-11-11 (Section 16, the live test).
- Through the SSH forward the peer is the forwarding process; from Lupin's container it is outside every scope. Both are operators, named by their header.
- Every record a route writes carries `actor: { kind, name, identity }`. "A request with neither field is the operator" (fleet spec Section 4) is retired.
- **Gate claims stay** for the four fleet tools: the scope proves *who*, the claim proves *which approved call*. A persona calling a fleet route without a claim is still 403 `claim_refused`.
- **Not a boundary.** A process on the persona account can write itself into another control group; the gate observes such a write (`kernel_owned_file`, D54) and T36 is the boundary. This closes omission and confusion, which is what the record's "operator" rule left open.
- uvicorn's protocol class is an internal: its version is pinned and the live test is the guard.

## 9. Interrupt

`POST /personas/{id}/interrupt { reason = "", hold_seconds = 900 }`, `?wait=<seconds>` (0 to 60).

| Row state | Does | Reply |
| --- | --- | --- |
| `busy`, `awaiting_human` | the adapter's interrupt (SIGINT to the process group and a respawn on the same conversation on the Jetski family; the control message on Claude); `session.interrupt { cause: operator, open_call_id }` | `{ interrupted: true, open_call, state: interrupting }` |
| `idle`, `hibernated`, `provisioning`, `respinning`, `dismissing` | nothing to cut | `{ interrupted: false, state }` |
| `closed` | | 409 `persona_closed` |

- **The hold.** With `hold_seconds > 0` the kernel sets `hold = { reason: "interrupted by the operator", until, by: operator, covers: all }` on the row (D62's hold, a second `by`). While it stands, no poke is sent and the hibernation clock runs. It is released by the next inbound block of kind `voice` or by `DELETE …/hold`; the persona's own `release()` cannot lift an operator hold. `hold_seconds = 0` interrupts without holding.
- **The next turn** opens with the D52 interrupt block: `[kernel HH:MM:SS] Your previous turn was interrupted by the operator during the tool call <tool>.` and the reason when one was given.
- **`cause`** on `session.interrupt` is now `urgent | held_turn | stop | operator | pressure_compaction`; the held-turn watch (D56) and the compaction rule (D57) call the same function without a hold.
- **Callers:** the operator; the console, where a line that is only `!` calls this route (T20 spec Section 7). A manager's tool for its own reports is a crew-layer row (Phase 2).

## 11. Slow calls

- `POST /personas`, `POST …/dismiss`, `POST …/respin`, `DELETE /personas/{id}`, `POST /jobs/{name}/run`, `POST /engines/{binary}/vet` do their checks (admission, claims, validation) under the registry lock, write the rows, and answer **202 within `kernel accept seconds` (2)**. Everything slower (the worktree, vetting, the voice allocation, the engine start, the memento wait) runs after the reply.
- **The outcome reaches the manager as a `kernel` block**, one per child, queued, never interrupting: `[kernel HH:MM:SS] <voice name> (<role>, <persona_id>) is ready.` or `… failed to start: <reason>.`; for a dismissal `… is retired.` or `… was not dismissed: no memento. Call dismiss again with force to override.` An operator spawn with no manager produces the fleet record only.
- The cosa-voice tools' results change accordingly: `spawn_sessions` returns the admitted rows and the sentence "You will be told as each one is ready."
- **`Idempotency-Key`** (any string up to 128 characters): the kernel keeps `( key, route, body hash ) → reply` for `kernel idempotency minutes` (10) and returns the first reply to a repeat; the same key with a different body is 409 `state_conflict`. Sent by the command line (a fresh key per invocation, reused by its own retry), by Lupin and by scripts. The tool server sends none: its calls return in two seconds, so the 180-second cut that produced repeats cannot occur, and a claim is single use.
- A spawn's voice refusal (`voice_persona_unavailable`, D64) and a vetting failure (D48) happen after the reply: the child's row reads `spawn: { status: failed, reason }`, as a failed batch child already did.

- **`PUT /personas/{id}/topic` (D64) is withdrawn**; the T31 and T28 specs point here.

## 13. Send

`POST /personas/{id}/messages { text, urgent = false, channel = "operator" }` → `{ message_id, disposition, queued_position }`.

| Row | `disposition` | What happens |
| --- | --- | --- |
| has a process, `idle` | `running` | the envelope is written now |
| has a process, any other state | `queued` | at the turn's end; `urgent` interrupts first (D8) |
| no process, room on the host | `waking` | the process starts with this block (D59, D65) |
| no process, no room | `deferred_capacity` | queued; `session.resume_deferred`; retried each sampler pass (D60) |
| `crash_looping` | `held_crash_looping` | queued; delivered after a re-spin clears the flag (D65) |
| `closed` | — | 409 `persona_closed` with `closed_at`, `closed_reason` |

- `message_id` is the ledger's identifier (D52), so `inbox.received` and `inbox.written` for this send can be found in the log.
- `urgent` on a persona that is not busy is an ordinary send. Over 1 MiB of text is 413 (the D56 record bound).
- `channel` is `operator` or `console` (D58), recorded on `inbox.received`.
- Operator only. A persona speaks to a persona through Lupin's DM route (D35), never through this one.

## 16. Reference implementation (runs; nine tests pass on 2026-11-11, fastapi 0.162.4, uvicorn 0.54.0)

`control_api.py`:

```python
"""control_api.py — the control API contract (T09): one error body, the three kernel states,
the contract number, the caller read from the socket, and the pure rules behind send,
interrupt, settings and the upgrade plan. FastAPI on a Unix socket; no lupin imports.
"""
import socket, struct
from dataclasses import dataclass
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse
from uvicorn.protocols.http.h11_impl import H11Protocol

API_VERSION, API_MINIMUM = 1, 1          # the kernel answers every contract in [ minimum, version ]

# ---------------------------------------------------------------- 1. the error body

CATALOGUE = {   # code: ( http status, retryable )
    "malformed_request"       : ( 400, False ), "claim_refused"       : ( 403, False ),
    "operator_only"           : ( 403, False ), "not_your_persona"    : ( 403, False ),
    "persona_not_found"       : ( 404, False ), "admission_refused"   : ( 409, False ),
    "persona_closed"          : ( 409, False ), "persona_has_reports" : ( 409, False ),
    "respawn_blocked"         : ( 409, False ), "state_conflict"      : ( 409, False ),
    "message_too_large"       : ( 413, False ), "unknown_field"       : ( 422, False ),
    "invalid_value"           : ( 422, False ), "api_version_unsupported": ( 426, False ),
    "internal_error"          : ( 500, False ), "kernel_starting"     : ( 503, True ),
    "kernel_stopping"         : ( 503, True ),
}

class KernelError( Exception ):
    """A refusal made before anything changed. `message` is one sentence a model can act on."""
    def __init__( self, code, message, **detail ):
        assert code in CATALOGUE, f"uncatalogued error code: {code}"
        self.code, self.message, self.detail = code, message, detail

def error_response( error ):
    status, retryable = CATALOGUE[ error.code ]
    body = { "error": { "code": error.code, "message": error.message, "retryable": retryable, "detail": error.detail } }
    return JSONResponse( body, status_code=status, headers={ "Retry-After": "1" } if retryable else {} )

# ---------------------------------------------------------------- 2. starting, ready, stopping

ANSWERS_WHILE_STOPPING = { ( "POST", "/gate" ), ( "POST", "hold" ), ( "DELETE", "hold" ) }

def state_refusal( state, method, path ):
    """None admits. `starting` admits /health alone; `stopping` admits reads, the gate and the hold."""
    if state == "ready" or path == "/health": return None
    if state == "starting":
        return KernelError( "kernel_starting", "The kernel is starting; try again in a few seconds." )
    last = path.rstrip( "/" ).rsplit( "/", 1 )[ -1 ]
    if method == "GET" or ( method, path ) in ANSWERS_WHILE_STOPPING or ( method, last ) in ANSWERS_WHILE_STOPPING: return None
    return KernelError( "kernel_stopping", "The kernel is stopping and is not changing the fleet; try again after it restarts." )

# ---------------------------------------------------------------- 3. the contract number

def parse_client( header ):
    """`Lupin-Client: tool-server/0.3.1 api=1` → ( "tool-server", "0.3.1", 1 ). A missing header is ( "unknown", "", None )."""
    if not header: return "unknown", "", None
    head, _, tail = header.partition( " " )
    name, _, build = head.partition( "/" )
    api = tail.strip().removeprefix( "api=" )
    return name, build, int( api ) if api.isdigit() else None

def version_refusal( client_api, version=API_VERSION, minimum=API_MINIMUM ):
    if client_api is None or minimum <= client_api <= version: return None
    return KernelError( "api_version_unsupported",
        f"This caller speaks contract {client_api}; the kernel speaks {minimum} to {version}. Re-spin the persona or update the client.",
        client_api=client_api, api_version=version, api_minimum=minimum )

# ---------------------------------------------------------------- 4. old callers after an upgrade

def upgrade_plan( rows, version=API_VERSION, minimum=API_MINIMUM ):
    """After a start: who runs as is, who is re-spun when next idle, who is re-spun now."""
    plan = { "current": [], "upgrade_pending": [], "respin_now": [] }
    for row in rows:
        if row.state == "closed": continue
        key = "current" if row.client_api == version else "upgrade_pending" if row.client_api >= minimum else "respin_now"
        plan[ key ].append( row.persona_id )
    return plan

# ---------------------------------------------------------------- 5. who is calling

class PeerProtocol( H11Protocol ):
    """Puts the calling process into scope[ "client" ] as ( user id, process id ), read from the socket (SO_PEERCRED)."""
    def connection_made( self, transport ):
        super().connection_made( transport )
        raw = transport.get_extra_info( "socket" ).getsockopt( socket.SOL_SOCKET, socket.SO_PEERCRED, struct.calcsize( "3i" ) )
        process_id, user_id, _ = struct.unpack( "3i", raw )
        self.client = ( str( user_id ), process_id )

def persona_of_cgroup( text ):
    """The persona whose scope a /proc/<pid>/cgroup line names, or None."""
    unit = ( text or "" ).strip().rsplit( "/", 1 )[ -1 ]
    return unit[ len( "lupin-persona-" ):-len( ".scope" ) ] if unit.startswith( "lupin-persona-" ) and unit.endswith( ".scope" ) else None

def read_cgroup( process_id ):
    try:
        with open( f"/proc/{process_id}/cgroup" ) as f: return f.read()
    except OSError:
        return None

@dataclass( frozen=True )
class Caller:
    kind       : str                 # persona | operator
    name       : str                 # the persona id, or the declared client name
    identity   : str                 # witnessed | asserted | declared
    client_api : int | None = None

def caller_of( process_id, client_header, asserted_persona_id=None, host_can_scope=True, read=read_cgroup ):
    name, _, api = parse_client( client_header )
    witnessed = persona_of_cgroup( read( process_id ) ) if process_id else None
    if witnessed:                                   return Caller( "persona", witnessed, "witnessed", api )
    if asserted_persona_id and not host_can_scope:  return Caller( "persona", asserted_persona_id, "asserted", api )
    return Caller( "operator", name, "declared", api )

def require_operator( caller ):
    if caller.kind != "operator":
        raise KernelError( "operator_only", "This route is for the operator; a persona cannot call it.", persona_id=caller.name )

def require_self_or_operator( caller, persona_id ):
    if caller.kind == "persona" and caller.name != persona_id:
        raise KernelError( "not_your_persona", f"Persona {caller.name} cannot change persona {persona_id}.", persona_id=persona_id )

# ---------------------------------------------------------------- 6. interrupt

def interrupt_decision( row, hold_seconds, now ):
    """Returns ( signal, reply, hold ). A persona that is not busy is not an error."""
    if row.state == "closed":
        raise KernelError( "persona_closed", f"Persona {row.persona_id} is closed.", closed_at=row.closed_at )
    hold = { "reason": "interrupted by the operator", "until": now + hold_seconds, "by": "operator", "covers": "all" } if hold_seconds > 0 else None
    busy = row.state in ( "busy", "awaiting_human" )
    return busy, { "interrupted": busy, "open_call": row.open_call if busy else None, "state": "interrupting" if busy else row.state }, hold

# ---------------------------------------------------------------- 9. settings

SETTINGS = {   # key: admitted values ( None clears the override and the manifest's value returns )
    "inbox.rider"            : ( True, False ),        "inbox.dm_grades"       : ( True, False ),
    "turn_end.pokes"         : ( True, False ),        "pressure.action"       : ( "respin", "advise" ),
    "memory.action"          : ( "respin", "advise" ), "watch.held_turn_action": ( "advise", "interrupt" ),
}
PATCHABLE = ( "manager_id", "topic", "settings" )

def validate_patch( body, caller, persona_id ):
    """Returns the changes to apply, [ ( key, value ) ]. Refuses by name; a persona may set only its own topic."""
    for key in body:
        if key not in PATCHABLE: raise KernelError( "unknown_field", f"'{key}' cannot be changed; the fields are {', '.join( PATCHABLE )}.", field=key )
    if caller.kind == "persona":
        require_self_or_operator( caller, persona_id )
        if set( body ) - { "topic" }: raise KernelError( "operator_only", "A persona may change only its own topic.", persona_id=caller.name )
    changes = [ ( key, body[ key ] ) for key in ( "manager_id", "topic" ) if key in body ]
    if "topic" in body and body[ "topic" ] is not None: changes[ -1 ] = ( "topic", str( body[ "topic" ] )[ :64 ] )
    for key, value in ( body.get( "settings" ) or {} ).items():
        if key not in SETTINGS: raise KernelError( "unknown_field", f"'{key}' is not a setting; the settings are {', '.join( SETTINGS )}.", field=key )
        if value is not None and value not in SETTINGS[ key ]:
            raise KernelError( "invalid_value", f"'{key}' takes {' or '.join( map( str, SETTINGS[ key ] ) )}, or null to clear.", field=key, value=value )
        changes.append( ( f"settings.{key}", value ) )
    return changes

# ---------------------------------------------------------------- 10. send

MESSAGE_LIMIT_BYTES = 1024 * 1024

def send_disposition( row, text, fits ):
    """Where a message goes. Taken unless the persona is closed; `fits` is the capacity check for one wake (D60)."""
    if len( text.encode() ) > MESSAGE_LIMIT_BYTES:
        raise KernelError( "message_too_large", "The message is over 1 MiB; put the content in a file and send its path.", limit_bytes=MESSAGE_LIMIT_BYTES )
    if row.state == "closed":
        raise KernelError( "persona_closed", f"Persona {row.persona_id} is closed and takes no messages.", closed_at=row.closed_at )
    if row.crash_looping:    return "held_crash_looping"
    if row.process_id:       return "running" if row.state == "idle" else "queued"
    return "waking" if fits else "deferred_capacity"

# ---------------------------------------------------------------- the application

def create_application( kernel ):
    """`kernel` offers: state, host_can_scope, and the registry. Only /health and the shared checks are wired here."""
    application = FastAPI()

    @application.exception_handler( KernelError )
    async def refuse( request, error ): return error_response( error )

    @application.middleware( "http" )
    async def shared_checks( request: Request, call_next ):
        _, process_id = request.scope.get( "client" ) or ( "", None )
        caller = caller_of( process_id if isinstance( process_id, int ) else None, request.headers.get( "lupin-client" ),
                            request.headers.get( "lupin-persona-id" ), kernel.host_can_scope )
        refusal = state_refusal( kernel.state, request.method, request.url.path ) or version_refusal( caller.client_api )
        if refusal: return error_response( refusal )
        request.state.caller = caller
        response = await call_next( request )
        response.headers[ "Lupin-Kernel-Api" ] = f"{API_MINIMUM}-{API_VERSION}"
        return response

    @application.get( "/health" )            # no registry lock
    async def health():
        return { "state": kernel.state, "api_version": API_VERSION, "api_minimum": API_MINIMUM,
                 "kernel_version": kernel.version, "process_id": kernel.process_id, "started_at": kernel.started_at }

    @application.get( "/whoami" )
    async def whoami( request: Request ):
        caller = request.state.caller
        return { "kind": caller.kind, "name": caller.name, "identity": caller.identity }

    return application
```
