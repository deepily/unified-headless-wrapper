## 2. Admission (the fourth check)

The check list of the fleet spec Section 4 gains its fourth entry, after the fleet cap and before the engine-quota slot (T22):

| Order | Check | Refusal names |
| --- | --- | --- |
| 4 | `requested > fit`, `fit = ( budget − committed ) // reserve( engine )` | budget, committed, running count, how many of this engine fit, requested |

- `committed` sums `reserve_bytes` over rows whose state is neither `closed` nor `hibernated`; `provisioning` rows count, so a second batch under the same lock sees the first.
- A batch is one engine; a mixed batch is two calls.
- **A wake** (`session.resumed`, framework Section 10.5) runs the same check with `requested = 1` before the process starts. Refused: the inbound message stays in the queue, one `session.resume_deferred { reason: host_capacity, fit }`, one `type: info` line to the manager, one spoken line to the human (`<name> is waiting for room on the host`), and the sampler retries the wake on every pass until it is admitted. Nothing is dropped.
- **Re-spin passes no admission** (D59), including a memory re-spin: the persona's reservation is already committed.
- `[host]` and `[memory]` are re-read from disk at each admission, like `[fleet]`.

## 3. The scope and the sampler

- **Launch** (adapter, every engine): `systemd-run --user --scope --quiet --collect -p MemoryAccounting=yes -p MemoryMax=<cap_bytes> -p MemorySwapMax=0 --slice=lupin-personas.slice --unit=lupin-persona-<persona_id> -- <engine argv>`; `oom_score_adj` 500 written by the child before exec. The scope path is `<user cgroup root>/lupin-personas.slice/lupin-persona-<id>.scope`, found from `/proc/<pid>/cgroup` once at start and stored on the row (`cgroup_path`).
- **At kernel start:** `systemctl --user set-property lupin-personas.slice MemoryMax=<budget_bytes> MemorySwapMax=0`; one `kernel.started` field `slice_bound: true | false`.
- **The sampler** is one kernel task every `memory_sample_seconds` (15) over every running row: `memory.current`, `anon` from `memory.stat`, `memory.peak` or the kernel-kept maximum, and the `oom_kill` count from `memory.events`. A scope that has vanished mid-pass is skipped, never reported at zero (lupin's invariant). Each sample refreshes the roster; the Section 4 lines are evaluated; one `memory.sample` per persona per `memory_log_minutes` (10) is logged.
- **Fallback measurement** (an uncapped persona on a `test` host): proportional set size (`Pss` from `/proc/<pid>/smaps_rollup`) summed over the pid's descendants, `source: pss`, no bound, `capped: false`.
- **Not ported** from `cc_memory_watch.py`: `is_claude_process`, `is_listener_process`, `parse_listener_owner_map`, `parse_tmux_pane`, `resolve_tmux_session`, the deployed copy and its parity test. **Kept in spirit:** `AlertTracker`'s first-crossing-then-step policy (as the lines), `read_scope_anon_kb`, the skip-on-vanish rule, `derive_cc_memory_peak`'s "group on the scope, never sum RSS".

## 4. The lines (per persona)

```
ratio = memory.current / cap_bytes          on every sample
ratio ≥ 0.80 and respin not yet seen   → watch.memory line=respin action=<respin|advise>; respin → D54 handshake trigger=memory; manager told
ratio ≥ 0.60 and notice not yet seen   → watch.memory line=notice action=none
ratio < 0.60                           → both lines re-arm
respawn                                → both lines re-arm
```

- `memory.action` per manifest: `respin` (default) or `advise`. Two memory re-spins inside `respin_window_hours` (6) → the third crossing is `advise` with an `alert`-level `watch.memory`: a leak that survives a fresh process is in the work.
- The handshake is the T18 spec's `respin( kernel, persona, now, trigger="memory" )`; the record set `respin.requested`, `respin.rehydrated`, `respin.without_memento` carries `trigger: operator | pressure | persona | memory` (the fleet spec route table and the T18 spec are amended).
- **The kill.** `memory.events oom_kill` incrementing between two samples → `session.oom_killed { last_current_bytes, peak_bytes, cap_bytes, slice_bound }` (`slice_bound` true when the slice, not the scope, was the constraint: the scope's `memory.max` was not reached), the process is gone, the row stays, the next inbound message restarts the process (T08), one advisory to the manager. The last turn's memento is whatever the handshake had already written; the kill is the backstop, not the plan.

## 5. Host pressure

- `slice_current = memory.current` of `lupin-personas.slice`; `psi_some_avg60` from the slice's `memory.pressure` (or `/proc/pressure/memory` where the slice file is absent).
- Upward crossing of `slice_current ≥ host_pressure_ratio × budget` or `psi_some_avg60 ≥ 25` → `host.pressure { ratio, idle_hibernate_minutes_in_force: 5 }` once; re-armed when both fall below 0.70 and 25.
- While under pressure the hibernation sweep (fleet spec Section 10) uses `idle_hibernate_minutes_under_pressure` (5). **A busy persona is never stopped for memory.** New spawns are already refused by Section 2; growth is answered by Section 4; the slice bound of Section 7 is the last line.
- `host.memory { total_bytes, available_bytes, budget_bytes, slice_current_bytes, committed_bytes, running, psi_some_avg60 }` every `memory_log_minutes` in the kernel log; the console shows `memory` beside `pressure` with the same colours (D58).

## 7. Launch composition, the two bounds, the uncappable host

- **Node engines** (AGY, Jetski): environment `GEMINI_CLI_NO_RELAUNCH=true` and `NODE_OPTIONS=--max-old-space-size=<heap_mib>`. The pid the kernel holds is the engine; a heap runaway dies at 6 GiB with a V8 error on `engine.stderr`; the cgroup bounds the rest. **Claude:** the cap alone; lupin found no heap flag in its bundle and its leaks are external.
- **Per persona:** `MemoryMax=<cap>`, `MemorySwapMax=0`, `MemoryAccounting=yes`, no `MemoryHigh` (lupin's pinned finding of 08-23: a soft limit manufactures the pressure systemd-oomd selects on), `oom_score_adj` 500.
- **Per fleet:** `lupin-personas.slice` at `MemoryMax=<budget>`, `MemorySwapMax=0`. A fleet-wide shortfall is a kill inside the slice of the operating system's choice, never a global OOM, never Lupin or Postgres.
- **Never** a property on `user-<uid>.slice`, `user@<uid>.service` or any unit the kernel did not create; a unit test asserts the composed commands name none of them (lupin's `test_launcher_memory_ceiling` ported).
- **No scope possible** (`systemd-run` absent, no `XDG_RUNTIME_DIR`, no user manager, delegation refused): `class = test` → the persona starts in the kernel's own cgroup, `memory.uncapped { reason }`, roster `capped: false`, `status: uncapped`, Section 3's fallback measurement, the reservation still charged; `class = production` → the spawn fails with `refused_uncappable`, named in the result and to the manager; a wake likewise.
- systemd-oomd: recorded by the inventory; no `ManagedOOMMemoryPressure` on the slice in Phase 1. Revisit if the inventory shows oomd active on a production host.

## 10. Reference implementation (runs; six tests pass on 2026-11-10)

`capacity.py` — standard library; the cgroup reader's file reads are injectable.

```python
"""capacity.py — host capacity (D60): the fourth admission check, the per-persona
memory lines, host pressure, and the cgroup reader. Pure except `CgroupReader`,
whose file reads are injectable. Standard library only.
"""
from dataclasses import dataclass, field

GIB = 1024 ** 3

def gib( n ):
    return f"{n / GIB:.1f}"

# ---------------------------------------------------------------- configuration

@dataclass( frozen=True )
class EngineMemory:
    reserve_bytes : int = 2 * GIB
    cap_bytes     : int = 8 * GIB
    heap_mib      : int | None = 6144        # Node engines only; None on claude

@dataclass( frozen=True )
class HostConfig:
    total_bytes              : int
    host_class               : str   = "test"      # production | test
    host_reserve_ratio       : float = 0.25
    host_reserve_floor_bytes : int   = 4 * GIB
    host_pressure_ratio      : float = 0.80
    host_pressure_rearm      : float = 0.70
    notice_ratio             : float = 0.60
    respin_ratio             : float = 0.80
    respin_window_hours      : int   = 6
    idle_hibernate_minutes               : int = 30
    idle_hibernate_minutes_under_pressure: int = 5

    @property
    def budget_bytes( self ):
        reserve = max( self.host_reserve_floor_bytes, int( self.total_bytes * self.host_reserve_ratio ) )
        return max( 0, self.total_bytes - reserve )

# ---------------------------------------------------------------- admission (check 4)

def running_rows( rows ):
    return [ row for row in rows if row.state not in ( "closed", "hibernated" ) ]

def committed_bytes( rows, table ):
    return sum( table[ row.engine ].reserve_bytes for row in running_rows( rows ) )

def capacity_refusal( requested, engine, rows, host, table ):
    """The fourth admission check: None admits, a string refuses (verbatim to the caller)."""
    running   = running_rows( rows )
    committed = committed_bytes( rows, table )
    budget    = host.budget_bytes
    reserve   = table[ engine ].reserve_bytes
    fit       = max( 0, ( budget - committed ) // reserve )
    if requested > fit:
        return ( f"host capacity: budget {gib( budget )} GiB, committed {gib( committed )} GiB by "
                 f"{len( running )} running, {fit} more {engine} fit at {gib( reserve )} GiB each, {requested} requested" )
    return None

# ---------------------------------------------------------------- per-persona lines

@dataclass
class MemoryLines:
    """One per persona. Mirrors D57's lines: once per upward crossing, re-armed below notice."""
    notice_seen : bool = False
    respin_seen : bool = False
    respins_at  : list = field( default_factory=list )   # epoch seconds of memory re-spins

    def rearm( self ):
        self.notice_seen = self.respin_seen = False

    def evaluate( self, current_bytes, cap_bytes, host, now, action_pref="respin" ):
        """Returns ( line, action ) for a crossing, or ( None, None )."""
        ratio = current_bytes / cap_bytes
        if ratio < host.notice_ratio:
            self.rearm()
            return None, None
        if ratio >= host.respin_ratio and not self.respin_seen:
            self.respin_seen = True
            window = host.respin_window_hours * 3600
            recent = [ t for t in self.respins_at if now - t < window ]
            action = "advise" if ( action_pref == "advise" or len( recent ) >= 2 ) else "respin"
            if action == "respin":
                self.respins_at = recent + [ now ]
            return "respin", action
        if ratio >= host.notice_ratio and not self.notice_seen:
            self.notice_seen = True
            return "notice", "none"
        return None, None

def memory_status( current_bytes, cap_bytes, capped, host ):
    if not capped:        return "uncapped"
    if cap_bytes is None: return "unknown"
    ratio = current_bytes / cap_bytes
    return "respin" if ratio >= host.respin_ratio else "notice" if ratio >= host.notice_ratio else "ok"

# ---------------------------------------------------------------- host pressure

@dataclass
class HostPressure:
    under_pressure : bool = False

    def evaluate( self, slice_current_bytes, psi_some_avg60, host ):
        """Returns True on an upward crossing (write host.pressure), False otherwise; hysteresis at rearm."""
        ratio = slice_current_bytes / host.budget_bytes if host.budget_bytes else 1.0
        if not self.under_pressure and ( ratio >= host.host_pressure_ratio or psi_some_avg60 >= 25 ):
            self.under_pressure = True
            return True
        if self.under_pressure and ratio < host.host_pressure_rearm and psi_some_avg60 < 25:
            self.under_pressure = False
        return False

    def idle_hibernate_minutes( self, host ):
        return host.idle_hibernate_minutes_under_pressure if self.under_pressure else host.idle_hibernate_minutes

# ---------------------------------------------------------------- the cgroup reader

class CgroupReader:
    """Reads one persona scope. `read` is injectable: path -> text or None (any OSError -> None)."""
    def __init__( self, scope_path, read=None ):
        self.path  = scope_path
        self.read  = read or self._read_file
        self.peak  = 0
        self.oom_kills_seen = 0

    @staticmethod
    def _read_file( path ):
        try:
            with open( path ) as f: return f.read()
        except OSError:
            return None

    @staticmethod
    def _stat_value( text, key ):
        for line in ( text or "" ).splitlines():
            k, _, v = line.partition( " " )
            if k == key: return int( v )
        return None

    def sample( self ):
        """One sample: ( current, anon, peak, new_oom_kills ); peak kept here where the kernel lacks memory.peak."""
        cur  = self.read( f"{self.path}/memory.current" )
        if cur is None: return None
        current = int( cur )
        anon    = self._stat_value( self.read( f"{self.path}/memory.stat" ), "anon" )
        kpeak   = self.read( f"{self.path}/memory.peak" )
        self.peak = int( kpeak ) if kpeak is not None else max( self.peak, current )
        kills   = self._stat_value( self.read( f"{self.path}/memory.events" ), "oom_kill" ) or 0
        new_kills, self.oom_kills_seen = max( 0, kills - self.oom_kills_seen ), kills
        return current, anon, self.peak, new_kills

# ---------------------------------------------------------------- launch composition

def scope_command( persona_id, cap_bytes, engine_argv ):
    """The per-persona scope (D60 part 7). No MemoryHigh — deliberate."""
    return [ "systemd-run", "--user", "--scope", "--quiet", "--collect",
             "-p", "MemoryAccounting=yes", "-p", f"MemoryMax={cap_bytes}", "-p", "MemorySwapMax=0",
             f"--slice=lupin-personas.slice", f"--unit=lupin-persona-{persona_id}", "--" ] + list( engine_argv )

def slice_properties( budget_bytes ):
    return [ "systemctl", "--user", "set-property", "lupin-personas.slice",
             f"MemoryMax={budget_bytes}", "MemorySwapMax=0" ]

def engine_environment( engine, memory ):
    """Node engines: relaunch off and a heap below the cap (D60 part 6)."""
    if engine in ( "agy", "jetski" ) and memory.heap_mib:
        return { "GEMINI_CLI_NO_RELAUNCH": "true", "NODE_OPTIONS": f"--max-old-space-size={memory.heap_mib}" }
    return {}

def uncapped_disposition( host_class, reason ):
    """A host where no scope can be made (D60 part 8)."""
    return "refuse" if host_class == "production" else "start_uncapped"
```

from dataclasses import dataclass
from capacity import *

@dataclass
class Row:
    engine : str
    state  : str = "idle"

TABLE = { "agy": EngineMemory(), "claude": EngineMemory( heap_mib=None ) }

def test_capacity_1_refusal_names_fit():
    host = HostConfig( total_bytes=12 * GIB, host_reserve_floor_bytes=4 * GIB )   # budget 8 GiB
    rows = [ Row( "agy" ), Row( "agy", "busy" ), Row( "agy", "provisioning" ), Row( "agy", "hibernated" ) ]
    r = capacity_refusal( 2, "agy", rows, host, TABLE )
    assert r == "host capacity: budget 8.0 GiB, committed 6.0 GiB by 3 running, 1 more agy fit at 2.0 GiB each, 2 requested"
    assert capacity_refusal( 1, "agy", rows, host, TABLE ) is None

def test_dev_server_budget():
    host = HostConfig( total_bytes=251 * GIB )
    assert round( host.budget_bytes / GIB ) == 188
    assert host.budget_bytes // ( 2 * GIB ) == 94

def test_capacity_2_lines_and_rearm():
    host, lines, cap = HostConfig( total_bytes=64 * GIB ), MemoryLines(), 8 * GIB
    assert lines.evaluate( int( 0.50 * cap ), cap, host, now=0 ) == ( None, None )
    assert lines.evaluate( int( 0.65 * cap ), cap, host, now=15 ) == ( "notice", "none" )
    assert lines.evaluate( int( 0.70 * cap ), cap, host, now=30 ) == ( None, None )      # once per crossing
    assert lines.evaluate( int( 0.85 * cap ), cap, host, now=45 ) == ( "respin", "respin" )
    lines.rearm()                                                                          # respawn
    assert lines.evaluate( int( 0.85 * cap ), cap, host, now=3600 ) == ( "respin", "respin" )
    lines.rearm()
    assert lines.evaluate( int( 0.85 * cap ), cap, host, now=7200 ) == ( "respin", "advise" )   # third in 6 h
    assert memory_status( int( 0.85 * cap ), cap, True, host ) == "respin"
    assert memory_status( 1, None, False, host ) == "uncapped"

def test_capacity_4_host_pressure_shortens_idleness():
    host, hp = HostConfig( total_bytes=16 * GIB ), HostPressure()          # budget 12 GiB
    assert hp.idle_hibernate_minutes( host ) == 30
    assert hp.evaluate( int( 0.85 * host.budget_bytes ), 0, host ) is True
    assert hp.evaluate( int( 0.85 * host.budget_bytes ), 0, host ) is False  # no repeat
    assert hp.idle_hibernate_minutes( host ) == 5
    hp.evaluate( int( 0.75 * host.budget_bytes ), 0, host )                 # between 0.70 and 0.80: still on
    assert hp.under_pressure
    hp.evaluate( int( 0.60 * host.budget_bytes ), 0, host )
    assert not hp.under_pressure and hp.idle_hibernate_minutes( host ) == 30

def test_capacity_3_cgroup_reader_without_memory_peak():

    r = CgroupReader( "/s", read=lambda p: files.get( p ) )
    assert r.sample() == ( 1000, 900, 1000, 0 )
    files[ "/s/memory.current" ] = "700"; files[ "/s/memory.events" ] = "oom_kill 1\n"
    assert r.sample() == ( 700, 900, 1000, 1 )          # peak kept by the kernel; one new kill
    assert r.sample() == ( 700, 900, 1000, 0 )
    files[ "/s/memory.current" ] = None
    assert r.sample() is None                            # scope gone: skipped, never reported at 0
