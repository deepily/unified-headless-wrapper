## 2. The limit, from the record (ruling 1)

The register asked how long Claude Code lets one call to a tool server run. The answer needs no capture.

**The vendor's documentation** (read 2026-11-16):

| Limit | Default | Reaches the kernel's tool server? |
|---|---|---|
| `MCP_TOOL_TIMEOUT`: wall-clock limit on one tool call, milliseconds | 100,000,000, about 28 hours | yes |
| Per-server `timeout` field in the server's configuration entry | none; overrides the variable for that server; values under 1000 are ignored | yes, if written |
| `CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT`: no response and no progress notification | 30 minutes for a server on standard input and output, 5 minutes for a network server; capped at the effective wall-clock limit; `0` disables it | yes |
| Per-request timer, to the server's first response byte | the greatest of 60 seconds, the applicable tool timeout and `MCP_TIMEOUT` | no: network servers only |

The kernel's tool server is one process per persona on standard input and output (D35, control path not data path; framework Section 3, interface 1), so the per-request timer does not apply.

**Lupin's measurement** (`src/scripts/start-cc-with-tmux.sh` lines 411 to 427, lupin `aabadd221`): on Claude Code 2.1.199, a tool made to hang for 120 seconds under `MCP_TOOL_TIMEOUT=15000` was cut at exactly 15 seconds and the turn recovered. The harness sets `660000` on every seat; the figure was sized to clear the 600-second ceiling of a blocking ask (`src/tests/unit/test_mcp_tool_timeout_spawn_env.py` lines 40, 41, 105), which D37 retired.

**The design.** No kernel tool call is held past 150 seconds (D37; D49, tool approval: the only held call is `ask_wait`).

So the capability table's Claude cell is filled from the record, and the check on the Claude Code version in use at the time runs as `Timeout-1` with the Claude adapter, where every other Claude check runs.

**Not verified in this session:** the honor check on the test VM's Claude Code 2.1.325; the design note the lupin comments cite (`src/rnd/v0.1.9/2026.07.03-notify-turn-hold-fix-design.md`) is not in the test VM's checkout.

## 3. The figure the Claude adapter sets (ruling 2)

**180 seconds.** At every engine start the Claude adapter writes `MCP_TOOL_TIMEOUT=180000` into the engine's environment.

- **One cut on every engine.** The Jetski family cuts every tool call at 180 seconds and the figure cannot be changed (C14, C14b). A tool too slow for that family now fails the same way on Claude, so Phase 3's repeat of Kernel-1 to Kernel-8 exercises what the other engines see.
- **A stuck call costs three minutes.** Unset, a call that never returns holds the turn until the 30-minute idle limit; the held-turn watch (D56, log schema and rotation; T17 spec Section 7) advises and does not end the call.
- **The margin is the family's:** 30 seconds over the 150-second hold.
- **The invariant:** `hold < limit <= family cut` (150 < 180 <= 180). The harness's 660 fails it by design: a call that works on Claude at 400 seconds would be cut elsewhere.

Three details follow from the vendor's table and are set here without a click (Section 9):

1. **The adapter overwrites an inherited value.** The kernel may itself have been started from a shell that carries the harness's `660000`.
2. **The adapter removes an inherited `CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT`.** A hold sends nothing for up to 150 seconds; an inherited idle limit below that would sever it. The default (30 minutes) is capped at the wall-clock limit, so removing the variable leaves 180 seconds as the only limit.
3. **The kernel writes no per-server `timeout`** into a Claude persona's tool-server configuration, and refuses to write one: the field would override the adapter's limit for that server.

If the tool server ever moves to a network transport, the per-request timer becomes `max( 60 s, 180 s, MCP_TIMEOUT )`, so the same setting covers it.

## 4. Records and configuration

No kernel record and no configuration key is added. The figure is a constant of the Claude adapter (`engines/claude.py`, D71's allow-listed path), beside the invariant that ties it to the hold and to the family's cut. The vendor's names (`MCP_TOOL_TIMEOUT`, `CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT`) are the engine's own and fall under D71's (engine-neutral naming) third exemption; they appear only in that adapter.

## 5. Reference implementation (runs; thirteen tests pass on 2026-11-16, Python 3, no dependencies)

`claude_tool_call_timeout.py`:

```python
"""Claude's tool-call limit (T33 -> D72): the reference implementation. Python 3, no dependencies.

Two rulings. (1) The limit is not measured again: the vendor documents it and lupin has shown it is obeyed.
(2) The Claude adapter sets it to 180 seconds, the cut the Jetski family applies and cannot change, in the
engine's environment at every start.

The vendor's names (MCP_TOOL_TIMEOUT, CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT, the per-server `timeout` field) are
the engine's own and are exempt from the naming rule (D71, exemption 3); they appear only in this module,
which belongs to the Claude adapter.
"""

ASK_HOLD_SECONDS                 = 150   # D37: the longest any tool call is held (asks, ask_wait)
FAMILY_TOOL_CALL_CUT_SECONDS     = 180   # C14, C14b: Jetski and AGY cut every tool call here; not configurable
CLAUDE_TOOL_CALL_TIMEOUT_SECONDS = 180   # ruling 2

WALL_CLOCK_VARIABLE = "MCP_TOOL_TIMEOUT"                      # milliseconds; unset means about 28 hours
IDLE_VARIABLE       = "CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT"     # milliseconds; capped at the wall-clock limit
SERVER_TIMEOUT_FIELD = "timeout"                              # per-server; overrides the variable for that server


def check_invariant( hold_seconds=ASK_HOLD_SECONDS, timeout_seconds=CLAUDE_TOOL_CALL_TIMEOUT_SECONDS,
                     family_cut_seconds=FAMILY_TOOL_CALL_CUT_SECONDS ):
    """
    Requires: three positive whole numbers of seconds.
    Ensures:  returns None when hold < timeout <= family cut; a held call is never severed, and no call
              that the family would cut survives on Claude.
    Raises:   ValueError naming the figures otherwise.
    """
    if not hold_seconds < timeout_seconds <= family_cut_seconds:
        raise ValueError( f"tool-call timeout {timeout_seconds} s must be above the hold ({hold_seconds} s) "
                          f"and no greater than the family's cut ({family_cut_seconds} s)" )


def claude_tool_call_environment( inherited, timeout_seconds=CLAUDE_TOOL_CALL_TIMEOUT_SECONDS ):
    """
    Requires: inherited is the environment the adapter is about to give the engine (a mapping of strings).
    Ensures:  returns a new dict; the wall-clock variable is the ruled figure in milliseconds, whatever was
              inherited; an inherited idle limit is removed, because a hold sends nothing for up to 150 s and
              an idle limit below that would sever it (the default is capped at the wall-clock limit anyway);
              every other variable is passed through; inherited is not modified.
    Raises:   ValueError when the figure breaks the invariant.
    """
    check_invariant( timeout_seconds=timeout_seconds )
    environment = { name: value for name, value in inherited.items() if name != IDLE_VARIABLE }
    environment[ WALL_CLOCK_VARIABLE ] = str( timeout_seconds * 1000 )
    return environment


def check_server_entries( servers ):
    """
    Requires: servers is the `mcpServers` mapping the kernel is about to write for a Claude persona.
    Ensures:  returns None when no entry carries a per-server timeout.
    Raises:   ValueError naming the server otherwise: the field would override the adapter's limit for it.
    """
    for name, entry in sorted( servers.items() ):
        if SERVER_TIMEOUT_FIELD in entry:
            raise ValueError( f"tool server '{name}' carries a per-server '{SERVER_TIMEOUT_FIELD}'; "
                              f"the Claude adapter's {WALL_CLOCK_VARIABLE} is the one limit" )


def cut_after_seconds( call_seconds, timeout_seconds=CLAUDE_TOOL_CALL_TIMEOUT_SECONDS ):
    """
    Requires: call_seconds is how long a tool call would run if nothing cut it.
    Ensures:  returns None when the call finishes inside the limit, else the second at which the engine
              cuts it. The expected outcome of Timeout-1.
    """
    return None if call_seconds <= timeout_seconds else timeout_seconds
```

`test_claude_tool_call_timeout.py`:

```python
"""Tests for the Claude tool-call limit (T33 -> D72). Run: python3 -m unittest -v test_claude_tool_call_timeout"""
import unittest

import claude_tool_call_timeout as limit


class TheFigure( unittest.TestCase ):

    def test_ruled_figure_is_the_family_cut( self ):
        self.assertEqual( limit.CLAUDE_TOOL_CALL_TIMEOUT_SECONDS, 180 )
        self.assertEqual( limit.CLAUDE_TOOL_CALL_TIMEOUT_SECONDS, limit.FAMILY_TOOL_CALL_CUT_SECONDS )

    def test_invariant_holds_for_the_ruled_figure( self ):
        self.assertIsNone( limit.check_invariant() )

    def test_invariant_refuses_a_figure_at_or_below_the_hold( self ):
        for seconds in ( 15, 150 ):
            with self.assertRaises( ValueError ): limit.check_invariant( timeout_seconds=seconds )

    def test_invariant_refuses_the_harness_figure( self ):
        with self.assertRaises( ValueError ): limit.check_invariant( timeout_seconds=660 )


class TheEnvironment( unittest.TestCase ):

    def test_sets_the_limit_in_milliseconds( self ):
        environment = limit.claude_tool_call_environment( { "LUPIN_PERSONA_ID": "p-1" } )
        self.assertEqual( environment[ "MCP_TOOL_TIMEOUT" ], "180000" )
        self.assertEqual( environment[ "LUPIN_PERSONA_ID" ], "p-1" )

    def test_overwrites_an_inherited_limit( self ):
        environment = limit.claude_tool_call_environment( { "MCP_TOOL_TIMEOUT": "660000" } )
        self.assertEqual( environment[ "MCP_TOOL_TIMEOUT" ], "180000" )

    def test_removes_an_inherited_idle_limit( self ):
        environment = limit.claude_tool_call_environment( { "CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT": "60000" } )
        self.assertNotIn( "CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT", environment )

    def test_does_not_modify_what_it_was_given( self ):
        inherited = { "MCP_TOOL_TIMEOUT": "660000", "CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT": "0" }
        limit.claude_tool_call_environment( inherited )
        self.assertEqual( inherited, { "MCP_TOOL_TIMEOUT": "660000", "CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT": "0" } )

    def test_refuses_a_figure_that_breaks_the_invariant( self ):
        with self.assertRaises( ValueError ): limit.claude_tool_call_environment( {}, timeout_seconds=120 )


class TheServerEntries( unittest.TestCase ):

    def test_accepts_entries_without_a_timeout( self ):
        self.assertIsNone( limit.check_server_entries( { "cosa-voice": { "command": "python3", "args": [] } } ) )

    def test_refuses_a_per_server_timeout_and_names_the_server( self ):
        with self.assertRaises( ValueError ) as caught:
            limit.check_server_entries( { "cosa-voice": { "command": "python3", "timeout": 600000 } } )
        self.assertIn( "cosa-voice", str( caught.exception ) )


class TheExpectedCut( unittest.TestCase ):

    def test_a_full_hold_is_not_cut( self ):
        self.assertIsNone( limit.cut_after_seconds( limit.ASK_HOLD_SECONDS ) )

    def test_a_hung_call_is_cut_at_the_limit( self ):
        self.assertEqual( limit.cut_after_seconds( 200 ), 180 )


if __name__ == "__main__":
    unittest.main()
```
