## 2. The sign-in route (ruling 1)

- Public record (narrative, "Where the record stands"): three routes. Only the cached account sign-in reaches Fable and Opus at a flat price; the Gemini Enterprise route bills per token, needs an administrator's opt-in for partner models and does not list Fable; an API key reaches Gemini models only; the tool keeps one sign-in per operating-system account, so several accounts would race.
- **Manifest:** `billing: default | vertex | cloud`. `vertex` is D59's (Claude only, Phase 3). `cloud` is reserved for the Gemini Enterprise route on AGY and refused by the validator by name (`billing: cloud is not yet captured on engine agy`) until a capture shows `AGY_ADC_AUTH=true` running a D44 role model end to end; that capture is scheduled when a per-token bill is wanted, not before.
- The account belongs to the host, not the persona. Nothing in the kernel accounts per persona at Google; the daily table (Section 12) does it from the kernel's own records.

## 3. Where the sign-in is kept (ruling 2)

- The kernel sets `GEMINI_FORCE_FILE_STORAGE=true` in every engine's spawn environment (beside D60's `GEMINI_CLI_NO_RELAUNCH=true`) and the runbook's sign-in command carries it, so the sign-in a person makes at a terminal lands in the file the service reads: `~/.gemini/antigravity-cli/antigravity-oauth-token`.
- **Start step (D65 step 2, invariants):** the kernel runs the meter read as an engine would be run (its own unit, no terminal). Exit 0 with a usage answer: `engine.login { state: ok, store: file }`. Exit 1: the start continues, `login: lapsed` from the first second, the Section 4 hold applies at once, and the card carries the command; a lapsed sign-in is a condition the kernel manages, never a startup refusal.
- **File mode:** the kernel sets the token file to 600 and `~/.gemini/antigravity-cli/` to 700 at start when they are looser, and records `engine.login.mode_fixed`. The D50 credential pattern `~/.gemini/*/oauth*` does not match the file; it is corrected to `~/.gemini/*/*oauth*` and `~/.gemini/*/credentials*` (T32 spec Section 4.2 amended below).
- The inventory script answers, per host, whether the file exists today and whether a unit-started process reads the meter with and without the variable. If a host's sign-in is in the keyring, one fresh sign-in with the variable set moves it; the runbook says so.

## 4. The lapsed sign-in (ruling 3)

| When | What the kernel does |
| --- | --- |
| Every `kernel engine login check seconds` (600), at start, and after any turn error classified `login_lapsed` | one meter read; a failed read is retried once after 5 s before `lapsed` is declared (the record has one report of a fresh process missing a valid file) |
| On lapse | `account.login = lapsed`; `engine.login { state: lapsed }`; admission refuses spawns and wakes with `admission_refused`, `detail.check: engine_login`, `retryable: true`, no `Retry-After` (the retry time is a person's); personas in a turn are `login_held` (not `crashed`, not a held turn, not poked, their queued messages kept); one `priority: high` card and one spoken line: *AGY's sign-in on `<host>` has lapsed; run `GEMINI_FORCE_FILE_STORAGE=true agy` as `<account>` and sign in.* Repeated at most once per `kernel engine login remind hours` (6). |
| On the next good read | `engine.login { state: ok }`; the hold lifts; each held persona's next turn opens with `[kernel HH:MM:SS sign-in restored, held N min]`; queued messages flow. |
| Always | gate rule `engine_login` (`enforce`, every role): the engine's interactive sign-in, `/logout`, and any write under `~/.gemini/antigravity-cli/` except the engine's own are denied; a persona that wants a sign-in tells its manager, who tells Rick. |

Warning ahead: if the inventory shows the token file's age follows a regular interval on both hosts, `kernel engine login warn hours` (24) adds one `priority: low` card that many hours before the interval ends; off (0) until the interval is known.

## 5. Reading the meter (ruling 4)

- Task `engine.meter` every `kernel engine meter seconds` (300), per engine adapter that implements `read_meter()`; AGY's runs `agy -p "/usage" --output-format json` with a 60 s timeout, zero tokens, about two seconds.
- Each read is a record `engine.meter { pool, window, remaining_fraction, reset_time, read_seconds }` per bucket; the newest set is on `/status` under `engine_account` and in `lupin kernel status`.
- **Override:** a `quota_exhausted` error the kernel saw (Section 10) blocks that pool until the reset the error stated, whatever the meter says meanwhile (one monitoring project saw the meter report full during an unexpired exhaustion). The block is `account.blocked_until[ pool ]`, persisted in the registry so a kernel restart keeps it.
- A read that is not a usage answer, or older than `kernel engine meter max age seconds` (900), is `unknown`; unknown admits and never defers.
- Pools: the meter's group names map to `gemini`, `third_party` (Claude and GPT models) and `argon`; a group the module does not know is skipped and logged once. D44's default roles all draw on `third_party`.
- Other engines: `read_meter()` returns `None` on Jetski and Claude until their adapters implement it; `None` is `unknown`.

## 6. The fifth admission check (ruling 5)

Fills the slot D59 left in framework Section 10.2, after the host-capacity check (D60).

| Condition | Spawn | Wake of a hibernated persona |
| --- | --- | --- |
| `login: lapsed` | refused, `engine_login` | deferred, `engine_login` |
| the model's pool blocked (observed exhaustion, unexpired) | refused, `engine_quota`, `reason: exhausted`, `Retry-After` = seconds to the reset | deferred the same way; `session.resume_deferred { reason: engine_quota }`, the sampler retries each pass (D60's pattern) |
| five-hour remainder < `kernel engine quota spawn floor five hour` (0.15) or weekly < `kernel engine quota spawn floor weekly` (0.05) | refused, `engine_quota`, `reason: low`, the window, the remainder, the floor; `Retry-After` = seconds to that bucket's `reset_time` when the meter gave one | admitted: a wake's message deserves an answer while any allowance remains |
| meter unknown or stale | admitted | admitted |

The refusal's `message` is one sentence (`the Claude and GPT pool has 10% of its five-hour allowance left, under the 15% floor; it refills at 15:04`), handed to a manager unchanged (D66). `fleet.refused` carries `check: engine_quota | engine_login` and the figures. The two floors are configuration and are re-set from the first week of `engine.meter` records.

## 7. A turn that runs into the limit (ruling 6)

1. The adapter classifies every error step and every `status: ERROR` result (Section 10). On `quota_exhausted` with `reset_seconds`: `account.note_exhaustion( pool, reset_seconds, now )`, record `engine.quota_exhausted { persona_id, pool, reset_seconds, reset_at }`.
2. The kernel interrupts the turn (D66's bare interrupt, the measured path) so the engine stops its one-a-second retries; the row's state is `quota_blocked` with `blocked_pool` and `blocked_until`. Not a crash (no crash-loop count), not a D56 held turn (no advisory), not poked (D62 treats `quota_blocked` like a hold that covers everything), free to hibernate after the usual 30 minutes.
3. The message the turn was answering is kept at the head of the queue. After the reset the persona's next turn opens with `[kernel HH:MM:SS quota restored, pool third_party, blocked N min]` followed by that message's header and text, as D65 reopens after a crash; the kernel never re-runs the turn itself.
4. Notices: one `priority: high` card per pool per block, *the Claude and GPT pool on `<host>` is exhausted until 3:42 PM Thursday (America/New_York); N personas are waiting*, and one `[kernel … pool blocked]` line to each manager with a report in that pool; nothing per persona. A second persona hitting the same block adds to `waiting`, no new card.
5. The block lifts at `blocked_until`; one `priority: low` card when the pool reopens, suppressed when the block was under 15 minutes.

## 8. While a pool is blocked (ruling 7)

- Default: wait. Every turn runs on the model the role was given, so the measurements stay clean.
- Manifest field `fallback_model` (empty by default; admitted override; validator: must be in a different pool from `model`). While the persona's own pool is blocked and `fallback_model` is set, the kernel re-spins the persona onto the fallback through the D54 handshake with `trigger: quota`, and re-spins it back at the next idle moment after the block lifts; each switch is `session.model_switched { from, to, reason }` and one `[kernel … model switched]` line to the persona. Suggested for the chief of staff and the managers only, so Rick can still reach the fleet.
- Every turn record already carries the model, so a fallback turn is distinguishable in every analysis.

## 9. Paid overage (ruling 8)

- `kernel engine overage = never | allow` (default `never`).
- At start, and before every spawn when the setting file has changed, the kernel writes `useG1Credits` and `useAiCredits` in `~/.gemini/antigravity-cli/settings.json` (and the shared `~/.gemini/config/config.json` when the key exists there) to match; `engine.overage { found: { useG1Credits, useAiCredits }, set: … }` records what it found and what it wrote. A key that reads differently from the setting at any later read is written again and logged at alert level (one spelling has been reported to re-enable itself).
- The lesson from lupin's `vertex_spend_ceiling.py` stands: a dollar budget is an alert, never a brake; only a rate limit stops spend. Under `never` a blocked pool stays blocked until its reset. Rick flips the key for a deadline; it takes effect at the next engine start.

## 10. Error kinds (ruling 9)

| Kind | Recognized by | The kernel |
| --- | --- | --- |
| `login_lapsed` | `authentication required` | Section 4 |
| `quota_exhausted` | a 429 (`RESOURCE_EXHAUSTED`, `code 429`, `quota reached`) **and** a stated `Resets in …` | Section 7; blocks the pool until that reset |
| `rate_limited` | a 429 naming a per-minute or rate limit, no reset | nothing: the engine's own retry handles it |
| `unavailable` | `code 502 | 503 | 504`, `UNAVAILABLE` | nothing for the first; D56's held-turn rule covers a long one |
| `refused_429` | a 429 with no reset and no rate-limit text | never blocks; `account.note_refused_429( persona_id )`; the second in a row for one persona while the meter shows allowance raises one alert `engine.refused_429_repeat` that the prompt may have been turned away; a good turn clears the count |
| `stale_error` | an error text on a turn that produced a `response` and no new error step | ignored, recorded |
| `other` | anything else | recorded at alert level, text kept (redacted by D50's `redact()`) |

The table is tested against the texts in Section 13 and against whatever the two hosts' engine logs already hold (the inventory script prints the three newest of each kind). The fixtures join D48's engine-update vetting run, so a new engine version that changes its wording is caught before a persona is admitted on it.

## 11. The reserve (ruling 10)

- `turn_gate( account, policy, role, model, now )` runs before every new turn in a pool. When the pool's five-hour remainder is under `kernel engine quota reserve five hour` (0.25), only `chief_of_staff` and `manager` start new turns; other personas' turns wait for the refill with their messages kept (`session.turn_deferred { reason: reserve }`, roster `deferred: reserve`).
- `kernel engine quota reserve mode = observe | enforce | off`, default `observe`: the rule logs `would_defer` and starts the turn. Switched to `enforce` after one week of records shows the reserve would have kept a manager reachable without idling workers more than Rick accepts. One number.
- A blocked pool or a lapsed sign-in defers every role; the reserve is the only role-aware gate.

## 12. The cost baseline (ruling 11)

- Daily kernel job `usage.rollup` (D65's job table, `daily at 00:10`, `app timezone`) folds the day's turn records (`turn.result.usage`: input, output, cache read, cache write, thinking where the engine reports it) by persona, role, model and billing route into `~/.lupin/kernel/usage/YYYY-MM-DD.json`.
- `lupin kernel usage [--days N] [--by persona|role|model]` prints the table with three derived columns: **list-price cost** from `kernel engine prices` (per model, per million tokens, in and out and cache read; a model with no price shows blank, never a guess), **pool share** consumed that day (first and last `engine.meter` of the day, both windows), and **tokens per pool point** (the day's third-party tokens over the five-hour points consumed, which over a week is the unpublished size of the allowance).
- **The baseline:** one working week of the Phase 4 shadow run (D63) on the development server, beside the same week's Claude Code usage from the sessions it shadows (Claude Code's own `/usage` and the Max plan's published price). Two numbers: dollars at list for the AGY week, and pool points per day against the plan's ceiling.
- **Prompt caching:** the cache-read column over the same week answers the deferred capture from ordinary use; that line leaves T34 and framework Section 14.5.
- No capture, no synthetic run.

## 15. Reference implementation (runs; ten tests pass on 2026-11-11, Python 3, no dependencies)

Lands in the kernel as `engine_account.py`; the Jetski-family adapter supplies the three reads (the meter JSON, a turn's error text, the sign-in probe's exit) and the admission list calls `admission_check` as check 5. Pure: no process, no clock, no file.

```python
"""
engine_account.py: what the kernel knows about the vendor account a fleet of engines shares.

Pure: no process, no clock, no file. The Jetski-family adapter supplies three reads (the usage
meter's JSON, a turn's error text, the sign-in probe's exit) and this module turns them into
facts and decisions. Shapes are from the public record for AGY 1.4.7 (spec Section 2); a shape
this module does not know is `other` or `unknown`, and unknown never refuses.
"""

import re
from dataclasses import dataclass, field
from typing      import Optional

# ---- pools -------------------------------------------------------------------------------------

# The meter's group names, as AGY prints them, keyed by the pool name the kernel uses.
POOL_BY_GROUP_NAME = {
    "gemini models"         : "gemini",
    "claude and gpt models" : "third_party",
    "gemini 4 argon"        : "argon",
}

def pool_for_model( model_id ):
    """
    Requires: model_id is an engine model identifier, for example "opus-5.5-high"
    Ensures : returns "argon", "gemini" or "third_party"; a model that is not Gemini is third_party
    """
    name = model_id.lower()
    if name.startswith( "gemini-4-argon" ): return "argon"
    if name.startswith( "gemini" )        : return "gemini"
    return "third_party"

# ---- the meter ---------------------------------------------------------------------------------

@dataclass
class Bucket:
    pool               : str
    window             : str              # "five_hour" | "weekly"
    remaining_fraction : float
    reset_time         : Optional[ str ]  # as the engine printed it; the kernel parses it at the edge

WINDOW_NAMES = { "5h": "five_hour", "weekly": "weekly" }

def parse_usage( reply ):
    """
    Requires: reply is the parsed JSON of `agy -p "/usage" --output-format json`
    Ensures : returns a list of Bucket, empty when the reply is not a usage answer;
              an unknown group or window is skipped, never guessed
    """
    command = ( reply or {} ).get( "command" ) or {}
    if command.get( "name", "usage" ) not in ( "usage", "quota" ): return []
    buckets = []
    for group in ( command.get( "data" ) or {} ).get( "groups" ) or []:
        pool = POOL_BY_GROUP_NAME.get( str( group.get( "name", "" ) ).strip().lower() )
        if pool is None: continue
        for bucket in group.get( "buckets" ) or []:
            window   = WINDOW_NAMES.get( bucket.get( "window" ) )
            fraction = bucket.get( "remaining_fraction" )
            if window is None or not isinstance( fraction, ( int, float ) ): continue
            buckets.append( Bucket( pool, window, float( fraction ), bucket.get( "reset_time" ) ) )
    return buckets

# ---- errors ------------------------------------------------------------------------------------

RESET_PATTERN = re.compile( r"Resets in\s+((?:\d+h)?(?:\d+m)?(?:\d+(?:\.\d+)?s)?)" )
PART_PATTERN  = re.compile( r"(\d+(?:\.\d+)?)([hms])" )

def parse_reset_seconds( error_text ):
    """
    Ensures: returns the seconds in "Resets in 148h49m28s", or None when no reset is stated
    """
    match = RESET_PATTERN.search( error_text or "" )
    if not match or not match.group( 1 ): return None
    scale = { "h": 3600, "m": 60, "s": 1 }
    return int( sum( float( amount ) * scale[ unit ] for amount, unit in PART_PATTERN.findall( match.group( 1 ) ) ) )

def classify_error( error_text, response="", saw_new_error_step=True ):
    """
    Requires: error_text is a result's `error`, an error step's text, or a stderr line
              response is the result's `response` for the same turn
              saw_new_error_step is False when the turn's own steps held no error
    Ensures : returns ( kind, reset_seconds ); kind is one of
              login_lapsed, quota_exhausted, rate_limited, unavailable, refused_429, stale_error, other
              only quota_exhausted carries reset_seconds, and only it may block a pool
    """
    text = error_text or ""
    if not text.strip(): return ( "other", None )
    if re.search( r"authentication required", text, re.I ): return ( "login_lapsed", None )
    if response.strip() and not saw_new_error_step       : return ( "stale_error", None )
    is_429 = bool( re.search( r"RESOURCE_EXHAUSTED|\bcode 429\b|quota reached", text, re.I ) )
    reset  = parse_reset_seconds( text )
    if is_429 and reset is not None                        : return ( "quota_exhausted", reset )
    if is_429 and re.search( r"per.minute|rate limit", text, re.I ): return ( "rate_limited", None )
    if is_429                                              : return ( "refused_429", None )
    if re.search( r"\bcode 50[234]\b|UNAVAILABLE", text )  : return ( "unavailable", None )
    return ( "other", None )

# ---- the account -------------------------------------------------------------------------------

@dataclass
class EngineAccount:
    """What the kernel holds for one engine's account on one host."""
    login          : str   = "unknown"                     # "ok" | "lapsed" | "unknown"
    buckets        : list  = field( default_factory=list ) # the last meter read
    sampled_at     : Optional[ float ] = None
    blocked_until  : dict  = field( default_factory=dict ) # pool -> epoch seconds, from an observed exhaustion
    bare_429_count : dict  = field( default_factory=dict ) # persona_id -> consecutive refused_429

    def remaining( self, pool, window ):
        for bucket in self.buckets:
            if bucket.pool == pool and bucket.window == window: return bucket.remaining_fraction
        return None

    def pool_blocked_until( self, pool, now ):
        """An observed exhaustion outranks the meter until its stated reset has passed."""
        until = self.blocked_until.get( pool )
        return until if until is not None and until > now else None

    def note_exhaustion( self, pool, reset_seconds, now ):
        self.blocked_until[ pool ] = max( self.blocked_until.get( pool, 0 ), now + reset_seconds )

    def note_refused_429( self, persona_id ):
        """Ensures: returns True when this is the second in a row for the persona (raise the alert once)"""
        count = self.bare_429_count.get( persona_id, 0 ) + 1
        self.bare_429_count[ persona_id ] = count
        return count == 2

    def note_good_turn( self, persona_id ):
        self.bare_429_count.pop( persona_id, None )

# ---- decisions ---------------------------------------------------------------------------------

@dataclass
class QuotaPolicy:
    spawn_floor_five_hour : float = 0.15
    spawn_floor_weekly    : float = 0.05
    reserve_five_hour     : float = 0.25
    reserved_roles        : tuple = ( "chief_of_staff", "manager" )
    reserve_mode          : str   = "observe"              # "enforce" | "observe" | "off"
    sample_max_age        : float = 900.0

def admission_check( account, policy, model_id, now, is_wake=False ):
    """
    Check 5 of admission (after skeleton crew, batch cap, fleet cap, host capacity).

    Ensures: returns None to admit, or a refusal dict { check, pool, reason, retry_after_seconds, ... }
             login lapsed refuses a spawn and a wake alike
             a blocked pool refuses a spawn and defers a wake
             a low meter refuses a spawn only; a wake is never refused for a low meter
             a missing or stale meter admits (unknown never refuses)
    """
    if account.login == "lapsed":
        return { "check": "engine_login", "reason": "login_lapsed", "retry_after_seconds": None }
    pool  = pool_for_model( model_id )
    until = account.pool_blocked_until( pool, now )
    if until is not None:
        return { "check": "engine_quota", "pool": pool, "reason": "exhausted", "retry_after_seconds": int( until - now ) }
    if is_wake: return None
    if account.sampled_at is None or now - account.sampled_at > policy.sample_max_age: return None
    for window, floor in ( ( "five_hour", policy.spawn_floor_five_hour ), ( "weekly", policy.spawn_floor_weekly ) ):
        left = account.remaining( pool, window )
        if left is not None and left < floor:
            return { "check": "engine_quota", "pool": pool, "reason": "low", "window": window,
                     "remaining_fraction": left, "floor": floor, "retry_after_seconds": None }
    return None

def turn_gate( account, policy, role, model_id, now ):
    """
    Whether a persona may start a new turn now.

    Ensures: returns ( decision, reason ); decision is "start", "defer" or "would_defer"
             a blocked pool or a lapsed login defers every role
             under the five-hour reserve only reserved roles start; in observe mode the rest
             start too and the kernel logs would_defer
    """
    if account.login == "lapsed": return ( "defer", "login_lapsed" )
    pool = pool_for_model( model_id )
    if account.pool_blocked_until( pool, now ) is not None: return ( "defer", "exhausted" )
    left = account.remaining( pool, "five_hour" )
    if policy.reserve_mode == "off" or left is None or left >= policy.reserve_five_hour: return ( "start", None )
    if role in policy.reserved_roles: return ( "start", "reserved_role" )
    return ( "defer", "reserve" ) if policy.reserve_mode == "enforce" else ( "would_defer", "reserve" )
```

| Alternative | Why not |

| Gemini Enterprise credentials now | per-token billing for a fleet of Opus personas; partner models behind an administrator; Fable unlisted; unmeasured here. Reserved as `billing: cloud` |
| Several Google accounts switched per persona | the tool keeps one sign-in per operating-system account; third-party switchers swap a global entry and race; Google says extra limits by other means are unsupported |

| Automatic fallover for every persona | silently changes what is being measured and drains the second pool |
| A token budget per persona | fair, but needs the pool's unpublished size and much tuning; the reserve is one number |
| A dedicated cost-measuring run | spends allowance on a workload that will not match real use; the shadow week is the real one |
