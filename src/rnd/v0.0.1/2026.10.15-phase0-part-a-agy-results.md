## Findings and what they change

### Tool gate (§8)

- **Hooks block calls in headless mode.** The project file `.agents/hooks.json` in the named-set shape (format A) works.
- **What the model sees on a deny:** `tool call denied by pre-tool hook: <deny_reason>`. The turn still ends `SUCCESS`, and the model reported the refusal accurately. A guard only has to return a reason string.
- **Hooks inherit the engine's environment.** `LUPIN_PERSONA_ID` reaches the guards with no lookup.
- **What the hook payload contains:** `conversationId`, `transcriptPath`, `modelName`, `stepIdx`, `workspacePaths`, `artifactDirectoryPath`, `toolCall {name, args}`. `transcriptPath` gives the arbiter an AGY transcript to read. `conversationId` maps a hook call to its session.
- **Every call carries `toolAction` and `toolSummary`.** These are short descriptions the engine writes ("Reading notes.txt") and are ready-made text for spoken progress updates.

| AGY tool | Key arguments | Claude equivalent |
|---|---|---|
| `run_command` | `CommandLine`, **`Cwd`**, `WaitMsBeforeAsync` | `Bash` (`command`) |
| `view_file` | `AbsolutePath` | `Read` (`file_path`) |
| `write_to_file` | `TargetFile`, `CodeContent`, `Overwrite`, `Description` | `Write` (`file_path`, `content`) |
| `replace_file_content` | `TargetFile`, `TargetContent`, `ReplacementContent`, `StartLine`, `EndLine`, `AllowMultiple`, `Instruction` | `Edit` (`file_path`, `old_string`, `new_string`) |
| `read_url_content` | `Url` | `WebFetch` (`url`) |
| `call_mcp_tool` | `ServerName`, `ToolName`, `Arguments` | `mcp__<server>__<tool>` |

Rules for the guard port:

1. **Use `args.Cwd` for repo resolution.** The commit-scope and merge-head guards currently resolve the repo from the process's working directory, which is wrong whenever the model sets `Cwd`.
2. **`WaitMsBeforeAsync` (10 000 ms default) lets a shell command keep running in the background after its tool call returns.** "Turn ended" does not mean "process gone". This affects the kill guard and the turn-age watchdog.
3. **The model listed, grepped and globbed through `run_command`.** No dedicated list or search tool appeared, so the existing Bash command-line guards cover nearly everything.
4. **MCP calls arrive as one generic tool.** Guards and the Write/Edit memento guard match on `name` plus `args.ServerName`/`args.ToolName`, never on a per-tool name.

### Identity (§4, §10)

- **One MCP server per engine.** Each server's parent pid is its engine's pid, and the two concurrent personas had two servers.
- **Inheritance works:** `persona-1` and `persona-2` each reached their own server.
- **`mcp_config.json` `env` blocks apply, but `${VAR}` is not expanded.** Static settings go in the config; per-persona values must come through the inherited environment.
- **Design:** the harness sets `LUPIN_PERSONA_ID` at spawn, and cosa-voice and hooks read it. No bridge-file lookup is needed.
- **Location:** AGY's MCP config is `~/.gemini/config/mcp_config.json`, managed by `agy mcp add|remove|list|enable|disable`.
- **The model called `view_file` once before its first MCP call in both C3 runs.** Possibly it reads the tool's schema. Worth one look in Part B: it adds a step and some latency per first MCP use.

### Resume (§5)

- `--conversation <unknown uuid>` is **accepted without error and starts a new conversation** with its own id. Resuming with the id the engine reported works (PELICAN was recalled).
- **Harness rule:** after every spawn with `--conversation`, check `init.conversation_id == requested`. On a mismatch, alert and stop. Never continue quietly, because a stale id silently drops the persona's context.

### Response pyramid and timing (§7, D13)

- **Every layer appeared exactly where intended.** Abstracts appeared for the table, tool-use, explanation and tips prompts. A document appeared only for the explicit request. The greeting and sign-off stayed spoken-only.
- **Caveat 1:** every reply used exactly three spoken lines, including "Say hello". The model reads "at most two supporting sentences" as "two". Tighten the rules text, for example "one line is enough when one line answers".
- **Caveat 2:** 8/8 counts lines, not quality. Rerun with `REPEAT=3` and read the spoken lines before trusting the rate.
- **D13 stands:** one notification per turn, at the end. The median gap is 0.7 s. Only document turns gap meaningfully (6.6 s).
- **Latency:**
    - The document prompt took 283 s to first token; it probably wrote artifacts first (check `transcriptPath`).
    - First speech on a fresh process was about 9 s, against about 2 s warm (10-12 measurement). Keep persona processes warm.

### Versions

- **AGY updates itself, and `agy update` has no flags**, so automatic updates can't be turned off from the command line.
- **Harness rule:** record `--version` in the session log at every spawn. Every capture already records `version.txt`.

## Incident: environment logging

The first C3 run logged every `LUPIN_*` variable, including a password, and the model echoed it in its reply. The output was deleted on the server. Both probes now log an exact allow-list of seven names and nothing else. Part B must use the fixed probes.
