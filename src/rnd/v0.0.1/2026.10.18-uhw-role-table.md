# UHW role table: what each persona sees and what governs it

**As of:** 2026-10-18 · lupin `78982e4fc` (`cosa_voice_mcp.py`: 32 tools) · follows D25 (threat model) and C11c (Jetski agent `tools:` covers native tools only)

## How a role is applied

Three mechanisms, one per surface. The persona manifest names the role, and the harness renders all three.

| Surface | Mechanism | Claude Code | Jetski / AGY |
|---|---|---|---|
| **Native tools** | allow-list at launch; anything not listed doesn't exist for the model | `--allowedTools` / `--disallowedTools` in the generated launch | `tools:` in the persona's agent definition (`--agent`) |
| **cosa-voice tools** | `tools/list` filtered by role: **exposure only** (D25) | same server | same server (the agent `tools:` list can't touch MCP, C11c) |
| **Rules** | the tool gate checks the common call shape; each rule is `enforce` or `observe` | PreToolUse hook shim | `.agents/hooks.json` shim |

**Roles** (from the cascade review cast and the adversarial SWE crew):
- `chief_of_staff` is the persona you talk to: it works on your behalf, staffs managers, and is the one escalation point to you. When you can't be reached, it is where the preference-learning surrogate answers in your stead (D26).
- `manager` runs a cascade or a crew.
- `steward` is the Workflow Steward.
- `author` writes the plan under review.
- `implementer`, `reviewer` and `tester` are crew members.

Notes:
- **Questions to you go through the manager; everything else is open** (D27). Only questions *to you* are routed. Crew members collaborate freely: they post to the commons, ask peers on a topic, and DM any colleague. When a crew member needs *your* answer, it asks its manager by DM (`dm-<manager>`), and the manager asks you or falls back to the chief of staff (D27). **All work is narrated, only some is spoken** (D28): crew still narrate through `notify` and their end-of-turn replies, so you can drill into any worker's progress. Whether a narration is spoken is decided on the client (priority, quiet mode by `sender_id`, the global slider), which is progressive disclosure applied to voice.
- **Every ask is ticketed** (C14): `converse`, the `ask_*` tools and `commons_ask_sync` return `pending` plus a ticket after about 150 s. Each gets a companion `ask_wait( ticket )`, listed wherever the ask is.
- **The steward sees the roster but cannot staff or reap.** It acknowledges `harvest-complete` by DM, and the manager does the reaping.
- **`chief_of_staff` lists the full set** because it staffs managers and may run a team itself.

## 3. Rules

Common call shape (framework §8); first matching rule decides; default **allow**.

| Rule | Applies to | Mode | Source |
|---|---|---|---|
| No in-process subagents for staffed roles | `invoke_subagent`, `define_subagent`, `manage_subagents`, `swarm` · `Task`/`Agent`, for every role except `chief_of_staff` | **enforce** | AH4L `subagent_governance` (parity) |
| Memento writes only through the memento path | `write`/`edit` targeting memento files | **enforce** | AH4L / p-is-p `memento_record_guard` |
| R&D docs written only where the workflow allows | `write`/`edit` under `src/rnd/` | **enforce** | p-is-p `rnd_write_guard` |
| Worktrees created only through the registry | `shell` matching `git worktree add` | **enforce** | p-is-p `worktree_creation_guard` |
| Commit scope and merge head | `shell` matching `git commit` / `git merge`, repo resolved from `cwd` (Part A rule 1) | **enforce** | AH4L guards |
| Branch protection | git reference-transaction hook (outside the tool gate) | **enforce** | `branch_guard` (engine-neutral) |
| Role exposure | any cosa-voice call to a tool not listed for the caller's role (§2) | observe | D25 |
| Task ownership | `task_transition`, `task_amend`, `task_edit`, `task_correlate` on an item the caller neither owns nor manages | observe | D25 |
| Fleet ownership | `dismiss_sessions` naming a session the caller didn't spawn | observe | D25 |
| Crew ask you only through their manager | `converse`, `ask_yes_no`, `ask_multiple_choice`, `ask_open_ended_batch` from a crew role | observe | D27 |
| Native duplicates | any never-listed native tool (§1) that is reached anyway | observe | D21, D22, D5 |

Notes:
- **AH4L guards not named here** (inventory §13) port at **enforce** under the same parity rule. This table lists those whose targets are known today.
- **An observe-mode miss writes** `{rule, persona, role, tool, arguments digest}` to the session log. The fleet-health module (D24) can then report would-deny counts per rule before any rule is switched to enforce.
